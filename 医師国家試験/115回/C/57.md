# 115回 C-57

## 問題

78歳の女性。左膝関節痛を主訴に来院した。2日前に誘因なく左膝関節痛が出現し、次第に増悪してきたため受診した。膝関節に腫脹を認め、発赤、熱感を伴っている。関節穿刺で、黄白色のやや混濁した関節液を認めた。

可能性が高い疾患はどれか。2つ選べ。

- 1. 偽痛風
- 2. 半月板断裂
- 3. 化膿性関節炎
- 4. 特発性膝骨壊死
- 5. 変形性膝関節症

## 正答・解説

**正答：1. 偽痛風、3. 化膿性関節炎**

1. **決め手**：高齢者の膝に、誘因のない急性発症の腫脹・発赤・熱感と混濁関節液を認める。急性単関節炎として偽痛風と化膿性関節炎を考える。
2. **CBT最小知識**：偽痛風はCPP結晶による急性関節炎で、高齢者の膝に多い。化膿性関節炎は緊急性があり、関節液のグラム染色・培養で評価する。
3. **選択肢からの連想**：半月板断裂は外傷や機械的症状、変形性膝関節症は慢性の運動時痛が中心。特発性膝骨壊死も通常はこのような急性炎症所見を示さない。
4. **ひっかけポイント**：偽痛風に似ていても化膿性関節炎を除外できない。関節液の結晶検査と培養を行う。
5. **一言暗記**：**高齢者の急性膝単関節炎は偽痛風と化膿性関節炎をまず考える。**
