# 93回 B-56

## 問題

糖尿病性腎症について正しいのはどれか。3つ選べ。

- 1. 早期診断には尿中微量アルブミンの測定が有用である。
- 2. 早期から糸球体濾過値の低下が認められる。
- 3. 腎不全になるとインスリンの必要量が増加する。
- 4. 糸球体輸入・輸出細動脈の硬化を認める。
- 5. 進行するとネフローゼ症候群をきたす。

## 正答・解説

**正答：1、4、5**

1. **決め手**：「早期診断」「微量アルブミン」および糖尿病性腎症の進行に伴う蛋白尿・ネフローゼという流れ。
2. **CBT最小知識**：初期は糸球体過剰濾過で、尿中微量アルブミンが先行する。進行するとGFR低下、顕性蛋白尿、ネフローゼ症候群、腎不全を来す。病理では糸球体硬化と輸入・輸出細動脈の硝子化を認める。
3. **選択肢からの連想**：腎不全ではインスリンの[[腎クリアランス]]が低下し、作用が遷延するため必要量は減少しやすい。
4. **ひっかけポイント**：早期はGFR低下ではなく過剰濾過。腎不全時のインスリン必要量は増加ではなく減少が基本。
5. **一言暗記**：**糖尿病性腎症は微量アルブミン尿が先行し、進行するとGFR低下・ネフローゼ；腎不全ではインスリン減量に注意。**
