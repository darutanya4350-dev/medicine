# 90回 D-29

## 問題

63歳の女性。3ヵ月前に突然口渇が出現するようになったので来院した。冷水を好んで飲用し、夜間に5、6回の排尿を認める。頭痛、視力障害および頭部外傷の既往はない。尿所見：糖（－）、蛋白（－）。高張食塩水負荷後尿浸透圧210mOsm/L。血清生化学所見：空腹時血糖76mg/dL、総蛋白7.6g/dL、尿素窒素14mg/dL、クレアチニン0.8mg/dL。血清浸透圧288mOsm/L（正常275～288）。

予想される検査所見はどれか。3つ選べ。

- 1. 尿量6,400mL/日
- 2. 血清ナトリウム148mEq/L
- 3. 空腹時尿浸透圧160mOsm/L
- 4. 水制限後体重3％減少時尿浸透圧684mOsm/L
- 5. バゾプレシン投与後尿浸透圧220mOsm/L

## 正答・解説

**正答：1、2、3**

1. **決め手**：尿糖陰性・正常血糖なのに口渇と多尿があり、高張食塩水負荷後も尿浸透圧が210mOsm/Lと低い。[[尿崩症]]を考える。
2. **CBT最小知識**：尿崩症では自由水を失うため、多尿、低張尿、血清Na高値をきたす。中枢性尿崩症では水制限でも尿を濃縮できず、バゾプレシン投与後は尿浸透圧が上昇する。
3. **選択肢からの連想**：水制限後に尿浸透圧が十分上昇するのは原発性多飲など。バゾプレシン投与後も反応が乏しければ[[腎性尿崩症]]を考える。
4. **ひっかけポイント**：高張食塩水負荷後の低尿浸透圧だけでは中枢性・腎性を確定できない。両者の鑑別にはバゾプレシンまたはデスモプレシンへの反応をみる。
5. **一言暗記**：**尿崩症は多尿・低張尿・高Na血症、水制限でも濃縮不良。**
