# 82回 C-54（改題）

## 問題

関節液の所見で正しい組合せはどれか．

- a．関節リウマチ － 粘稠度の増加
- b．正常 － 半透明
- c．化膿性関節炎 － 膿性
- d．半月板損傷 － 脂肪滴の存在
- e．変形性関節症 － 粘稠度の減少

## 正答・解説

**正答：c．化膿性関節炎 － 膿性**

- 化膿性関節炎では、関節液は混濁〜膿性となり、好中球増多と粘稠度低下を伴う。
- [関節リウマチ](../../../03_疾患/膠原病・免疫/関節リウマチ.md)では粘稠度は低下する。正常関節液は透明で高粘稠度である。
- 脂肪滴は関節内骨折などでみられ、半月板損傷の典型所見ではない。
- 変形性関節症では非炎症性関節液で、粘稠度は比較的保たれる。
