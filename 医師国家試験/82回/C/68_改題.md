# 82回 C-68 改題

## 問題

4歳の女児。跛行を訴えて来院した。X線単純写真で両側発育性股関節形成不全と診断された。現在まで治療は受けていない。

この患児にみられる所見はどれか。**3つ選べ。**

- a. Trendelenburg徴候を両側にみる。
- b. 両側股関節に著明な拘縮をみる。
- c. 開排制限がみられる。
- d. 大腿骨頭が前上方へ変位している。
- e. 大腿皮膚溝に左右差がみられる。

## 正答・解説

**正答：a、c、d**

1. **決め手**：4歳の未治療・両側病変・跛行から、歩行開始後の両側DDHの所見を考える。
2. **CBT最小知識**：年長児のDDHでは、開排制限、跛行、Trendelenburg徴候、骨頭の上方偏位をみる。
3. **選択肢からの連想**：両側例では大腿皮膚溝の左右差は目立ちにくい。著明な拘縮は必須所見ではない。
4. **ひっかけポイント**：皮膚溝の左右差や脚長差は一側性で手掛かりになりやすいが、両側性では左右差が出にくい。
5. **一言暗記**：**両側DDHは両側Trendelenburg＋開排制限、皮膚溝の左右差は目立たない。**
