# 86回 E-42

## 問題

5歳の女児。腹部膨満を主訴として来院した。人形様顔貌、著明な肝腫大がある。血清生化学所見：空腹時血糖30mg/dL、空腹時乳酸70mg/dL（正常5～20）、尿酸8mg/dL、総コレステロール250mg/dL。この疾患でしばしば認められるのはどれか。2つ選べ。

- 1. 心肥大
- 2. 巨舌
- 3. 筋力低下
- 4. 鼻出血
- 5. 低身長

## 正答・解説

**正答：4、5**

1. **決め手**：人形様顔貌・著明な肝腫大に、低血糖、乳酸高値、尿酸高値、高コレステロール血症を伴う。
2. **CBT最小知識**：[[糖原病Ⅰ型（von Gierke病）]]では、低血糖、乳酸アシドーシス、高尿酸血症、高脂血症、肝腫大、低身長をきたす。
3. **選択肢からの連想**：筋力低下は筋型糖原病、巨舌は[[先天性甲状腺機能低下症]]、心肥大は蓄積性疾患などを連想する。
4. **ひっかけポイント**：糖原病Ⅰ型は肝型で、空腹時低血糖が強い。筋症状が中心の糖原病とは区別する。
5. **一言暗記**：人形様顔貌＋肝腫大＋低血糖・乳酸・尿酸高値＝糖原病Ⅰ型。
