# 111回 I-12

## 問題

糖尿病性足壊疽で正しいのはどれか。

1. 痛みを強く自覚する。
2. 血行障害の併存がある。
3. 両側対称性が特徴である。
4. 末梢神経障害は合併しにくい。
5. 深部の重症感染の原因菌はGram陽性球菌が多い。

## 正答・解説

**正答：2. 血行障害の併存がある**

**糖尿病性足病変の3大原因**：末梢神経障害・血行障害（PAD）・感染 — この3因子が重なって重症化する。

**各選択肢の検討**

| 選択肢                  | 正誤    | 根拠                                                 |
| -------------------- | ----- | -------------------------------------------------- |
| 1. 痛みを強く自覚する         | ×     | [[糖尿病性神経障害]]による**知覚低下**のため痛みに気づきにくい。重症化するまで発見が遅れる  |
| **2. 血行障害の併存がある**    | **○** | 動脈硬化（[[閉塞性動脈硬化症|末梢動脈疾患]]）による血流低下が創傷治癒を遷延させ、壊疽を悪化させる         |
| 3. 両側対称性が特徴          | ×     | 骨突出部・圧力がかかる部位に生じ、**片側性**が多い。両側対称性は末梢神経障害の症状の特徴     |
| 4. 末梢神経障害は合併しにくい     | ×     | 神経障害は必発に近く合併する。知覚低下が受診遅延の主因                        |
| 5. 深部重症感染 → Gram陽性球菌 | ×     | 深部・重症例では**Gram陰性桿菌**（緑膿菌など）を含む**混合感染**が多い　[[蜂窩織炎]] |

**覚え方**

| 病態 | 結果 |
|---|---|
| 末梢神経障害 | 痛みに気づかない → 傷の発見遅延 |
| 血行障害 | 治癒しない → 壊死・壊疽 |
| 感染 | 深部に拡大 → 骨髄炎・敗血症 |

> 深部重症感染の原因菌：**Gram陰性桿菌（緑膿菌など）＋混合感染** ← 国試頻出の誤り選択肢
