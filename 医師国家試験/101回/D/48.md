# 101回 D-48

## 問題

54歳の男性。意識障害を主訴に来院した。

**現病歴**：5年前に1型糖尿病と診断され、インスリン治療を開始した。1週前から38℃台の発熱と咽頭痛とがあり、2日前食欲低下と嘔気とを認めたためインスリン注射を自己中止した。今朝、意識がもうろうとしているところを家族に気付かれた。

**家族歴**：特記すべきことはない。

**現症**：意識はJCSⅡ-20。身長176cm、体重60kg。体温37.3℃。呼吸数30/分。脈拍92/分、整。血圧124/76mmHg。貧血と黄疸とを認めない。舌は乾燥している。心音と呼吸音とに異常を認めない。腹部は平坦、軟で、肝・脾は触知しない。

**検査所見**：尿所見：蛋白（－）、糖4＋、ケトン体3＋。血糖は簡易測定器で測定可能範囲を超える異常高値である。

生理食塩水の点滴と静脈内インスリン持続注入とによって患者の意識レベルは一時改善したが、やがて再び意識障害が進行した。  
治療方針を決めるために最も有用な検査はどれか。

- a. 頭部単純CT
- b. 脳脊髄液
- c. 脳波
- d. 心エコー検査
- e. 心電図

## 正答・解説

**正答：a. 頭部単純CT**

本症例の診断は[[糖尿病性ケトアシドーシス]]（DKA）。1型DM・インスリン自己中止・尿ケトン体3＋・呼吸数30/分（Kussmaul呼吸）が根拠。

**問題の核心：治療後に意識障害が再増悪した理由**

> DKA治療中に「一時改善 → 再び悪化」のパターン ＝ **脳浮腫**を第一に疑う

**脳浮腫（DKA合併）**
- 誘因：インスリンによる急速な血糖降下・浸透圧の急低下 → 脳内への水分移動
- 好発：小児・若年者（本例は54歳で比較的若め）
- 症状：意識レベルの二相性悪化、頭痛、嘔吐
- 対応：マンニトール・高張食塩水（浸透圧療法）

**各選択肢の検討**

| 選択肢 | 判断 |
|---|---|
| **a. 頭部単純CT** | **○** 脳浮腫・脳出血・脳梗塞など構造的異常を迅速に評価 |
| b. 脳脊髄液 | × 脳浮腫疑いで腰椎穿刺は脳ヘルニア誘発のリスクあり。CT先行が原則 |
| c. 脳波 | × てんかんを疑う状況ではなく、緊急性・迅速性でCTに劣る |
| d. 心エコー | × 意識障害の原因として心原性を疑う根拠が乏しい |
| e. 心電図 | × DKAでは高K血症の評価に有用だが、再増悪の原因検索では頭部CTが優先 |

**覚え方**  
DKA治療中の意識悪化 → 脳浮腫 → **CT**（腰椎穿刺は後回し）
