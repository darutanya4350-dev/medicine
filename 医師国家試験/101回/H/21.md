# 101回 H-21

## 問題

53歳の女性。健康診査で脂質異常症を指摘されて来院した。喫煙習慣と飲酒習慣とはない。父が脳卒中で死亡している。身長160cm、体重67kg、腹囲86cm。脈拍76/分、整。血圧142/90mmHg。心音と呼吸音とに異常を認めない。尿所見：蛋白（－）、糖（－）。血清生化学所見：空腹時血糖128mg/dL、総コレステロール246mg/dL、LDL-コレステロール159mg/dL、HDL-コレステロール54mg/dL、トリグリセリド156mg/dL。心電図では上室性期外収縮が散発している。

対応として適切なのはどれか。2つ選べ。

- 1. 生活指導
- 2. 3か月後の血清生化学検査
- 3. 血糖降下薬の投与
- 4. スタチン系薬の投与
- 5. フィブラート系薬の投与

## 正答・解説

**正答：1. 生活指導、2. 3か月後の血清生化学検査**

1. **決め手**：LDL-C 159 mg/dL、TG 156 mg/dLは軽度上昇で、明らかな動脈硬化性疾患もない。腹囲増加・血圧高値もあり、まず生活習慣を改善して再評価する。
2. **CBT最小知識**：脂質異常症の一次予防では、包括的リスクを評価し、生活指導を基本に一定期間後の脂質再検査を行う。
3. **選択肢からの連想**：LDL-C高値には[[スタチン]]、TG高値にはフィブラートを用いるが、異常が軽度なら直ちに開始しない。空腹時血糖128 mg/dLは再検査などで[[糖尿病]]を確認してから治療を判断する。
4. **ひっかけポイント**：上室性期外収縮は脂質異常症の薬物療法適応を決める所見ではない。薬剤は脂質値だけでなく、動脈硬化性疾患リスク全体で選ぶ。
5. **一言暗記**：**軽度の脂質異常症の一次予防は生活指導→約3か月後に再評価。**
