# 麻酔薬

> 全身麻酔は、主に**催眠（意識消失）・鎮痛・筋弛緩**を組み合わせて行う。薬剤ごとに担う作用が異なる。

## 薬効群の整理

| 薬効群 | 主な作用 | 代表薬 |
|---|---|---|
| **静脈麻酔薬** | 催眠・全身麻酔の導入／維持 | [プロポフォール](プロポフォール.md)、ケタミン、チオペンタール |
| **吸入麻酔薬** | 全身麻酔の維持 | [セボフルラン](セボフルラン.md)、イソフルラン、亜酸化窒素（笑気） |
| **催眠鎮静薬** | 鎮静・抗不安・健忘 | ジアゼパム、ミダゾラム |
| [**局所麻酔薬**](局所麻酔薬.md) | 神経伝導を遮断し、局所の感覚を消失 | リドカイン、ロピバカイン |
| **オピオイド** | 強い鎮痛 | モルヒネ、フェンタニル |

## CBTチェック

- ケタミン → **静脈麻酔薬**。鎮痛作用も有する。
- 亜酸化窒素（笑気） → **吸入麻酔薬**。鎮痛作用を有する。
- ベンゾジアゼピン系（ジアゼパム、ミダゾラム） → **鎮静薬**であり、鎮痛作用は乏しい。
- フェンタニル → **オピオイド鎮痛薬**（[オピオイド](../鎮痛薬/オピオイド.md)）。
