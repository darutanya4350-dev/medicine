# 高脂血症治療薬の一覧

> 脂質異常症治療薬は、主にLDL-Cを下げる薬と[[トリグリセリド]]（TG）を下げる薬に分けて整理する。

## 薬剤分類

| 主な標的 | 薬剤・ノート | CBTでの要点 |
|---|---|---|
| LDL-C | [スタチン](スタチン.md)（アトルバスタチン、ロスバスタチン、ピタバスタチンなど） | HMG-CoA還元酵素阻害。第一選択薬 |
| LDL-C | [エゼチミブ](エゼチミブ.md) | NPC1L1阻害。小腸コレステロール吸収を抑制 |
| LDL-C | [エボロクマブ](エボロクマブ.md) | PCSK9阻害。LDL受容体の分解を抑制 |
| TG | [フィブラート系薬剤](フィブラート系薬剤.md) | PPARα活性化。TG低下作用が最も強い |
| TG・動脈硬化リスク | [イコサペント酸エチル](イコサペント酸エチル.md) | EPA製剤。主にTGを低下 |

## 追加で押さえる薬剤

- [[陰イオン交換樹脂]]：胆汁酸と結合し、腸管からの再吸収を抑えてLDL-Cを低下させる。
- [[ニコチン酸]]：脂肪組織からの遊離脂肪酸放出を抑え、TGを低下させる。
- [[プロブコール]]：LDL-Cを低下させるが、使用場面は限定的。
- [[ロミタピド]]：MTP阻害薬。LDL受容体活性が完全欠損したFHホモ接合体にも効果が期待できる。
- [[エビナクマブ]]：ANGPTL3阻害薬。LDL受容体非依存的にLDL-Cを低下させる。

## CBTチェック

- **LDL-C**：スタチン、エゼチミブ、エボロクマブ。
- **TG**：フィブラート系薬剤、イコサペント酸エチル。
- **FHホモ接合体でLDL受容体完全欠損**：ロミタピド、エビナクマブ。
- 一言暗記：**スタチンはLDL、フィブラートとEPAはTG、PCSK9阻害薬はLDL受容体を保つ。**
