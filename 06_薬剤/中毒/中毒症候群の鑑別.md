# 中毒症候群の鑑別

> 中毒では、原因物質を直接同定できなくても、意識・呼吸・瞳孔・分泌・皮膚・循環の組合せから中毒症候群（toxidrome）を推定できる。まず気道・呼吸・循環を安定化する。

## 要点

| 中毒 | CBTでの決め手 | 初期対応・解毒 |
|---|---|---|
| [[オピオイド]] | [[意識障害]]＋呼吸抑制＋縮瞳 | 換気、[[ナロキソン]] |
| 有機リン | 縮瞳＋流涎・発汗・下痢＋気道分泌増加 | [[硫酸アトロピン]]＋PAM（プラリドキシム） |
| 交感神経刺激薬 | 興奮、散瞳、頻脈、高血圧、高体温、発汗 | ベンゾジアゼピン、冷却、支持療法 |
| 抗コリン薬 | 意識障害、散瞳、頻脈、高体温、皮膚乾燥、尿閉 | 支持療法、気道・循環管理 |
| 鎮静薬・睡眠薬 | 意識障害、呼吸抑制、筋弛緩 | 気道確保・換気、支持療法 |
| 三環系抗うつ薬 | 意識障害、けいれん、低血圧、QRS幅延長・不整脈 | 炭酸水素ナトリウム |

### 胃洗浄と代表的な解毒薬

- 胃洗浄は、灯油・ガソリンなどの石油製品、強酸・強アルカリ、気道未確保の意識障害では避ける。誤嚥、再損傷、穿孔の危険がある。
- 活性炭は、吸着される物質を大量摂取してから早期（目安1時間以内）に、気道が保護されている場合に検討する。石油製品・腐食性物質・鉄・リチウムなどには無効または不適である。
- オピオイド→[[ナロキソン]]、アセトアミノフェン→N-アセチルシステイン、ベンゾジアゼピン→フルマゼニル、ワルファリン→ビタミンK、有機リン→[[硫酸アトロピン]]＋プラリドキシム。

### 特に混同する3群

| 症候 | オピオイド | 有機リン | 抗コリン薬 |
|---|---|---|---|
| 瞳孔 | 縮瞳 | 縮瞳 | 散瞳 |
| 分泌・皮膚 | 目立たない | びしょびしょ（流涎・発汗・気道分泌） | カラカラ（皮膚乾燥） |
| その他 | 呼吸抑制 | 下痢、徐脈、気道分泌増加 | 尿閉、腸蠕動低下 |

## CBTチェック

- **縮瞳＋呼吸抑制** → オピオイド、拮抗薬はナロキソン。
- **縮瞳＋分泌過多** → 有機リン、アトロピン＋PAM。
- **散瞳＋乾燥＋尿閉** → 抗コリン薬。
- **QRS幅延長を伴う中毒** → 三環系抗うつ薬、炭酸水素ナトリウム。
- 一言暗記：**オピオイドは呼吸抑制、有機リンはびしょびしょ、抗コリン薬はカラカラ**。
