
## 最重要

|作用|効果|
|---|---|
|**α1作用**|血管**収縮**|
|**β1作用**|心収縮力**増強**|
|**β2作用**|血管・気管支**拡張**|

| 薬剤                | 作用         | 使いどころ                      |
| ----------------- | ---------- | -------------------------- |
| **ノルアドレナリン**  | 強いα1、+β1   | [敗血症](../../03_疾患/感染症/敗血症.md)性ショックの第一選択(強力な血管収縮) |
| **アドレナリン**    | α、β両方      | **アナフィラキシーショック・心肺停止**の第一選択 |
| **ドパミン**      | α、β両方      | 低用量:血管拡張/高用量:血管収縮、心収縮力増強   |
| **イソプロテレノール** | β1、β2      | 血管拡張+心収縮力増強                |
| [**β遮断薬**](β遮断薬.md) | β受容体遮断 | 慢性心不全・頻脈性不整脈など |
| **アトロピン**     | 抗コリン(心拍数↑) | [敗血症](../../03_疾患/感染症/敗血症.md)には無効(既に頻脈のため)       |

- 敗血症性ショックは末梢血管拡張が主体 → **α作用の強い薬(ノルアドレナリン)**を選ぶ
