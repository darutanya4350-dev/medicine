# 利尿薬の作用部位

> 利尿薬は腎単位の部位ごとに作用点が異なる。**サイアザイド系は遠位尿細管のNa⁺-Cl⁻共輸送体（NCC）を阻害する。**

## 作用部位と特徴

| 薬効群 | 主な作用部位・標的 | 代表薬・重要な変化 |
| --- | --- | --- |
| 炭酸脱水酵素阻害薬 | 近位尿細管・炭酸脱水酵素 | アセタゾラミド：HCO₃⁻排泄↑、代謝性アシドーシス |
| 浸透圧利尿薬 | 近位尿細管〜ヘンレ係蹄下行脚 | マンニトール：水排泄↑ |
| ループ利尿薬 | ヘンレ係蹄太い上行脚・NKCC2 | フロセミド：Ca²⁺・Mg²⁺排泄↑ |
| サイアザイド系 | **遠位尿細管・NCC** | ヒドロクロロチアジド：Ca²⁺再吸収↑ |
| K保持性利尿薬 | 集合管・アルドステロン受容体/ENaC | スピロノラクトン：高K血症に注意 |

- フロセミドは近位尿細管から分泌された後、ヘンレ係蹄**太い上行脚の管腔側**でNa⁺-K⁺-2Cl⁻共輸送体（**NKCC2**）を阻害し、NaCl再吸収と尿濃縮機構を抑制する。
- 遠位尿細管では、Ca²⁺再吸収が[[副甲状腺ホルモン（PTH）]]と活性型ビタミンDによって調節される。サイアザイド系はCa²⁺再吸収を増やす。
- ループ利尿薬とサイアザイド系はK⁺排泄を増やし、低K血症・代謝性アルカローシスを来しうる。
- **NCC自体はK⁺を輸送しない**。ただし、サイアザイド系によるNCC阻害 → 集合管へ届くNa⁺が増加 → ENaCを介するNa⁺再吸収と管腔の陰性化 → K⁺分泌増加、となる。
- さらに利尿による循環血漿量減少でRAAS・アルドステロンが亢進し、集合管でのNa⁺再吸収とK⁺排泄を促す。したがって**低K血症ではサイアザイド系利尿薬は原則避ける**。
- トルバプタンは集合管のバソプレシンV2受容体を阻害し、水利尿（aquaretic effect）を起こす。Na⁺排泄を主作用としない。
- SGLT2阻害薬は近位尿細管のSGLT2を阻害し、尿糖排泄と浸透圧利尿を増やす。

## CBTチェック

- **サイアザイド系＝遠位尿細管＝NCC阻害＝尿中Ca²⁺低下**。
- **ループ利尿薬＝ヘンレ係蹄太い上行脚＝NKCC2阻害＝尿中Ca²⁺上昇**。
- 「フロセミドで阻害されるNa⁺輸送体」→ **Na⁺-K⁺-2Cl⁻共輸送体（NKCC2）**。
- 「低K血症に投与すべきでない降圧薬」→ **サイアザイド系利尿薬**。
- 集合管に作用する利尿薬はK保持性利尿薬とV2受容体拮抗薬である。
