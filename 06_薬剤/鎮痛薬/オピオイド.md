# オピオイド

> **オピオイド**は、オピオイド受容体に作用して鎮痛作用を示す薬物の総称である。中等度～高度の疼痛、特にがん疼痛や術後の強い疼痛に用いる。

## 作用機序

- 主に中枢神経の**μ（ミュー）オピオイド受容体**を刺激し、痛みの伝達を抑える。
- 鎮痛だけでなく、鎮静、呼吸抑制、縮瞳、消化管運動低下も起こす。

## 代表薬

| 分類 | 代表薬 | ポイント |
|---|---|---|
| **強オピオイド** | モルヒネ、オキシコドン、フェンタニル、ヒドロモルフォン、メサドン | 高度の疼痛に用いる。 |
| **弱オピオイド** | コデイン、トラマドール | 中等度の疼痛などで用いる。 |
| **部分作動薬** | ブプレノルフィン | μ受容体への部分作動薬。 |
| **拮抗薬** | ナロキソン | オピオイドの作用を競合的に拮抗する。過量投与時に用いる。 |

個別薬については[モルヒネ](モルヒネ.md)を参照。

## 主な副作用

- **便秘**：耐性が生じにくく、対策が重要。
- 悪心・嘔吐
- 眠気・鎮静
- **呼吸抑制**
- 縮瞳
- 尿閉
- 依存、耐性、身体依存

## 中毒・過量投与

### 三徴

- **意識障害**
- **呼吸抑制**
- **縮瞳**

### 対応

- 気道確保・呼吸管理を行う。
- **ナロキソン**を投与してオピオイド作用を拮抗する。

## 注意点

- アルコール、ベンゾジアゼピン系薬など中枢神経を抑制する薬との併用では、鎮静・呼吸抑制が強まる。
- 長期使用後の急な中止では、離脱症状（不安、発汗、悪心、下痢など）を生じうる。
- 重篤な呼吸抑制や麻痺性イレウスでは使用を避ける。

## CBTチェック

- オピオイドの代表的副作用 → **便秘・呼吸抑制・縮瞳**
- オピオイド中毒の三徴 → **意識障害・呼吸抑制・縮瞳**
- オピオイド過量投与への拮抗薬 → **ナロキソン**
- 強いがん疼痛の代表的治療薬 → **強オピオイド**
- 経口投与が原則、痛みが消えるまで増量して良い
