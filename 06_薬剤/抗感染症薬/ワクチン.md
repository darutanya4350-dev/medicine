# ワクチン

## 最低限(超要約)

- 接種経路は**皮下注射が基本**、例外を覚える:**経皮=BCG**、**筋肉=HPVワクチン・新型コロナウイルスワクチン**、**経口=[ロタウイルス](../../01_基礎医学/微生物/ウイルス/ロタウイルス.md)ワクチン**
- ワクチンは**生ワクチン**と**不活化ワクチン**に大別される
- **注射生ワクチンから次の注射生ワクチン**までは接種間隔を**27日以上**空ける。それ以外の異なるワクチンの組合せに一律の間隔制限はない（2020年10月〜）。

## 異なるワクチンの接種間隔

| 組合せ | 一律の間隔制限 |
| --- | --- |
| 注射生 → 注射生 | **27日以上必要** |
| 経口生 → 注射生 | 不要 |
| 注射生 → 不活化、または不活化 → 任意のワクチン | 不要 |

- 注射生ワクチンはMR、[[水痘]]、BCG、おたふくかぜなどである。経口生ワクチンである[[ロタウイルス]]ワクチンはこの制限の対象外である。
- 同じワクチンを複数回接種する場合は、製剤ごとに定められた接種間隔を守る。
- 接種間隔の問題では、MRワクチン → 水痘ワクチンのみが「27日以上」に該当する。

## 接種経路のまとめ

| 経路     | 該当ワクチン                                                            |
| ------ | ----------------------------------------------------------------- |
| 皮下(基本) | 風疹ワクチン、麻疹ワクチン、日本脳炎ワクチン、水痘ワクチン、流行性耳下腺炎ワクチンなど多数 |
| 経皮     | **BCG**(結核)                                                   |
| 筋肉     | **HPVワクチン**、**新型コロナウイルスワクチン**                             |
| 経口     | **[ロタウイルス](../../01_基礎医学/微生物/ウイルス/ロタウイルス.md)ワクチン**                                                |

> 覚え方:「経皮はBCGだけ」「筋注はHPVとコロナ」「経口はロタ」、それ以外は皮下と考えてよい

## ワクチンの種類

| 分類      | 特徴                                 | 代表例                                                        |
| ------- | ---------------------------------- | ---------------------------------------------------------- |
| 生ワクチン   | 弱毒化した病原体そのもの、免疫獲得は強いが副反応リスクあり、妊婦禁忌 | BCG、麻疹、風疹、水痘、[ロタウイルス](../../01_基礎医学/微生物/ウイルス/ロタウイルス.md)ワクチン、おたふくかぜ                     |
| 不活化ワクチン | 病原体の一部・不活化したもの、複数回接種が必要なことが多い      | 日本脳炎ワクチン、HPVワクチン、インフルエンザ、新型コロナウイルスワクチン、DPT |
| トキソイド   | 毒素を無毒化                             | 破傷風、ジフテリア                                                  |

## 混合ワクチン

| 名称          | 対象疾患                                                       | 経路  | 分類                 |
| ----------- | ---------------------------------------------------------- | --- | ------------------ |
| DPT     | ジフテリア(D)・[百日咳](../../03_疾患/感染症/百日咳.md)(P)・破傷風(T)                                 | 皮下  | 不活化(トキソイド+不活化菌体成分) |
| DPT-IPV | ジフテリア・[百日咳](../../03_疾患/感染症/百日咳.md)・破傷風・ポリオ(%E4%B8%8D%E6%B4%BB%E5%8C%96,IPV) | 皮下  | 不活化                |

- 定期接種:生後**2ヶ月〜**開始、1期初回3回+1期追加1回(計4回)、その後**DT(二種混合)**として11〜12歳で1回追加
- 現在の定期接種は基本的に**四種混合(DPT-IPV)**が主流(ポリオを個別に打つ必要がなくなった)
- 破傷風トキソイドは効果が減弱するため、外傷時に追加接種を検討することがある
