# 全身性エリテマトーデス（SLE）

> **全身性エリテマトーデス（systemic lupus erythematosus：SLE）**は、自己抗体・免疫複合体により皮膚、関節、腎、血液など多臓器に障害を来す自己免疫疾患。若年女性に多い。

## 要点

- 代表症候は**蝶形紅斑・光線過敏**、無痛性口腔潰瘍、非びらん性多関節炎、漿膜炎、腎炎、神経精神症状、血球減少である。
- 中枢神経病変（[[神経精神ループス]]）では、けいれん、認知機能障害、気分障害、精神病症状などを呈しうる。
- 検査では[[抗核抗体]]陽性、[[抗dsDNA抗体]]・[[抗Sm抗体]]、低補体価が重要である。蛋白尿・細胞性円柱は[[ループス腎炎]]を示唆する。
- 慢性の全身性炎症によって、血中の**フィブリノゲンや免疫グロブリン**が増加します。これらが赤血球同士をくっつけて[[連銭形成]]を起こすと、赤血球が重くまとまって速く沈むため、赤沈が亢進します。
- 活動性SLEでは赤沈亢進に比べてCRPが正常〜軽度上昇にとどまることがある。著明なCRP上昇では感染症などの合併を考える。
- ACR 1997分類では、皮膚粘膜・関節・漿膜・腎・神経・血液・免疫・抗核抗体の**11項目中4項目以上**がCBTの目安である。
- EULAR/ACR 2019分類は**抗核抗体陽性を入口**とし、臨床・免疫所見の加重合計**10点以上**で分類する。いずれも分類基準であり、診断は他疾患の除外を含めて総合的に行う。

## CBTチェック

- 若年女性の光線過敏、蝶形紅斑、無痛性口腔潰瘍、関節症状、白血球減少、蛋白尿 → **SLE**を考える（M3E 18303601・18303602）。
- SLEに特異度が高い自己抗体 → **抗Sm抗体**、病勢・腎炎の評価に有用 → **抗dsDNA抗体・補体価**。
- ACR 1997は**4/11項目**、EULAR/ACR 2019は**ANA陽性 + 10点以上**。
- 発熱・蝶形紅斑・光線過敏に精神症状を伴う → SLEによる[[症状精神病]]（神経精神ループス）を考える。
