# ARDS（急性呼吸窮迫症候群）

> ARDSは、肺胞・毛細血管の炎症と透過性亢進による**非心原性肺水腫**で、急性の低酸素血症と肺コンプライアンス低下をきたす病態である。

## 要点

- 肺血管内皮・肺胞上皮の障害 → 血管透過性亢進 → 蛋白に富む液体が間質・肺胞へ漏出する。
- 肺胞水腫と炎症により、肺サーファクタントが不活化・機能不全となり、肺胞虚脱をきたす。
- 肺胞虚脱・肺の硬化 → 肺コンプライアンス低下、換気血流比不均衡、重症低酸素血症。
- 心不全による肺うっ血（心原性肺水腫）ではなく、肺毛細血管透過性亢進が中心である。
- 原因は[[敗血症]]、肺炎、誤嚥、外傷、大量輸血など。治療では原因治療と肺保護換気を行う。

## CBTチェック

- ARDS → 肺血管透過性亢進、サーファクタント機能不全、肺コンプライアンス低下。
- 「肺サーファクタント増加」「肺コンプライアンス増加」は誤り。
- 非心原性肺水腫であり、心原性肺水腫との鑑別が重要。
