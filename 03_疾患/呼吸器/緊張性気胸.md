# 緊張性気胸

> 胸腔内に入った空気が抜けずに内圧が上昇し、肺と大静脈を圧迫して[[閉塞性ショック]]を来す病態。外傷初療では、呼吸・循環が不安定なら画像検査を待たずに減圧する。

## 要点

- 胸腔内圧上昇 → 患側肺虚脱・縦隔偏位 → 大静脈圧迫による静脈還流低下 → 心拍出量低下・閉塞性ショック、という流れで急速に悪化する。
- 外傷後の呼吸困難、頻呼吸、低酸素血症、血圧低下、**頸静脈怒張**、患側呼吸音減弱をみたら疑う。気管偏位は進行した所見であり、出現を待たない。
- **皮下気腫**は胸部の空気漏れを示す手がかりで、気胸を伴うことがある。ただし皮下気腫だけで緊張性気胸とは診断しない。
- 血行動態不安定または重い呼吸障害がある場合は、胸部X線・CT・超音波のために処置を遅らせず、直ちに胸腔減圧を行う。
- 一時的な減圧後は、再緊張を防ぐため[[胸腔ドレナージ]]で持続的に排気する。心タンポナーデも重要な鑑別で、必要に応じて超音波で評価する。

## CBTチェック

- **外傷 + 呼吸障害 + 低血圧 + 頸静脈怒張** → 緊張性気胸または[[心タンポナーデ]]を考える。
- 緊張性気胸は、画像所見ではなく**臨床診断で緊急減圧する病態**である。
- 治療の原則 → **直ちに胸腔減圧、その後に胸腔ドレナージ**。
