# 先天性食道閉鎖症

> **先天性食道閉鎖症**は、食道が連続せず、しばしば[[気管食道瘻]]を伴う先天異常である。出生直後の泡沫状流涎・哺乳時チアノーゼと、胃管のcoil-up signが重要である。

## 要点

- Gross分類では、上部食道が盲端で下部食道が気管と交通する**C型**が最多（約85〜90%）である。

| Gross型 | 食道閉鎖 | 気管食道瘻・腹部ガス |
|---|---|---|
| A型 | あり | 瘻なし・腹部ガスなし |
| B型 | あり | 上部食道側の瘻・腹部ガスなし |
| C型 | あり | 下部食道側の瘻・腹部ガスあり |
| D型 | あり | 上下の瘻・腹部ガスあり |
| E型（H型） | なし | 瘻のみ・腹部ガスあり |

- 出生直後から泡沫状流涎、哺乳時の咳嗽・チアノーゼ、呼吸障害を認める。経鼻胃管が盲端で反転する**coil-up sign**が診断の手がかりである。
- C型では瘻を介して空気が胃腸管へ入り、腹部X線で胃・腸管ガスを認める。A型・B型では腹部ガスを認めない。
- 経口摂取を中止し、上部食道盲端の持続吸引と呼吸管理を行ったうえで、瘻孔閉鎖・食道吻合術を行う。[[VACTERL連合]]などの合併奇形も評価する。

## CBTチェック

- 泡沫状流涎、哺乳時チアノーゼ、胃管挿入不能では先天性食道閉鎖症を疑う。
- **coil-up sign＋腹部消化管ガスあり**はGross C型を示唆する。
- E型は食道閉鎖を伴わないH型気管食道瘻である。
