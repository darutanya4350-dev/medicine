# Eisenmenger症候群

> [[心室中隔欠損症]]・[[心房中隔欠損症]]・[[動脈管開存症]]などの左→右短絡が長期に持続し、[[肺高血圧症]]の進行によって右→左短絡へ逆転した病態である。チアノーゼと右心負荷を来す。

## 要点

- 左→右短絡 → 肺血流増加 → 肺血管閉塞性病変・肺高血圧 → 右→左短絡への逆転、という経過をたどる。
- 右→左短絡によりチアノーゼ、[[ばち状指]]、二次性多血症を認める。食後は血管拡張で体血管抵抗が下がり、右→左短絡が増えてチアノーゼが目立つことがある。
- 胸部X線で肺動脈主幹部の突出、心電図で右室肥大、心エコーで肺動脈拡張や短絡を評価する。確定的な血行動態評価には心臓カテーテル検査を用いる。
- 肺高血圧により右室圧は上昇するが、左室圧上昇は特徴的でない。
- Eisenmenger化後は短絡閉鎖術は原則行わず、専門施設で肺動脈性肺高血圧に対する治療を検討する。

## CBTチェック

- **みられやすい所見**：右→左短絡、肺高血圧、右室肥大。もとの左→右短絡は病歴上の原因として重要である。**左室圧上昇**は選ばない。
- **ばち状指**は慢性低酸素血症を示唆する。[[Raynaud]]症状は膠原病、匙状爪は[[鉄欠乏性貧血]]、スワンネック変形・ボタンホール変形は[[関節リウマチ]]で典型的である。
- **胸部単純CT**は本症例の診断に必須ではない。胸部X線、心電図、心エコー、心臓カテーテル検査は、それぞれ肺血管・右心負荷・構造と短絡・血行動態の評価に役立つ。
