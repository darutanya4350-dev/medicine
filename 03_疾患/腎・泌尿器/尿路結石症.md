# 尿路結石症

> **尿路結石症**は、尿路の結石によって疝痛発作・血尿・尿路閉塞を来す疾患である。急な側腹部〜鼠径部痛と血尿から疑い、CTで部位と閉塞を評価する。

## 要点

- [尿管結石](尿管結石.md)では、突然の間欠的な側腹部痛、血尿、[[肋骨脊椎角叩打痛|CVA叩打痛]]を認める。痛みは鼠径部・陰囊へ放散することがある。
- 診断には非造影CTが有用で、結石の部位・大きさ・水腎症を評価する。超音波検査は水腎症の確認に役立つ。
- カルシウム結石（シュウ酸カルシウム・リン酸カルシウム）は単純X線で写りやすい。尿酸結石・シスチン結石は写りにくいが、CTでは評価できる。
- 尿酸結石は酸性尿・高尿酸血症や痛風を背景とし、リン酸マグネシウムアンモニウム結石は尿素分解菌による感染結石である。
- 発熱・膿尿を伴う尿路閉塞は重症化しうるため、[[急性腎盂腎炎]]の合併を確認する。

| 鑑別・誤答選択肢 | 尿路結石と区別する所見 |
|---|---|
| [[急性腎盂腎炎]] | 発熱、膿尿、全身倦怠感を伴う。CVA叩打痛は両者でみられる。 |
| [[腹膜炎]]・消化管穿孔 | 筋性防御・反跳痛などの腹膜刺激症状を認める。 |
| [[精巣捻転]] | 突然の陰囊痛・陰囊内容腫大が中心で、時間依存性の緊急疾患である。 |
| [[過活動膀胱]] | 尿意切迫感・切迫性尿失禁が中心で、疝痛発作や血尿は典型的でない。 |

## CBTチェック

- **側腹部疝痛＋血尿＋結石既往** → 尿管結石を考える。
- 単純X線で写らない結石＋飲酒歴・高尿酸血症 → 尿酸結石を考える。
- 尿細胞診は[[尿路上皮癌]]、膀胱造影は下部尿路の評価であり、尿管結石の部位診断にはCTを選ぶ。
