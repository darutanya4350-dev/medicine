# 半月体形成性糸球体腎炎

> 糸球体係蹄壁の障害を契機に、ボウマン腔内へ細胞・線維成分が増殖して半月体を形成する糸球体腎炎。半月体は時間経過とともに線維化する。

## 要点

- 半月体の経時変化：**細胞性半月体 → 線維細胞性半月体 → 線維性半月体**。
- 細胞性半月体は初期病変で、細胞成分が主体である。
- 線維細胞性半月体は細胞成分と線維成分が混在する中間段階である。
- 線維性半月体は陳旧性病変で、線維成分が主体となり不可逆性が高い。
- 原因として[[抗糸球体基底膜抗体病（Goodpasture症候群）]]、[[ANCA関連血管炎]]、[[ループス腎炎]]などがある。

## CBTチェック

- 「初期に細胞からなる」→ **細胞性半月体**。
- 「経過とともに線維化」→ **細胞性 → 線維細胞性 → 線維性**。
- 半月体形成＋数週〜数か月で腎機能低下 → [[急速進行性糸球体腎炎]]を考える。
