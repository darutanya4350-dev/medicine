# 原発性糸球体疾患の鑑別

> 糸球体疾患は、**血尿主体か、ネフローゼ型の蛋白尿主体か、急速な腎機能低下を伴うか**で整理する。症候・補体・腎生検所見を組み合わせて絞り込む。

## 鑑別

| 臨床像 | 主な疾患 | CBTでの手がかり |
|---|---|---|
| 急性の血尿・浮腫・高血圧 | [[急性糸球体腎炎]] | 溶連菌感染後に間隔をおく、C3低下、hump |
| 慢性・反復性の血尿 | [[IgA腎症]]、[[Alport症候群]] | IgA腎症は感染と同時期、Alportは難聴・家族歴 |
| ネフローゼ型の高度蛋白尿 | [[微小変化型ネフローゼ症候群]]、[[膜性腎症]]、[[巣状分節性糸球体硬化症]] | 年齢、発症速度、光顕・電子顕微鏡所見 |
| 血尿・蛋白尿から腎機能が急速低下 | [[抗糸球体基底膜抗体病（Goodpasture症候群）]]、[[ANCA関連血管炎]] | 半月体形成、肺胞出血やANCA・抗GBM抗体 |

- 小児の急性ネフローゼで光顕ほぼ正常・足突起癒合 → 微小変化型を考える。
- 中高年の緩徐なネフローゼで基底膜肥厚・spike形成 → 膜性腎症を考える。
- 巣状分節性硬化・ステロイド抵抗性 → 巣状分節性糸球体硬化症を考える。

## CBTチェック

- 血尿に先行感染がある場合、**感染からの時間差**と補体価で急性糸球体腎炎・IgA腎症を区別する。
- 高度蛋白尿＋若年＋光顕異常なし → 微小変化型ネフローゼ症候群。
- 数週〜数か月で腎機能が悪化し半月体形成を認める → 急速進行性糸球体腎炎を考える。
