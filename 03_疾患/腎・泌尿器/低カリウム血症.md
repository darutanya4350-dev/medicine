# 低カリウム血症

> **低カリウム血症**は、血清K濃度の低下により骨格筋・心筋の興奮性が低下し、脱力や不整脈をきたす電解質異常である。

## 要点

- 原因は消化管からの喪失（嘔吐・下痢）、腎からの喪失（利尿薬、アルドステロン過剰）、細胞内移行（インスリン、アルカローシス）が重要である。
- 細胞外K⁺低下 → 静止膜電位がより負になる（過分極）→ 骨格筋が興奮しにくくなる → **筋力低下・脱力・弛緩性麻痺**。
- 心電図ではT波平低化、ST低下、U波増高を認め、重症では不整脈の原因となる。
- 反復する脱力発作と低K血症では、[[周期性四肢麻痺]]、特に[[甲状腺中毒性周期性四肢麻痺]]を考える。

## CBTチェック

- 血清濃度低下で脱力発作 → **カリウム**。
- 低K血症 → U波増高、高K血症 → T波先鋭化・QRS幅増大。
- 問題文の「自己誘発性嘔吐＋下剤・利尿薬乱用＋K 2.3 mEq/L」→低カリウム血症による筋力低下を考える（M3E 18304084）。
