# Fanconi症候群

> 近位尿細管の再吸収が広範に障害される病態で、糖・アミノ酸・リン酸・尿酸・重炭酸などが尿中へ失われる。

## 要点

- 尿所見：血糖が高くないのに糖尿、アミノ酸尿、リン酸尿、低分子蛋白尿を認める。
- 血液所見：リン喪失による低リン血症、尿酸喪失による低尿酸血症、重炭酸喪失による2型（近位型）[[尿細管性アシドーシス]]。
- 原因は遺伝性疾患のほか、薬剤・重金属・多発性骨髄腫などの後天性疾患がある。
- 高リン血症ではなく、リンの尿中喪失による**低リン血症**となる。

## CBTチェック

- 「糖尿＋アミノ酸尿＋低リン血症＋低尿酸血症＋代謝性アシドーシス」→ Fanconi症候群を考える。
- Fanconi症候群でみられないのは **高リン血症**。

## 覚え方

### 近位尿細管は「回収係」

- 近位尿細管は原尿から、**糖・アミノ酸・リン・重炭酸・尿酸・水**を回収する。
- Fanconi症候群ではこの回収機能が広範に障害され、これらが尿中へ漏れる。

### 「FANCONI」で連想するもの

| 頭文字 | 漏れるもの・原因 | 連想する所見 |
|---|---|---|
| **F** | Phosphate（リン） | 低リン血症 → くる病・骨軟化症 |
| **A** | Amino acids（アミノ酸） | アミノ酸尿 |
| **N** | Na⁺・重炭酸 | 近位型（Ⅱ型）[[尿細管性アシドーシス]] |
| **C** | Carbohydrate（糖） | 腎性糖尿 |
| **O** | Osteomalacia（骨軟化症） | リン喪失の結果として起こる |
| **N** | Nephrotoxin（腎毒性物質） | 薬剤・重金属 |
| **I** | Idiopathic／Inherited（特発性・遺伝性） | シスチン症など |
