# 主な腎尿路奇形

> 先天性腎尿路奇形では、尿路感染症の反復、尿のうっ滞・逆流、尿失禁を手掛かりにする。病変の部位と典型的な合併症を結び付けて覚える。

## 主な病態

| 奇形 | 要点 | 代表的な問題 |
|---|---|---|
| [[馬蹄腎]] | 両腎下極が癒合する | 腎盂尿管移行部の通過障害 → 水腎症・尿路結石 |
| [[重複腎盂尿管]] | 腎盂・尿管が重複する | 上腎由来尿管は[[尿管異所開口]]・尿管瘤、下腎由来尿管は[[膀胱尿管逆流症]]を伴いやすい |
| [[尿管異所開口]] | 尿管口が膀胱三角部以外に開口 | 女児で括約筋遠位への開口なら持続性尿失禁 |
| [[水腎症]] | 腎盂・腎杯が拡張する | 小児では[[腎盂尿管移行部狭窄症]]が重要 |
| [[膀胱尿管逆流症]] | 膀胱尿が尿管・腎盂へ逆流する | 反復性[[急性腎盂腎炎]]・腎瘢痕 |

## CBTチェック

- 女児で「正常に排尿できるが常に尿が漏れる」→ [[尿管異所開口]]を考える。
- 小児の反復性有熱性尿路感染症 → [[膀胱尿管逆流症]]を考え、VCUGで評価する。
- [[尿道下裂]]は、外尿道口が陰茎腹側に開口する奇形である。
