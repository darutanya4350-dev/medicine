# 高カリウム血症

> **高カリウム血症**は、血清K濃度上昇により心筋の興奮・伝導に障害をきたし、不整脈や心停止につながりうる電解質異常である。

## 要点

- 原因は腎排泄低下（腎不全、低アルドステロン）、細胞外移行（アシドーシス、組織崩壊）、薬剤（ACE阻害薬、ARB、カリウム保持性利尿薬など）が重要である。
- レニン・アンジオテンシン系抑制薬によって起きる
- ACE阻害薬・ARBはアルドステロン低下を介してK排泄を減らし、高K血症を起こしやすい。一方、サイアザイド系利尿薬はK排泄を増やし、低K血症を起こしうる。
- 心電図は**T波先鋭化（テント状T波）**から始まり、進行するとPR延長、P波平低化・消失、**QRS幅増大**を認める。
- 重症ではQRSとT波が融合するsine wave（正弦波）となり、[[心室細動]]・心停止の危険がある。
- 心電図異常を伴う場合は緊急対応が必要で、カルシウム投与で心筋膜を安定化し、インスリン・ブドウ糖などでKを細胞内へ移動させ、必要により透析で除去する。
- [[グルコース-インスリン療法（GI療法）]]は、インスリンでNa⁺/K⁺-ATPaseを活性化してKを細胞内へ移動させる一時的治療である。血糖低下を防ぐためブドウ糖を併用し、低血糖に注意する。

## CBTチェック

- 高K血症 → **T波先鋭化、QRS幅増大**。
- 低K血症 → T波平低化、U波増高。高K血症と逆に覚える。
- 高K血症ではQT時間は短縮傾向であり、延長ではない。
- 高K血症の治療は、心筋保護（カルシウム）・細胞内移動（GI療法）・体外除去（透析）を区別する。
- 薬剤の連想：ACE阻害薬・ARB・K保持性利尿薬 → 高K、サイアザイド・ループ利尿薬 → 低K。
