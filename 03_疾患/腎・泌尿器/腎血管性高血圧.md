# 腎血管性高血圧

> **腎血管性高血圧**は、腎動脈の狭窄・閉塞による腎血流低下でレニン分泌が亢進し、二次性高血圧を来す病態である。

## 要点

- 腎動脈狭窄 → 腎灌流圧低下 → レニン-アンジオテンシン-アルドステロン系の活性化 → 高血圧となる。
- [傍糸球体装置](../../01_基礎医学/生理/傍糸球体装置.md)から分泌されたレニンはアンジオテンシノーゲンをアンジオテンシンIへ変換し、ACEを介してアンジオテンシンIIが生じる。アンジオテンシンIIの血管収縮とアルドステロンによるNa・水貯留が血圧を上げる。
- 二次性高血圧のうち**高レニン性**の代表である。[[原発性アルドステロン症]]ではアルドステロン高値に対してレニンは低値となる。
- 高齢者では粥状動脈硬化が多く、腎動脈起始部に好発する。
- 若年女性では[[線維筋性異形成]]を考える。腎動脈の中〜遠位部に多く、血管造影で数珠状所見を示す。
- [[高安動脈炎|大動脈炎症候群]]でも腎動脈狭窄を来す。片側腎萎縮や腹部血管雑音は手掛かりとなる。
- 腎ドプラ超音波、CT/MR血管造影などで評価する。治療は薬物療法を基本とし、病態により血行再建を検討する。
- 左右腎静脈レニン活性（PRA）比は、左右差のある腎動脈狭窄で患側腎からのレニン分泌亢進を確認する補助検査となる。

腎動脈造影で片側腎動脈の近位部狭窄を認める。狭窄より末梢の腎灌流低下がレニン分泌を促す。

## CBTチェック

- 腎動脈狭窄では**レニン過剰分泌**による腎血管性高血圧を来す。
- 「若年女性＋数珠状の腎動脈狭窄」は線維筋性異形成を考える。
- 「高齢男性＋腎動脈起始部の狭窄」は粥状動脈硬化を考える。
- 「左右腎静脈PRA比」→ 腎血管性高血圧症の補助診断を考える。
- 「患側腎静脈血のレニン活性上昇」→ 腎動脈狭窄による腎血管性高血圧を考える。
- 腎動脈狭窄が長期化すると、患側腎は虚血により萎縮しやすい。
- 高血圧＋低K血症で、**レニン・アルドステロンともに高値**、腹部血管雑音、片側腎萎縮を認めたら腎動脈狭窄を考える。[[原発性アルドステロン症]]はレニン低値・アルドステロン高値である。
- 問題文の「若年発症の重症高血圧＋腹部血管雑音」→腎血管性高血圧を考える（M3E 18303972）。
- 問題文の「レニン・アルドステロンともに高値」→続発性アルドステロン症を考え、腹部血管雑音があれば腎動脈狭窄を疑う（M3E 18303973–18303974）。
- [[クッシング症候群]]ではコルチゾール過剰を示す身体所見・検査異常を確認する。腹部血管雑音や腎萎縮は腎血管性高血圧を支持する。
