# 急性胆管炎

> **急性胆管炎**は、[総胆管結石](総胆管結石.md)などによる胆道閉塞に細菌感染が加わる疾患である。重症化すると[敗血症性ショック](../感染症/敗血症性ショック.md)をきたすため、緊急の胆道ドレナージを要する。

## 要点

- 主な原因は総胆管結石であり、悪性腫瘍や胆道ステント閉塞も原因となる。
- **Charcot 3徴**は、発熱・右上腹部痛・黄疸である。
- **Reynolds 5徴**はCharcot 3徴にショックと意識障害を加えたもので、重症例を示唆する。
- 急性閉塞性化膿性胆管炎では、敗血症によるショック・意識障害・DICを合併しうる。[門脈圧亢進](門脈圧亢進.md)は典型的ではない。
- 血液検査では炎症反応上昇と胆道系酵素・ビリルビン上昇を認め、画像で胆管拡張や結石を確認する。
- 抗菌薬投与に加え、重症例や閉塞が持続する場合はERCPによる胆道ドレナージを行う。

## CBTチェック

- 発熱 + 腹痛 + 黄疸 → 急性胆管炎（Charcot 3徴）。
- 胆管炎での血圧低下は、まず敗血症性ショックを考える。貧血がなければ出血性ショックは考えにくい。
- 重症胆管炎で起こりにくい所見 → 門脈圧亢進。 胆道系の異常で門脈圧には影響しないことが多い
- 総胆管結石 + 黄疸では、閉塞性黄疸を考える。
