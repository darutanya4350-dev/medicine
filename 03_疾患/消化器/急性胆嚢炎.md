# 急性胆嚢炎

> **急性胆嚢炎**は、主に胆嚢管の結石嵌頓に続いて胆嚢に炎症が起こる疾患である。脂肪食後の右上腹部痛や右肩への放散痛は典型的だが、確定には炎症所見と画像所見を組み合わせる。

## 要点

- 典型症状は持続する右季肋部痛（または心窩部痛）、発熱、悪心・嘔吐。胆嚢周囲の炎症が横隔膜を刺激し、右肩へ関連痛を生じることがある。
- 右季肋部を圧迫しながら吸気すると痛みで吸気が止まる **Murphy徴候** が重要な局所所見である。
- 血液検査では白血球増多・CRP上昇を認める。総胆管結石を伴わなければ、黄疸や胆道系酵素上昇は目立たないことが多い。
- 腹部超音波検査で胆石、胆嚢腫大、胆嚢壁肥厚、胆嚢周囲液体貯留などを確認する。超音波が第一選択である。
- 初期治療は絶食、輸液、鎮痛、抗菌薬。全身状態と重症度を評価し、適応があれば早期腹腔鏡下胆嚢摘出術を行う。

## CBTチェック

- 脂肪食後の右上腹部痛＋右肩への放散痛 → 胆石による胆嚢疾患を考える。発熱・持続痛・Murphy徴候が加われば急性胆嚢炎を疑う。
- 一過性の疝痛で炎症所見が乏しい → 胆石発作（胆道疝痛）。持続痛・発熱・炎症反応上昇 → 急性胆嚢炎。
- 発熱＋右上腹部痛＋黄疸 → [[急性胆管炎]]（Charcot 3徴）を考える。
