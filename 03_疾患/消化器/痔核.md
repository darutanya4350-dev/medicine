# 痔核

> **痔核**は、肛門管の[[肛門クッション]]がうっ血・滑脱して、出血や脱出を生じる病態である。歯状線を境に内痔核と外痔核に分ける。

## 要点

|  | 内痔核 | 外痔核 |
|---|---|---|
| 発生部位 | 歯状線より口側 | 歯状線より肛門側 |
| 主な症状 | 無痛性の鮮血便・脱出 | 疼痛、腫脹 |

- 内痔核は3時・7時・11時方向に好発し、進行すると脱出する。
- 排便時の怒責、便秘、長時間の座位などが誘因となる。
- 出血を痔核だけと決めつけず、[[大腸癌]]なども鑑別する。

## CBTチェック

- 無痛性の鮮血便と脱出は内痔核、強い疼痛は外痔核や裂肛を考える。
- 内痔核は歯状線より口側にあるため、通常は痛みが少ない。
