# 早期胃癌の肉眼分類

> **早期胃癌**は、リンパ節転移の有無にかかわらず癌の深達度が粘膜下層までの胃癌である。肉眼型は0型（表在型）に分類する。

胃壁の深達度は、粘膜（M）→粘膜下層（SM）→固有筋層（MP）→漿膜下層（SS）→漿膜（S）の順に深くなる。M・SM癌が早期胃癌、MP以深が進行胃癌である。

## 要点

| 型 | 名称 | 所見 |
|---|---|---|
| 0-I | 隆起型 | 明らかな隆起 |
| 0-IIa | 表面隆起型 | 軽度の隆起 |
| 0-IIb | 表面平坦型 | 平坦 |
| 0-IIc | 表面陥凹型 | 浅い陥凹 |
| 0-III | 陥凹型 | 深い陥凹 |

胃癌の肉眼分類。0型は早期胃癌、1〜4型は進行胃癌に用いる。

- 進行胃癌の1〜4型は[[進行胃癌の肉眼分類]]を参照する。
- 内視鏡的粘膜下層剝離術（ESD）は、リンパ節転移リスクが低い早期胃癌に対する内視鏡治療である。CBTでは、粘膜固有層にとどまる分化型癌を基本適応として押さえる（実際の適応は大きさ・潰瘍所見なども含めて判定する）。

## CBTチェック

- **0-IIc = 表面陥凹型早期胃癌**。
- 0-IIaは表面隆起型、0-IIbは表面平坦型、0-IIIは陥凹型。
