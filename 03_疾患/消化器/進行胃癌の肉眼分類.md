# 進行胃癌の肉眼分類

> 進行胃癌は肉眼形態で1〜5型に分類する。**4型（びまん浸潤型）**は明らかな腫瘤や潰瘍をつくらず、胃壁を広範に肥厚・硬化させる。

## 要点

| 型 | 名称 | 肉眼所見 |
|---|---|---|
| 1型 | 腫瘤型 | 境界明瞭な隆起性腫瘤 |
| 2型 | 潰瘍限局型 | 周堤を伴う、境界明瞭な潰瘍 |
| 3型 | 潰瘍浸潤型 | 潰瘍の周囲へ浸潤し、境界が不明瞭 |
| 4型 | びまん浸潤型 | 広範な胃壁肥厚・硬化（linitis plastica） |
| 5型 | 分類不能型 | 1〜4型に分類できない |

- 0型は[[早期胃癌の肉眼分類]]（表在型）に用いる分類である。
- 4型では腹膜播種の頻度が高く、進行度評価が重要である。
- 治療の基本は[[胃癌]]を参照する。

## CBTチェック

- 明らかな腫瘤・潰瘍がなく、胃壁が広く肥厚 → **4型**。
- 腫瘤を形成する進行胃癌 → 1型。
- 潰瘍の境界が明瞭 → 2型、周囲に浸潤して不明瞭 → 3型。
