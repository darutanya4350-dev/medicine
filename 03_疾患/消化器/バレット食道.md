# バレット食道

> **バレット食道**は、胃から連続する円柱上皮（バレット粘膜）が食道下部に存在する状態である。慢性的な[[胃食道逆流症]]と関連し、食道腺癌の発生母地となりうる。

## 要点

- 反復する胃酸逆流 → 食道粘膜傷害 → 扁平上皮から円柱上皮への置換という流れで生じる。
- 内視鏡で食道胃接合部付近のバレット粘膜を確認する。
- 本邦では、胃から連続して食道へ伸びる円柱上皮の存在で定義する。
- 長いバレット食道では食道腺癌のリスクに注意する。
- 正常食道の重層扁平上皮が、胃酸逆流への修復過程で円柱上皮へ置換される（化生）。
- アカラシアでは蠕動消失を認めるが、粘膜は重層扁平上皮のままである。

## CBTチェック

- [逆流性食道炎](逆流性食道炎.md)を反復し、食道下部が円柱上皮化 → **バレット食道**。
- バレット食道と関連する癌 → **食道腺癌**。
- 問題文の「食道上皮の円柱上皮化生」→ バレット食道。癌の発生母地となる（M3E 18204270）。
