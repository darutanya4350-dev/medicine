# C型肝炎

> **C型肝炎**はC型肝炎ウイルス（hepatitis C virus：HCV）による肝炎である。HCVは1本鎖RNAウイルスで、慢性化しやすい。

## 要点

- 主な[感染経路](../../01_基礎医学/微生物/総論/感染経路.md)は血液を介する感染である。
- 急性感染後もHCV-RNA陽性が持続すると[慢性肝炎](慢性肝炎.md)へ進展し、肝硬変・[[肝細胞癌]]の原因となる。
- HCV抗体検査はスクリーニングであり、抗体陽性は感染既往を含む。現在のHCV感染の確定には核酸増幅法によるHCV-RNA検査を用いる。
- 直接作用型抗ウイルス薬（DAA）によりウイルス排除を目指す。
- 腎外病変として、クリオグロブリン血症を介した[膜性増殖性糸球体腎炎](../腎・泌尿器/原発性糸球体疾患の鑑別.md)をきたすことがある。
- 現在はIFNフリーDAA治療が中心である。過去のインターフェロン療法では、[[うつ病]]などの精神症状が重要な副作用だった。
- 国内で承認された予防ワクチンはない。

## CBTチェック

- C型肝炎ウイルスはRNAウイルス。
- C型肝炎は[母子感染](../../01_基礎医学/微生物/総論/母子感染.md)が主ではなく、成人初感染でも慢性化しうる。
- HCV抗体は中和抗体ではない。
- C型肝炎の確定診断：HCV-RNA検査。
- インターフェロン療法の精神障害：うつ病。
- C型肝炎＋[[膜性増殖性糸球体腎炎]] → クリオグロブリン血症関連腎炎を考える。
