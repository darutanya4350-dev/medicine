# 胃癌の転移様式

> [[胃癌]]はリンパ行性・血行性・播種性に転移する。左鎖骨上窩リンパ節、卵巣、Douglas窩、臍はCBTで問われやすい転移先である。

## 要点

- **リンパ行性転移**：腹腔内から胸管を経て左鎖骨上窩リンパ節へ至るものが[[Virchow転移]]である。リンパ節転移だが、臨床的には遠隔転移として扱う。
- **血行性転移**：門脈を経る[[肝転移]]が代表的で、[[肺転移]]も起こる。
- **播種性転移**：漿膜を越えた癌細胞が腹腔内に散布され、[[腹膜播種]]・癌性腹膜炎・腹水を生じる。女性ではDouglas窩、男性では直腸膀胱窩への転移を[[Schnitzler転移]]という。
- **卵巣転移**：[[Krukenberg腫瘍]]は胃癌など消化器癌の卵巣転移で、両側性が多い。
- **臍転移**：腹腔内癌が臍に播種して結節をつくるものを[[Sister Mary Joseph結節]]という。

## CBTチェック

- 胃癌 + 左鎖骨上窩リンパ節腫大 → [[Virchow転移]]を考える。
- 胃癌 + 両側卵巣腫大 → [[Krukenberg腫瘍]]を考える。
- 胃癌 + Douglas窩腫瘤 → [[Schnitzler転移]]を考える。
- 胃癌 + 臍の硬い結節 → [[Sister Mary Joseph結節]]を考える。
