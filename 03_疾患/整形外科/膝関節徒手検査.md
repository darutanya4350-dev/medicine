# 膝関節徒手検査

> 膝の徒手検査は、前十字靱帯（ACL）、側副靱帯、半月板など、疑う損傷に対応させて覚える。

## 要点

| 検査 | 主にみる損傷 | 手技の要点 |
| --- | --- | --- |
| Lachmanテスト | ACL | 膝20〜30°屈曲位で脛骨を前方へ引く |
| 前方引き出しテスト | ACL | 膝90°屈曲位で脛骨を前方へ引く |
| pivot-shiftテスト | ACL | 下腿内旋＋外反ストレスを加えながら屈曲・伸展させる |
| 外反ストレステスト | 内側側副靱帯（MCL） | 膝に外反ストレスを加える |
| McMurrayテスト | 半月板 | 回旋・屈伸で関節裂隙の疼痛やクリックを誘発する |

- ACL損傷ではLachmanテストが前方引き出しテストより鋭敏で、急性期は疼痛や筋緊張で前方引き出しが行いにくいことがある。
- 内側側副靱帯は外反ストレス、外側側副靱帯は内反ストレスで評価する。

## CBTチェック

- 問題文の「Lachman・pivot-shift・前方引き出し」→ ACL損傷。
- 「McMurray」→ 半月板損傷。
- 「外反ストレス」→ MCL損傷。「内反ストレス」→ 外側側副靱帯損傷。
