# 双極症（双極性障害）

> **双極症（双極性障害）**は、躁状態または軽躁状態とうつ状態を繰り返す気分障害である。躁状態の有無を確認することが、単極性の[[うつ病]]との鑑別に重要である。

## 要点

|  | 躁状態 | うつ状態 |
|---|---|---|
| 気分 | 高揚・爽快、または易刺激性 | 抑うつ、興味・喜びの低下 |
| 思考 | 観念奔逸、誇大妄想 | 思考制止、微小妄想・自殺念慮 |
| 行動・意欲 | 行為心迫、活動性亢進、浪費など | 制止〜抑うつ性昏迷、意欲低下 |
| 睡眠 | 睡眠欲求が少なく、眠らず活動する | 早朝覚醒などの不眠、または過眠 |

- 双極Ⅰ型は躁状態、双極Ⅱ型は軽躁状態とうつ状態を示す。
- 躁状態では、睡眠時間が短くても疲れず、口数が増え、怒りっぽくなることがある。
- うつ状態だけでは[[うつ病]]と区別しにくいため、過去の躁・軽躁エピソードを必ず確認する。

## CBTチェック

- 「眠らずに活動」「観念奔逸」「誇大妄想」→ 躁状態を考える。
- 「早朝覚醒」「思考制止」「抑うつ気分」→ うつ状態を考える。
- うつ状態の患者に過去の躁・軽躁状態がある → [[うつ病]]ではなく双極症を考える。
