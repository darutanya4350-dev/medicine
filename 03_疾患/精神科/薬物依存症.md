# 薬物依存症

> **薬物依存症**は、薬物をやめたくても強い欲求や使用の制御困難が生じ、反復使用が続く状態である。CBTでは、身体依存と精神依存を分けて整理する。

## 要点

|  | 身体依存 | 精神依存 |
|---|---|---|
| 中心所見 | 中断・減量で離脱症状 | 強い欲求、使用をやめられない |
| CBTの典型薬物 | モルヒネ、ヘロイン、アルコール、バルビツール酸系 | コカイン、アンフェタミンなどの覚醒剤 |
| 関連事項 | 耐性を伴うことがある | 再使用・再発につながりやすい |

- **モルヒネ**は身体依存・精神依存のいずれも起こしうる。
- コカイン・アンフェタミンは、CBTでは精神依存が強く身体依存は基本的にないと整理する。
- LSD-25は幻覚剤で、身体依存は基本的にない。大麻の依存性は比較的弱いが、使用障害が起こりうるため「依存がない」と断定しない。
- シンナーは覚醒剤ではなく、有機溶剤に分類される。覚醒剤はアンフェタミン・メタンフェタミンが代表である。
- 覚醒剤では、反復使用により少量でも幻覚・妄想などが出やすくなる[[逆耐性現象]]を認める。

## CBTチェック

- 「身体依存がみられる薬物」→ [[モルヒネ]]、ヘロイン、アルコール、バルビツール酸系を考える。
- 「中断後の発汗・振戦・下痢・嘔吐など」→ 身体依存による離脱症状を考える。
- 「薬物を強く欲し、使用を制御できない」→ 精神依存を考える。
- 「逆耐性現象」→ [[覚醒剤精神病]]を考える。
- 「シンナー」→ 有機溶剤、「モルヒネ・ヘロイン」→ アヘン類、「抗不安薬」→ 向精神薬依存を考える。
