# 重症筋無力症

> **重症筋無力症**は、神経筋接合部の自己免疫性障害により、眼瞼下垂・複視や四肢筋の易疲労性を来す疾患である。反復・持続で悪化し、休息で改善する変動性が最も重要である。

## 鑑別の要点

| 疾患 | 重症筋無力症との違い |
| --- | --- |
| [[ランバート・イートン筋無力症候群]] | 下肢近位筋優位、腱反射低下・自律神経症状を伴い、反復運動で筋力・腱反射が改善する |
| [[ギラン・バレー症候群]] | 急性に進行する対称性筋力低下と腱反射低下が中心で、休息による回復・日内変動はない |
| [[周期性四肢麻痺]] | 発作性の四肢麻痺で、発作時の血清K異常が手掛かり。眼瞼下垂・複視は典型でない |
| [[筋萎縮性側索硬化症]] | 進行性の筋萎縮・線維束性収縮と錐体路徴候を示し、易疲労性や眼症状は典型でない |

- 抗アセチルコリン受容体抗体または抗MuSK抗体を確認し、反復刺激試験では漸減現象（waning）を認める。
- 胸腺腫を合併しうるため、胸部画像で評価する。
- 眼瞼下垂・複視などの外眼筋症状から始まりやすく、感覚障害や腱反射低下は通常みられない。
- 神経筋接合部での[[アセチルコリン]]受容体機能障害が本態であり、テンシロン（エドロホニウム）試験で一過性に症状が改善する。

## CBTチェック

- **眼瞼下垂・複視＋休息で改善する筋力低下＋夕方に増悪**なら重症筋無力症を選ぶ。
- 眼症状・頸部屈筋・四肢近位筋を優先してみる。手袋靴下型の感覚障害は重症筋無力症らしくない。
- 多発性筋炎や糖尿病性多発ニューロパチーは慢性の筋力低下・感覚障害を来しうるが、休息での明らかな改善は示さない。
- 嚥下障害・呼吸筋力低下を伴うときは、[[重症筋無力症クリーゼ]]を疑う。
