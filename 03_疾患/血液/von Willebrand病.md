# von Willebrand病

> von Willebrand病（von Willebrand disease：VWD）は、von Willebrand因子（vWF）の量的欠乏または質的異常による遺伝性出血性疾患である。

## 要点

- vWFは、傷害血管壁のコラーゲンと血小板を結びつけて[[血小板粘着]]を促す。
- vWFは[[凝固第VIII因子]]のキャリア蛋白として、第VIII因子を血中で安定化する。
- [[鼻出血]]、紫斑、過多月経などの[[粘膜・皮膚出血]]が中心で、男女ともに発症する。
- 血小板数と[[出血時間・PT・APTTの比較|PT]]は正常、出血時間は延長する。第VIII因子活性の低下により[[出血時間・PT・APTTの比較|APTT]]は延長することがある。
- 軽症例にはvWFを放出させる[[デスモプレシン]]（DDAVP）、無効・不適切な病型や重い出血にはvWF含有第VIII因子製剤などを用いる。

## CBTチェック

- vWFの役割は「[[血小板粘着]]」と「[[凝固第VIII因子]]の安定化」の2つである。
- [[血小板凝集]]では、血小板同士をつなぐ[[フィブリノゲン]]が重要である。
- [[血友病|血友病A]]は関節内・筋肉内出血が中心で出血時間は正常だが、VWDは粘膜出血が中心で出血時間が延長する。定期補充療法は重症例に限られる。
- 歯肉出血を含む粘膜出血の鑑別は[[歯肉出血]]を参照する。
