# 悪性リンパ腫の代表的染色体転座

> CBTでは、非Hodgkinリンパ腫の代表的な「疾患・転座・遺伝子」の組合せを覚える。

## 要点

| 疾患 | 染色体転座 | 主な結果 |
|---|---|---|
| [[Burkittリンパ腫]] | t(8;14) | [[MYC]]過剰発現 |
| [[濾胞性リンパ腫]] | t(14;18) | [[BCL2]]過剰発現 → アポトーシス抑制 |
| [[マントル細胞リンパ腫]] | t(11;14) | [[CCND1]]過剰発現 → cyclin D1増加 |

## CBTチェック

- 8番染色体のMYC → t(8;14) → Burkittリンパ腫。
- 18番染色体のBCL2 → t(14;18) → 濾胞性リンパ腫。
- 11番染色体のCCND1 → t(11;14) → マントル細胞リンパ腫。
