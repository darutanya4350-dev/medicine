# 発作性夜間ヘモグロビン尿症

> 発作性夜間ヘモグロビン尿症（paroxysmal nocturnal hemoglobinuria：PNH）は、造血幹細胞の後天的な[[PIGA遺伝子]]変異により、補体介在性の[[血管内溶血]]をきたす疾患である。

## 要点

- [[GPIアンカー蛋白]]が欠損し、補体制御蛋白である[[CD55]]・[[CD59]]を血球表面に発現できなくなる。
- 赤血球が補体に破壊され、貧血、黄疸、早朝の暗褐色尿（[[ヘモグロビン尿]]）を生じる。
- 溶血所見は[[LD]]上昇、[[間接ビリルビン]]上昇、[[ハプトグロビン]]低下、[[網赤血球]]増加である。
- 自己抗体による溶血ではないため、[[Coombs試験|直接Coombs試験]]は陰性となる。診断にはフローサイトメトリーでCD55・CD59欠損血球を検出する。
- [[血栓症]]と[[骨髄不全]]が重要で、[[再生不良性貧血]]との合併・相互移行がある。治療には補体C5阻害薬の[[エクリズマブ]]などを用いる。

## CBTチェック

- [[PIGA遺伝子]]変異 → [[GPIアンカー蛋白]]欠損 → [[CD55]]・[[CD59]]欠損 → 補体による[[血管内溶血]]。
- PNHの組合せは「LD・[[間接ビリルビン]]上昇、ハプトグロビン低下、[[Coombs試験|直接Coombs試験]]陰性」である。
- 主要病態は[[血管内溶血]]、[[血栓症]]、[[骨髄不全]]の3つである。
