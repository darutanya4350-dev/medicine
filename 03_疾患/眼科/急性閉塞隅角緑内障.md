# 急性閉塞隅角緑内障

> **急性閉塞隅角緑内障**は、狭い隅角が急に閉塞して房水流出が妨げられ、眼圧が急上昇する眼科救急疾患である。典型的な機序は**瞳孔ブロック**である。

## 要点

- 眼痛、視力低下・霧視、光源の周囲に輪が見える虹視、充血、頭痛、悪心・嘔吐を急に来す。
- 角膜浮腫、毛様充血、**浅前房**、縦長の中等度散瞳、著明な[[眼圧]]上昇が典型である。
- 瞳孔ブロック → 後房圧上昇 → 虹彩が前方へ押される → 隅角閉塞 → 眼圧上昇、の順に進む。
- 暗所や散瞳作用のある薬剤で誘発されうる。狭隅角では[抗コリン薬](../../06_薬剤/自律神経・循環/ムスカリン受容体遮断薬.md)や市販の総合感冒薬を含む薬剤歴を確認する。
- 緊急に薬物で眼圧を下降させ、瞳孔ブロックを解除するレーザー虹彩切開術を行う。反対眼も発作リスクを評価する。

関連：[[頭痛の鑑別]]、[眼症状と開放隅角緑内障との鑑別](../../02_症候・診察/眼症状の鑑別.md)

## CBTチェック

- 眼痛・頭痛・嘔吐＋虹視＋浅前房・中等度散瞳・角膜浮腫 → 急性閉塞隅角緑内障。
- 散瞳により閉塞を悪化させるため、急性発作中に**散瞳眼底検査を行わない**。
- 閉塞隅角の典型機序は**瞳孔ブロック**。線維柱帯流出路抵抗の増大は[[開放隅角緑内障]]で重要である。
