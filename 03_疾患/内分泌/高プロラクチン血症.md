# 高プロラクチン血症

> **高プロラクチン血症**は、血中プロラクチン（PRL）が上昇した状態である。女性では[[無月経]]・乳汁漏出・不妊を来す。

## 要点

- PRL上昇 → 視床下部のGnRH分泌抑制 → LH・FSH低下、LHサージ抑制 → 排卵障害 → 無月経となる。
- 主な原因は、薬剤性（抗精神病薬・制吐薬など）、[[プロラクチノーマ]]、原発性[[甲状腺機能低下症]]、妊娠・授乳である。
- 月経異常または乳汁漏出ではPRLを測定し、妊娠、服薬、甲状腺機能を確認する。頭痛・視野障害や持続的高値では下垂体MRIを考慮する。
- 治療は原因への対応である。薬剤性では可能なら減量・変更、プロラクチノーマではドパミン作動薬を用いる。

## CBTチェック

- 「無月経＋乳汁漏出」は高プロラクチン血症を疑う。
- 高PRL血症は低ゴナドトロピン性の排卵障害を来す。
