# クッシング症候群

> [[副腎の層と分泌ホルモン|コルチゾール]]が慢性的に過剰となる病態。医原性のほか、ACTH依存性とACTH非依存性に分ける。

## 要点

- 脂肪再分布 → 中心性肥満、満月様顔貌、水牛様脂肪沈着を来す。
- 蛋白異化 → 赤紫色皮膚線条、皮膚菲薄化、近位筋力低下、[[骨粗鬆症]]を来す。
- 糖新生と[[インスリン抵抗性]]の亢進 → [[糖尿病]]、鉱質コルチコイド様作用 → [[高血圧症]]・[[低カリウム血症]]を来す。
- スクリーニングは尿中遊離コルチゾール、深夜コルチゾール、少量デキサメタゾン抑制試験を用いる。
- 高コルチゾール血症の確認後、血中ACTHでACTH依存性か非依存性かを分ける。
- コルチゾール過剰では好中球増多による白血球増多と、早朝高値・夜間低値の日内変動消失を認める。

## CBTチェック

- [[クッシング病]]は[[下垂体腺腫]]によるACTH過剰であり、クッシング症候群の一病型である。
- ACTH高値 → 下垂体性・異所性ACTH産生、ACTH低値 → 副腎腫瘍などを考える。
- 赤紫色皮膚線条＋近位筋力低下＋中心性肥満 → クッシング症候群を考える。
- Cushing病では高用量デキサメタゾンでコルチゾールが抑制されやすく、CRH試験ではACTH・コルチゾールが増加する。
