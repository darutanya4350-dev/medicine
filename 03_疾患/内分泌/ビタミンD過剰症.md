# ビタミンD過剰症

> **ビタミンD過剰症**は、ビタミンD製剤・サプリメントの過量摂取などにより腸管からのCa吸収が過剰となり、[[高カルシウム血症]]を来す病態。骨粗鬆症治療中の高齢者では服薬状況も確認する。

## 要点

- ビタミンD作用増強 → 腸管Ca吸収増加 → 高Ca血症・高Ca尿症 → PTH分泌抑制を来す。
- 悪心、食欲低下、便秘などの腹部症状に加え、倦怠感、筋力低下、認知機能変化、多尿、口渇、脱水を認める。重症例では腎障害・不整脈を来しうる。
- 骨粗鬆症治療薬、サプリメント、Ca製剤の重複や過量摂取を確認する。認知機能低下は服薬過量のリスクとなる。
- 検査では高Ca血症とPTH低値を認める。サプリメントによる過剰摂取では25-ヒドロキシビタミンD高値を伴うことが多い。
- 治療は原因製剤の中止と輸液による脱水補正を基本とし、重症度に応じて高Ca血症への治療を行う。

## CBTチェック

- 骨粗鬆症治療中＋高Ca血症＋PTH低値 → ビタミンD過剰症などの**PTH非依存性高Ca血症**を考える。
- [[原発性副甲状腺機能亢進症]]では高Ca血症にもかかわらずPTHが抑制されない。
- ビタミンD欠乏では低Ca血症や骨軟化症を考え、過剰症とは逆に整理する。
