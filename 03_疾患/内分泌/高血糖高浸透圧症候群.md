# 高血糖高浸透圧症候群

> **高血糖高浸透圧症候群（hyperglycemic hyperosmolar state：HHS）**は、著しい高血糖による浸透圧利尿で高度の脱水・高浸透圧血症を来す[糖尿病の急性合併症](糖尿病の急性合併症.md)。高齢の2型糖尿病患者に多く、著明なケトアシドーシスは通常みられない。

## 要点

- インスリン作用の不足 → 高血糖 → 浸透圧利尿 → 脱水・高浸透圧血症 → [[意識障害]]を来す。少量のインスリン作用が残るため、[[糖尿病性ケトアシドーシス]]よりケトーシスは軽い。
- 高齢の2型糖尿病、感染症・脳血管障害、飲水不足、利尿薬・副腎皮質ステロイド薬などが誘因となる。
- 口渇、多飲、多尿、体重減少、全身倦怠感、皮膚緊張低下、頻脈、意識障害を認める。高齢者では口渇が目立たないことがある。
- 検査では著しい高血糖、高浸透圧血症、脱水に伴う腎機能低下を認める。ケトン体上昇と代謝性アシドーシスは顕著でない。
- 治療は入院下での輸液による脱水補正を最優先とし、カリウムなどの電解質を確認しながらインスリン投与と誘因の治療を行う。

## CBTチェック

- 高齢の糖尿病患者＋利尿薬＋皮膚緊張低下・強い倦怠感 → HHSを考える。
- HHSは高度の脱水・高浸透圧血症が中心、[[糖尿病性ケトアシドーシス]]はケトーシス・代謝性アシドーシスが中心である。
- 脱水を伴う高血糖では、感染症などの誘因も検索する。
