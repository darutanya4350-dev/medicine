# 副甲状腺機能低下症

> **副甲状腺機能低下症**はPTH作用の不足により、低Ca血症と高P血症をきたす病態である。PTH分泌低下による特発性・続発性と、PTHが効かない偽性副甲状腺機能低下症がある。

## 要点

- 低Ca血症により神経・筋の興奮性が高まり、[[テタニー]]、しびれ、筋痙攣をきたす。
- PTH低下または作用不全 → 腎でリン排泄低下 → 高P血症となる。
- 血中Caが少なくても、リンが多いとCa×Pの積が上昇し、リン酸Caが軟部組織や大脳基底核に沈着することがある。
- 偽性副甲状腺機能低下症ではPTHは高値だが、標的臓器のPTH抵抗性により低Ca・高Pとなる。

## CBTチェック

- 低Ca＋高P＋テタニー → 副甲状腺機能低下症または偽性副甲状腺機能低下症を考える。
- 低Caなのに石灰化 → 高P血症によるCa×P積上昇を考える。
- 低Ca＋高P＋PTH低値＋大脳基底核石灰化 → 副甲状腺機能低下症を考える。
