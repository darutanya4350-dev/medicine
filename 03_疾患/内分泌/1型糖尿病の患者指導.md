# 1型糖尿病の患者指導

> 1型糖尿病はインスリン分泌が絶対的に欠乏するため、患者自身が血糖管理・低血糖対応・シックデイ対応を習得することが不可欠。

## 要点

### 低血糖の症状（二相性）

| 相 | 機序 | 主な症状 |
|---|---|---|
| 自律神経症状（早期）| 交感神経亢進（[アドレナリン](../../06_薬剤/自律神経・循環/アドレナリン.md)放出）| **振戦・動悸・冷汗・空腹感・顔面蒼白** |
| 中枢神経症状（後期）| 脳の糖不足 | 頭痛・集中力低下・眠気・[[意識障害]]・けいれん |

- 振戦は**自律神経（交感神経）症状** ← 看護師国試で問われやすい
- 長期罹患・厳格管理者では自律神経症状が現れにくい「**無自覚性低血糖**」に注意

### シックデイのインスリン管理

- **自己判断でのインスリン中止は厳禁**
  - 感染・ストレスでカテコラミン↑ → インスリン抵抗性↑ → 食事が取れなくても高血糖・DKAのリスク
  - 基礎インスリンは原則継続。食事量に応じて追加（速効型）を調整
- 水分と糖質を少量頻回に補給（おかゆ・スープ・スポーツドリンク）
- 嘔吐・高熱・意識変容 → 速やかに受診

### 自己血糖測定（SMBG）の保険適用

- 1型糖尿病患者のSMBG（試験紙・穿刺針の費用）は**医療保険対象**
  - 在宅自己注射指導管理料に含まれて算定される
  - 「保険対象外」は**誤り**

### 運動と血糖

- 運動は**食後1〜2時間**が効果的（血糖上昇期に消費）
- 空腹時（朝食前など）の運動 → 低血糖リスクが高く**非推奨**

## CBTチェック

- 低血糖の**振戦**は「自律神経症状」か「中枢神経症状」か → **自律神経症状**
- シックデイでインスリンを中止してよいか → **×。継続が原則**
- SMBGの費用は保険適用か → **○。保険対象**
