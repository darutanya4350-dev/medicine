# 二次性糖尿病

> [[糖尿病]]・耐糖能異常を見たら、1型・2型だけでなく、血糖上昇ホルモンの過剰による内分泌疾患も考える。症例中の特徴的な身体所見や発作症状から原因を逆引きする。

## 要点

| 原因疾患 | 血糖上昇の主因 | 症例で拾う手掛かり |
| --- | --- | --- |
| [[クッシング症候群]] | コルチゾール過剰 → インスリン抵抗性 | 中心性肥満、満月様顔貌、赤紫色皮膚線条、近位筋力低下 |
| [[先端巨大症]] | 成長ホルモン過剰 → インスリン抵抗性 | 手足の肥大、下顎前突、巨大舌、発汗 |
| [[褐色細胞腫]] | カテコールアミン過剰 → インスリン分泌抑制・糖新生亢進 | 発作性高血圧、頭痛、動悸、発汗 |
| [[甲状腺機能亢進症]] | 代謝亢進・糖吸収や糖新生の亢進 | 体重減少、頻脈、手指振戦、発汗 |

- [[副腎皮質ステロイド]]投与歴があれば、薬剤性の二次性糖尿病も考える。

## CBTチェック

- 症例に「糖尿病」があれば、内分泌疾患を示す体型・顔貌・発作性症状・脈拍をもう一度探す。
- 問題文の「糖尿病＋頭痛・動悸・発汗・発作性高血圧」→ [[褐色細胞腫]]を考える。
- 糖尿病は主診断ではなく、血糖上昇ホルモン過剰を示す合併症として提示されることがある。
