# 甲状腺癌の組織型

> 甲状腺癌は組織型により転移経路と病理所見が異なる。CBT・国試では、乳頭癌・濾胞癌・髄様癌・未分化癌の特徴を区別する。

## 要点

| 組織型 | 重要所見 |
|---|---|
| 乳頭癌 | 砂粒腫、リンパ行性転移 |
| 濾胞癌 | 血行性遠隔転移 |
| 髄様癌 | C細胞由来、カルシトニン、間質アミロイド |
| 未分化癌 | 高齢者、急速増大、予後不良 |

## CBTチェック

- 砂粒腫 → 乳頭癌、血行性遠隔転移 → 濾胞癌、間質アミロイド → 髄様癌。
- 髄様癌は[[甲状腺髄様癌]]として、カルシトニン上昇や[[多発性内分泌腫瘍症2型]]との関連も確認する。
