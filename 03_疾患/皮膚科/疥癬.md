# 疥癬

> 疥癬は、ヒゼンダニ（Sarcoptes scabiei var. hominis）が角質層に寄生する感染症。強い掻痒と、手指間・手関節・腋窩・下腹部・外陰部などの皮疹が手掛かりになる。

## 要点

- 疥癬トンネル（線状の皮疹）を形成し、夜間に掻痒が強くなりやすい。
- 高齢者施設などで集団発生することがある。
- 診断は皮疹からヒゼンダニや虫卵を検出する顕微鏡検査、またはダーモスコピーなどで行う。
- 治療はイベルメクチン内服や外用薬を用いる。接触者の確認・対応も重要。

## 白癬との比較

|  | 白癬 | 疥癬 |
|---|---|---|
| 原因 | 白癬菌（真菌） | ヒゼンダニ |
| 典型所見 | 環状・辺縁拡大、中心治癒 | 疥癬トンネル、強い夜間掻痒 |
| 検査 | KOHで菌糸 | 顕微鏡で虫体・虫卵 |
| CBTでの代表治療 | 抗真菌薬 | イベルメクチン |

## CBTチェック

- 「疥癬トンネル」「施設で集団発生」→ [[疥癬]]を考える。
- KOHで菌糸をみるのは[[白癬]]であり、疥癬ではダニ・虫卵の検出を考える。
