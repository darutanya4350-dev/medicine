# 神経学的徴候の鑑別

> 神経診察の徴候は、髄膜刺激、錐体路障害、後索障害、神経根刺激など、障害部位と対応させて覚える。

## 要点

| 徴候 | 主な意味・関連部位 |
|---|---|
| 項部硬直 | 髄膜刺激。[[髄膜炎]]や[[くも膜下出血]]など |
| Hoffmann反射 | 錐体路障害を示唆。頸髄症などでみられる |
| Babinski反射 | 錐体路障害。足底刺激で母趾が背屈する |
| Romberg徴候 | 深部覚・後索障害による感覚性失調 |
| 指鼻試験 | 小脳性運動失調。測定障害や企図振戦をみる |
| [[温度眼振検査（カロリックテスト）]] | 外側半規管を含む末梢前庭機能 |
| Lasègue徴候 | 坐骨神経・神経根の伸展で下肢痛。腰椎椎間板ヘルニアなど |

- 項部硬直は、仰臥位で頭部を前屈させたときの抵抗をみる。
- Romberg徴候は、開眼では立てるが閉眼で動揺・転倒が増えることが手掛かりになる。
- Hoffmann反射とBabinski反射はいずれも錐体路徴候だが、刺激部位が手指と足底で異なる。

## CBTチェック

- 「髄膜刺激症状」→ 項部硬直、Kernig徴候、Brudzinski徴候を考える。
- 「中指末節をはじくと母指が屈曲」→ Hoffmann反射、錐体路障害。
- 「閉眼でふらつく」→ Romberg徴候、深部覚・後索障害。
- 「指鼻試験が拙劣」→ 小脳性運動失調、測定障害を考える。
- 「温水・冷水を外耳道に注入して眼振を誘発」→ カロリックテスト、末梢前庭機能を評価する。
- 「足底外縁をこすると母趾背屈」→ Babinski反射、錐体路障害。
- 「下肢伸展で坐骨神経領域の痛み」→ Lasègue徴候、神経根刺激。

### 問題演習の振り返り（M3E 問題18106790）

1. **決め手**：設問が「髄膜刺激症状」を尋ねており、項部硬直が該当する。
2. **CBT最小知識**：項部硬直は[[髄膜刺激徴候]]。髄膜炎やくも膜下出血を考える手掛かりになる。
3. **選択肢からの連想**：Hoffmann・Babinskiは錐体路、Rombergは後索・深部覚、Lasègueは神経根刺激を示唆する。
4. **ひっかけポイント**：首の硬さ（項部硬直）と、閉眼でのふらつき（Romberg）を混同しない。
5. **一言暗記**：髄膜刺激は項部硬直、錐体路はBabinski、後索はRomberg。
