# 無月経

> **原発性無月経**は初経がない状態、**続発性無月経**は月経があった後に停止した状態である。月経には視床下部・下垂体・卵巣・子宮／流出路のすべてが必要となる。

## 原発性・続発性無月経と原因臓器

| 原因臓器・部位 | 原発性無月経               | 続発性無月経                       |
| ------- | -------------------- | ---------------------------- |
| 視床下部    | Kallmann症候群、体重減少     | ストレス、やせ、過度の運動、[[神経性痩せ症]]     |
| 下垂体     | 下垂体腫瘍、先天性機能低下        | [[高プロラクチン血症]]、[[Sheehan症候群]] |
| 卵巣      | [[Turner症候群]]、性腺形成不全 | 早発卵巣不全、[[多嚢胞性卵巣症候群]]         |
| 子宮・流出路  | ミュラー管形成不全、[[処女膜閉鎖症]] | アッシャーマン症候群、子宮頸管狭窄            |
| その他     | 甲状腺疾患、副腎疾患           | 妊娠、授乳、甲状腺疾患、薬剤               |

- 原発性無月経は、15歳までに初経がない場合に精査する。第二次性徴がない場合は、視床下部・下垂体または卵巣性を優先して考える。
- 続発性無月経は、規則的だった月経が3か月、もともと不規則な月経が6か月以上停止した場合を目安とする。
- 第二次性徴があり、周期性下腹部痛を伴う原発性無月経では、子宮・腟の流出路閉塞を考える。
- 続発性無月経では、まず妊娠を除外する。次にプロラクチン、甲状腺機能、FSH・LH・エストラジオールなどで原因部位を評価する。
- FSH高値は卵巣性（高ゴナドトロピン性）、FSH・LH低値または正常は視床下部・下垂体性（低ゴナドトロピン性）を支持する。
- [[多嚢胞性卵巣症候群（PCOS）]]では排卵障害により、低温相が持続する一相性の[[基礎体温]]を示しやすい。
- **高プロラクチン血症**では、プロラクチン上昇 → 視床下部のGnRHパルス分泌抑制 → LH・FSH分泌とLHサージの抑制 → 卵胞発育・排卵障害 → 無月経となる。乳汁漏出を伴うことがある。

## CBTチェック

- 「低身長＋原発性無月経＋FSH高値」は[[Turner症候群]]を考える。
- 「原発性無月経＋第二次性徴あり＋周期性腹痛」は[[処女膜閉鎖症]]などの流出路閉塞を考える。
- 続発性無月経の最初の確認は妊娠である。
- 「無月経＋乳汁漏出」は高プロラクチン血症を疑い、プロラクチン値を測定する。
