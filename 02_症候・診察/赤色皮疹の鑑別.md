# 赤色皮疹の鑑別

> 赤い皮疹は、表皮の炎症（湿疹）、真皮の血管透過性亢進（蕁麻疹）、血管拡張による紅斑などに分けて考える。

## 要点

- 原発疹は皮膚病変の初期形態（紅斑・紫斑・丘疹・水疱・膿疱など）。
- 続発疹は原発疹の経過や損傷後に生じる形態で、びらん・潰瘍・痂皮・鱗屑・萎縮などがある。

|  | 湿疹 | 蕁麻疹 | 紅斑 |
|---|---|---|---|
| 主な病態 | 海綿状変性＋真皮血管拡張 | 真皮浅層の血管透過性亢進 | 真皮血管の拡張など、多様な原因 |
| 皮疹 | 丘疹・小水疱・湿潤・落屑など | 赤く平らに盛り上がる膨疹 | 平らな赤み（薬疹・結節性紅斑など） |
| 症状・経過 | 掻痒、慢性化で苔癬化 | 掻痒、通常は一過性 | 原因により異なる |
| 手掛かり | IV型アレルギーなど | I型アレルギーなど | 様々な原因、真皮血管拡張 |

## CBTチェック

- 海綿状変性・小水疱・落屑・湿潤＋掻痒 → [[湿疹]]。
- 赤く平らに盛り上がる一過性の膨疹＋掻痒 → [[蕁麻疹]]。
- 平らな赤みで、硝子圧法（圧迫）で消退するもの → 紅斑を考える。
- 「原発疹でないもの」→ 潰瘍などの続発疹を選ぶ。
