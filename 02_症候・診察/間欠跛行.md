# 間欠跛行

> 歩行により下肢の痛み・しびれ・脱力が生じ、休息すると軽快する症候。主に[[末梢動脈疾患]]による血管性と、[[腰部脊柱管狭窄症]]による神経性を鑑別する。

## 要点

|  | 血管性 | 神経性（脊髄性） |
| --- | --- | --- |
| 主な原因 | [[閉塞性動脈硬化症]]など | [[腰部脊柱管狭窄症]] |
| 症状 | 下肢筋の虚血による疼痛 | 下肢のしびれ・疼痛・脱力 |
| 軽快する姿勢 | 立ち止まるだけで軽快 | 前屈・座位で軽快しやすい |
| 所見・検査 | 足背動脈減弱、ABI低下 | 下肢動脈拍動は保たれ、腰椎MRIなど |

- 血管性では歩行時の筋虚血により疼痛が生じ、安静で酸素需給が改善して軽快する。
- 神経性では歩行や立位で脊柱管内の馬尾・神経根が圧迫され、前屈で症状が軽快しやすい。
- 両者が合併することもあるため、高齢者の間欠跛行ではABI測定が重要である。

## CBTチェック

- 高齢・喫煙・[[糖尿病]]を背景に、下肢冷感や足背動脈拍動減弱を伴えば血管性間欠跛行を考える。
- 前かがみで症状が軽快し、自転車では歩行より症状が出にくい場合は[[腰部脊柱管狭窄症]]を考える。
- 若年の喫煙者では[[閉塞性血栓血管炎]]（Buerger病）も鑑別に挙げる。
