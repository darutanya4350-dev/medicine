# 徒手筋力テスト（MMT）

> 徒手筋力テスト（manual muscle testing：MMT）は、重力と抵抗に抗して関節を動かせるかを0〜5で評価する。

## 要点

| MMT | 判定 |
| --- | --- |
| 0 | 筋収縮なし |
| 1 | 筋収縮はあるが関節運動なし |
| 2 | 重力を除けば全可動域を動かせる |
| 3 | 重力に抗して全可動域を動かせるが、抵抗には抗せない |
| 4 | 重力＋抵抗に抗して動かせるが、正常より弱い |
| 5 | 強い抵抗に抗して正常に動かせる |

- 足関節背屈では、側臥位など重力を除いた肢位で動けばMMT 2。
- 坐位で重力に抗して背屈できなければ、MMT 3にはならず2と判定する。

## CBTチェック

- 問題文の「重力を除けば動く」→ MMT 2。
- 「重力に抗して動くが抵抗には抗せない」→ MMT 3。
- 「筋収縮のみ」→ MMT 1。「収縮なし」→ MMT 0。
