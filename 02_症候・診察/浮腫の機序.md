# 浮腫の機序

> **浮腫**は、間質液が過剰に貯留した状態である。毛細血管での濾過が静脈・リンパ管による回収を上回ると生じる。

## 要点

- 体水分の約1/3が細胞外液であり、そのうち約1/4が血漿、残りが間質液に分布する。
- [[Starlingの法則]]では、毛細血管の静水圧と膠質浸透圧の差によって血管内外の水移動が決まる。

| 機序 | 代表例 |
|---|---|
| 毛細血管内静水圧上昇 | [[心不全]]、静脈閉塞 |
| 血漿膠質浸透圧低下 | [[ネフローゼ症候群]]、肝硬変 |
| 毛細血管透過性亢進 | 敗血症、アナフィラキシー、熱傷 |
| リンパ流障害 | リンパ節郭清、フィラリア症 |
| 腎でのNa・水貯留 | [[急性糸球体腎炎]]、腎不全 |

- 実際の浮腫では複数の機序が重なり、レニン・アンジオテンシン・アルドステロン系や抗利尿ホルモンによるNa・水貯留が増悪因子となる。

## CBTチェック

- 溶連菌感染後[[急性糸球体腎炎]]：**GFR低下 → Na・水排泄低下 → 循環血液量増加 → 浮腫・高血圧**。
- [[ネフローゼ症候群]]：高度蛋白尿と低アルブミン血症による膠質浸透圧低下に、腎でのNa貯留も関与する。
- うっ血性心不全では静水圧上昇、敗血症では透過性亢進、リンパ節郭清後ではリンパ流障害が中心となる。
