# 下部尿路症状

> **下部尿路症状**は蓄尿症状・排尿症状・排尿後症状に分ける。蓄尿症状は尿をためている間に現れる症状である。

## 要点

| 分類 | 代表症状 |
| --- | --- |
| 蓄尿症状 | 尿意切迫感、頻尿、夜間頻尿、尿失禁 |
| 排尿症状 | 尿勢低下、排尿遅延、腹圧排尿、尿線途絶 |
| 排尿後症状 | 残尿感、排尿後滴下 |

- [[過活動膀胱]]では尿意切迫感を必須症状とし、頻尿・夜間頻尿・切迫性尿失禁を伴いうる。
- [[前立腺肥大症]]や[[神経因性膀胱]]では排尿症状や残尿を伴いやすい。

## CBTチェック

- **尿失禁・尿意切迫感**は蓄尿症状。
- **残尿感・腹圧排尿・尿線途絶**は蓄尿症状ではない。
