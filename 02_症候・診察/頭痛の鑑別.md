# 頭痛の鑑別

> 頭痛では、まず緊急性のある**二次性頭痛**を除外し、危険な所見がなければ[[片頭痛]]・[[緊張型頭痛]]・[[群発頭痛]]などの一次性頭痛を鑑別する。

## 鑑別

- レッドフラッグは、突然発症、新規・進行性、発熱、意識障害・局所神経症状、50歳以降の初発、妊娠・産褥、姿勢や咳・運動で変化する頭痛、乳頭浮腫などである。

| 手がかり | 主な鑑別 |
|---|---|
| 1分以内に最強となる雷鳴頭痛、嘔吐・意識障害 | [[くも膜下出血]]、[[可逆性脳血管攣縮症候群]]、動脈解離 |
| 発熱、項部硬直、意識障害 | [[髄膜炎]]・脳炎 |
| 眼痛、充血、視力低下、中等度散瞳 | [[急性閉塞隅角緑内障]] |
| 進行性、早朝の嘔吐、乳頭浮腫、[[Cushing現象]] | 頭蓋内占拠性病変・頭蓋内圧亢進 |
| 鼻漏、顔面痛、副鼻腔の叩打痛 | [[副鼻腔炎]] |

- 一次性頭痛は、片側拍動性・悪心・光過敏なら[[片頭痛]]、両側圧迫性で動作による増悪がなければ[[緊張型頭痛]]、片側眼窩部激痛と同側自律神経症状なら[[群発頭痛]]を考える。

## CBTチェック

- 「突然」「今までで最悪」「嘔吐・意識障害」は、一次性頭痛より[[くも膜下出血]]を優先する。
- 発熱・項部硬直なら[[髄膜炎]]、眼痛・充血・中等度散瞳なら[[急性閉塞隅角緑内障]]を考える。
- 一次性頭痛らしい性状でも、初発・神経学的異常・非典型的経過があれば二次性頭痛を検索する。
