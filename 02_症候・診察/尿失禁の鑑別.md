# 尿失禁の鑑別

> **尿失禁**は、自分の意思に反して尿が漏れる症状である。尿意・腹圧との関係、残尿の有無、神経障害を手掛かりに分類する。

## 主な型

| 型 | 典型像 | 主な背景 |
|---|---|---|
| 腹圧性 | 咳・くしゃみ・運動で漏れる | 出産・加齢による骨盤底筋の脆弱化 |
| 切迫性 | 強い尿意に続いて間に合わず漏れる | [[過活動膀胱]]、脳血管障害など |
| 溢流性 | 多量の残尿があり、少量ずつ持続して漏れる | [[前立腺肥大症]]、[[神経因性膀胱]] |
| 反射性 | 尿意を伴わず反射的に漏れる | 脊髄障害による神経因性膀胱 |
| 機能性 | 排尿機能は保たれるがトイレに間に合わない | 認知症、歩行障害 |

## CBTチェック

- 前立腺肥大症で残尿増加 → **溢流性尿失禁**を考える。
- 咳・くしゃみで漏れる → 腹圧性、強い尿意で我慢できず漏れる → 切迫性尿失禁。
- 溢流性尿失禁では少量の漏れがあっても[[尿閉]]を否定せず、残尿を評価する。
