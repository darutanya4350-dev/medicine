# 歯肉出血

> 歯肉出血は、まず**局所の歯周炎**か、紫斑・鼻出血などを伴う**全身性の出血傾向**かを分けて考える。

## 要点

| 機序 | 主な疾患 | 手がかり |
| --- | --- | --- |
| 局所炎症 | [[歯周炎]] | 歯垢、発赤・腫脹、歯磨き時の出血 |
| 血小板減少 | [[ITP]]、[[急性白血病]] | 点状出血・紫斑、自然出血 |
| 血小板機能・粘着異常 | [[血小板無力症]]、[[von Willebrand病]] | 一次止血障害による粘膜出血 |
| 凝固因子欠乏 | [[血友病]]A・B | 外傷後の出血、関節内出血も重要 |
| 消費・脆弱化 | [[DIC]]、[[壊血病]] | DICは止血因子消費、壊血病はビタミンC欠乏 |

- [[血小板無力症]]はGPIIb/IIIa異常による血小板凝集障害、von Willebrand病は血小板粘着障害をきたす。
- 急性白血病では骨髄での正常造血が抑制され、血小板減少による歯肉出血・紫斑が初発症状となりうる。
- 歯肉の発赤・腫脹と歯垢を伴う場合は、炎症による血管拡張・易出血性から歯周炎を考える。

## CBTチェック

- **歯肉出血＋紫斑・鼻出血**は血小板数または機能の異常を考える。
- **歯肉出血＋発熱・貧血・血小板減少**は急性白血病を疑う。
- 局所所見だけでは説明できない反復出血では、血算・血小板数・PT・APTTを確認する。
