# 高張性脱水

> 水の欠乏がナトリウム（Na）の欠乏より大きい脱水で、[[高ナトリウム血症]]を伴う。細胞外液が高浸透圧となり、細胞内から細胞外へ水が移動するため、細胞内脱水が強い。

## 要点

- Na濃度が血漿より低い水分（自由水）を失うことで起こる。過度の発汗、発熱、水分摂取不足、多尿を来す[[尿崩症]]、乳幼児の下痢・嘔吐などが原因となる。
- 水分喪失 → 細胞外液の浸透圧上昇 → **細胞内液から細胞外液へ水が移動** → 細胞内脱水、という流れである。
- 細胞内脱水により、口渇、発熱、興奮、けいれん、傾眠・意識障害などの中枢神経症状をきたす。
- 細胞外液量が比較的保たれるため、循環不全や血圧低下は重症になるまで目立ちにくい。
- 補正を急ぐと血清Naが急低下して脳浮腫を起こしうるため、重症例は血清Naを監視しながら緩徐に補正する。

## CBTチェック

- 高張性脱水は**高ナトリウム血症**であり、低ナトリウム血症ではない。
- 主要な病態は細胞内脱水であり、神経症状が重要である。
- 「発汗過多・尿崩症＋高Na血症」は高張性脱水を考える。
- [[ロタウイルス胃腸炎]]に伴うNa 162 mEq/Lは高張性脱水を示す。
