# 難聴の鑑別

> 難聴は外耳・中耳の障害による伝音難聴と、内耳・聴神経の障害による感音難聴に大別する。

## 要点

| 所見 | 伝音難聴 | 感音難聴 |
|---|---|---|
| 障害部位 | 外耳・中耳 | 内耳・聴神経 |
| 純音聴力 | 気骨導差あり | 気骨導差なし |
| Weber試験 | 患側へ偏る | 健側へ偏る |
| Rinne試験 | 患側で陰性 | 陽性 |

- 伝音難聴は[[滲出性中耳炎]]・[[真珠腫性中耳炎]]など、感音難聴は[[突発性難聴]]・[[メニエール病]]・[[騒音性難聴]]などが代表である。
- 確認には[[純音聴力検査]]を用い、耳鏡所見や症状と合わせて判断する。

## CBTチェック

- Weber試験で患側に偏る → 伝音難聴、健側に偏る → 感音難聴。
- Rinne試験で骨導＞気導（陰性） → 伝音難聴。
