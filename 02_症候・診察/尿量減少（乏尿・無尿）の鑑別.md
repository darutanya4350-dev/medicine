# 尿量減少（乏尿・無尿）の鑑別

> **乏尿**（目安：0.5 mL/kg/時未満、または成人で約400 mL/日未満）は、[[急性腎障害]]を疑う重要所見である。原因を**腎前性・腎性・腎後性**に分け、病歴、診察、尿所見、腎エコーを合わせて判断する。

## 鑑別と検査

- **腎前性**：有効循環血漿量または腎血流の低下。脱水・出血、[[心不全]]、[[ショック]]、肝硬変など。尿細管は保たれ、Naを再吸収するため濃い尿・低Na尿となる。
- **腎性（腎実質性）**：腎実質の障害。虚血・腎毒性による[[急性尿細管壊死]]、[[急性糸球体腎炎]]、[急性間質性腎炎](../03_疾患/腎・泌尿器/急性間質性腎炎.md)、血管炎など。尿細管障害ではNa再吸収が低下する。
- **腎後性**：尿路閉塞。[[前立腺肥大症]]、尿路結石、骨盤内腫瘍、神経因性膀胱など。両側性閉塞（または単腎での閉塞）で[[急性腎障害]]を来し、膀胱・腎エコーで閉塞を確認する。

| 指標 | 腎前性 | 腎性（主に急性尿細管壊死） |
|---|---|---|
| BUN/Cr比 | **20以上** | **10未満** |
| 尿中Na濃度 | **20 mEq/L未満** | **40 mEq/L超** |
| FENa | **1%未満** | **2%超** |
| 尿浸透圧 | **500 mOsm/kg以上** | **350 mOsm/kg未満** |
| 尿比重 | **1.020以上** | **1.010以下** |
| 尿Cr/血清Cr比 | **40超** | **20未満** |

- **BUN/Cr比**：腎前性では尿細管での尿素再吸収も増え、BUNがCrより上がりやすい。消化管出血、蛋白異化亢進、ステロイド投与でも上昇しうる。
- **尿中Na濃度**：尿細管がNaを保持できるかの目安。利尿薬投与中は高くなり、判別しにくい。
- **FENa**（ナトリウム排泄分画）：濾過されたNaのうち尿へ排泄された割合。`FENa（%）＝(尿中Na × 血清Cr) ÷ (血清Na × 尿中Cr) × 100`。腎前性では低値、急性尿細管壊死では高値が典型である。
- 腎前性では尿細管が保たれているため、Naと水を再吸収して**濃縮尿**となる。したがって、低比重尿（例：1.006）は腎前性に合わない。
- 腎前性の尿沈渣は基本的に異常の少ない**bland sediment**であり、尿蛋白強陽性・尿潜血陽性は典型的でない。尿潜血陽性は、[[急性糸球体腎炎]]などの腎実質性障害、尿路出血、[[横紋筋融解症]]によるミオグロビン尿を考える。
- 下痢・低血圧による循環血漿量低下では、レニン-アンジオテンシン-アルドステロン系が働き、Na再吸収とK排泄が促進される。よって尿Kが0 mEq/Lとなることはない。
- 腎後性の各指標は、初期には腎前性様、遷延すると腎性様となり一定しない。閉塞の確認には腎・膀胱エコーが重要である。
- 腹部超音波では腎の大きさと[[水腎症]]の有無を非侵襲的に確認する。急性腎障害では腎は正常大〜腫大のことが多く、慢性腎不全では両腎の萎縮・皮質菲薄化を認めることが多い。
- ただし、[[糖尿病性腎症]]、[[常染色体優性多発性嚢胞腎（ADPKD）|多発性嚢胞腎]]、[[アミロイドーシス]]などでは慢性でも腎萎縮を認めないことがある。
- これらは単独で確定診断できない。敗血症、糸球体腎炎、肝腎症候群、利尿薬使用時などでは典型値から外れうる。

## 無尿と尿閉の初期整理

|  | 無尿 | 尿閉 |
|---|---|---|
| 膀胱内の尿 | 乏しい | 貯留する |
| 主な原因 | 腎前性・腎性、両側上部尿路閉塞 | 下部尿路閉塞、[[神経因性膀胱]] |
| 手掛かり | [[急性腎障害]]の病歴・所見 | 下腹部膨満・疼痛、[[溢流性尿失禁]] |
| 初期対応 | 原因・体液量に応じて治療する | 導尿・カテーテル留置で膀胱を減圧する |

- 無尿では、循環血漿量低下なら補液、尿路閉塞ならドレナージなど、原因に応じて対処する。利尿薬は体液過剰の是正以外には用いない。

## CBTチェック

- 腎前性は「腎血流低下だが尿細管は保たれる」ため、**BUN/Cr比高値・尿中Na低値・FENa低値**となる。
- 腎後性では閉塞解除を急ぐ。無尿、下腹部膨満、前立腺疾患・結石の病歴ではまず閉塞を疑う。
- 無尿と尿閉の鑑別では、**膀胱内に尿が貯留しているか**を確認する。尿漏れがあっても尿閉を否定しない。
- FENaは **1%未満：腎前性を支持、2%超：急性尿細管壊死を支持**。1〜2%は判断が難しく、臨床所見と併せる。
- 下痢＋低血圧＋BUN/Cr比高値なら腎前性をまず考え、選択肢では**尿Na低値・濃縮尿・尿所見が乏しい**ものを選ぶ。
