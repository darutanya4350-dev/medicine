# 小児低身長

> **小児低身長**は、同性・同年齢の標準身長の−2.0 SD以下を目安とする。現在の身長だけでなく、[[成長曲線]]が下方へずれる成長速度の低下を重視する。

## 要点

- 母子健康手帳や学校記録から身長・体重を成長曲線へ記入し、出生時の在胎週数・身長・体重、周産期異常、食事・便通、慢性疾患、薬剤、両親の身長と思春期時期を確認する。
- **身長低下＋体重が比較的保たれる／増える**場合は内分泌疾患、**体重増加不良が先行**する場合は栄養不良・吸収不良・慢性全身疾患を考える。
- 身体診察では体型・四肢の均衡、翼状頸などの症候性所見、甲状腺、思春期発育を確認する。女児の原因不明の低身長では[[Turner症候群]]を疑う。
- 骨年齢は左手・手関節X線で評価する。初期検査は血算、生化学、炎症反応、TSH・遊離T4、IGF-1などを原因に応じて選び、GH分泌不全は他疾患を除外後にGH分泌刺激試験で診断する。

| 主な原因 | 成長曲線・体重の特徴 | 手がかり |
|---|---|---|
| 家族性・体質性 | 低い位置をおおむね平行に成長 | 両親の身長、家族の思春期時期。体質性では骨年齢遅延 |
| 内分泌疾患 | 身長SDが低下し、体重は比較的保たれる | [[成長ホルモン分泌不全性低身長症]]、[[甲状腺機能低下症]]、Cushing症候群 |
| 栄養・慢性疾患 | 体重増加不良が目立ちやすい | 慢性下痢、炎症性腸疾患、腎・心疾患、心理社会的要因 |
| 染色体・骨系統疾患 | 症候性所見や体の不均衡を伴う | [[Turner症候群]]、[[軟骨無形成症]]、[[Prader-Willi症候群]] |
| SGA性低身長症 | 出生時から低身長で、低い曲線をほぼ平行に推移する | 在胎週数に比して出生時の身長・体重が小さく、2歳頃までのキャッチアップ不良。骨年齢・GH分泌は正常なことが多い |

## CBTチェック

- 画像の6歳男児は身長が−2.0→−2.5→−3.0 SDと低下し、体重は−1 SD以内で保たれるため、[[成長ホルモン分泌不全性低身長症]]を疑う。
- 在胎週数に比べ出生身長・体重が小さく、骨年齢遅延やGH分泌不全がなくても低身長が持続する場合は[[SGA性低身長症]]を考える。成長曲線は出生後から低い位置をおおむね平行にたどる。
- 骨盤位分娩などの周産期異常は下垂体障害の手がかりになり得る。家族性・体質性低身長は両親の身長・思春期時期と骨年齢を含めて判断する。
