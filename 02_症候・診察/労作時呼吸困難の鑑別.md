# 労作時呼吸困難の鑑別

> 労作時呼吸困難は、酸素運搬能の低下（[[貧血]]）、肺のガス交換障害、心拍出量低下を主に区別する。病歴、聴診、血算、胸部画像、心エコーを組み合わせて評価する。

## 要点

| 主な病態 | 手がかり | 初期評価 |
| --- | --- | --- |
| [[貧血]] | 眼瞼結膜蒼白、黒色便・過多月経などの出血歴 | 血算、MCV、網赤血球 |
| [[COPD]] | 喫煙歴、咳・痰、喘鳴、やせ | 呼吸機能検査、胸部X線 |
| [[間質性肺炎]] | 乾性咳嗽、fine crackles、ばち状指 | 胸部CT、呼吸機能検査 |
| [[心不全]] | 起坐呼吸、浮腫、Ⅲ音、湿性ラ音 | BNP、心エコー、胸部X線 |

- [[肺高血圧症]]では労作時息切れ、Ⅱ音肺動脈成分の亢進、右心負荷所見を認める。診断の入口は心エコーである。
- 心雑音を伴う場合は[[弁膜症]]、若年者の心不全では[[心筋症]]や[[先天性心疾患]]も考える。
- SpO₂、心電図、胸部X線は、呼吸器疾患・心疾患を同時に評価する基本検査である。

## CBTチェック

- **結膜蒼白＋Hb低下**なら、呼吸器症状が乏しくても貧血による労作時呼吸困難を考える。
- 喫煙歴＋慢性の咳・痰・息切れはCOPD、乾性咳嗽＋fine cracklesは間質性肺炎を示唆する。
- 浮腫・Ⅲ音・湿性ラ音・胸部X線での肺うっ血は心不全を示唆する。
