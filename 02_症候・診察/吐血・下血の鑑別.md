# 吐血・下血の鑑別

> **吐血・黒色便**は上部消化管出血を、**鮮血便・暗赤色便**は下部消化管出血をまず考える。ただし、大量の上部消化管出血では鮮血便となることがあり、便色だけで出血源を断定しない。

## 上部消化管出血

| 疾患 | CBTでの手がかり |
| --- | --- |
| [[Mallory-Weiss症候群]] | 飲酒・反復する嘔吐の後に吐血 |
| [[食道静脈瘤]] | [[肝硬変]]、[門脈圧亢進](../03_疾患/消化器/門脈圧亢進.md)、突然の大量吐血 |
| [[胃潰瘍]] | NSAIDs・H. pylori、食後に増悪する心窩部痛 |
| [[十二指腸潰瘍]] | NSAIDs・H. pylori、空腹時・夜間痛、食事で軽快しやすい |

- 吐血・黒色便では、まず循環動態、Hb、BUN／Cr、抗血栓薬・NSAIDs使用歴と肝疾患の有無を確認し、上部消化管内視鏡へつなぐ。

## 下部消化管出血

| 疾患群 | CBTでの手がかり |
| --- | --- |
| [[潰瘍性大腸炎]]・[[クローン病]] | 若年者、慢性・反復性の血便や下痢；内視鏡・生検で鑑別 |
| [[アメーバ赤痢]]・[[感染性腸炎]] | 渡航・性的接触、生もの・集団発生、発熱・下痢などの感染歴 |
| [[虚血性腸炎]] | 高齢者・便秘、突然の左下腹部痛に続く血便 |
| [[大腸憩室出血]] | 腹痛に乏しい突然の鮮血便・大量出血 |
| [[大腸癌]]・[[痔核]] | 癌は便潜血・便通異常・体重減少、内痔核は硬便後の排便時にみられる無痛性の鮮血便 |

- 血行動態が不安定、失神、持続する大量出血、強い腹痛・腹膜刺激症状を伴う場合は緊急対応を優先する。
- 黒色便でも小腸・右側結腸出血のことがあり、鮮血便でも大量の上部消化管出血を除外できない。
- 発熱・腹痛・下痢を伴う血便は感染性・炎症性・虚血性腸炎を、無痛性の大量下血は憩室出血を優先して考える。
- 硬便後に腹痛・肛門痛を伴わない鮮血便では、内痔核を考える。肛門痛が強ければ裂肛を考える。
