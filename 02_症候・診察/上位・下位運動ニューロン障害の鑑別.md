# 上位・下位運動ニューロン障害の鑑別

> 上位運動ニューロン障害は錐体路の抑制が外れて痙性・反射亢進を示し、下位運動ニューロン障害は筋へ至る最終経路の障害として弛緩性麻痺・筋萎縮を示す。

## 要点

| 所見 | 上位運動ニューロン障害 | 下位運動ニューロン障害 |
|---|---|---|
| 筋トーヌス | 亢進（痙縮） | 低下（弛緩性） |
| 深部腱反射 | 亢進、病的反射 | 低下・消失 |
| 筋萎縮・ fasciculation | 目立ちにくい | 筋萎縮・線維束性収縮 |
| 障害部位 | 錐体路（脳・脳幹・脊髄） | 前角細胞・運動神経・神経根など |

- 仮性球麻痺は両側の皮質延髄路障害による上位運動ニューロン徴候で、嚥下障害・構音障害・情動失禁などを示す。
- 運動失調は主に小脳障害、または後索障害による深部覚障害でみられる。
- Babinski反射、痙性麻痺、深部腱反射亢進は上位運動ニューロン障害を考える。

## CBTチェック

- 「筋萎縮・線維束性収縮・腱反射低下」→ 下位運動ニューロン障害。
- 「筋トーヌス亢進・腱反射亢進・Babinski反射」→ 上位運動ニューロン障害。
- 「運動失調」→ 小脳または後索、「仮性球麻痺」→ 両側皮質延髄路を考える。

### 問題演習の振り返り（M3E 問題18200570）

前回の回答：B → 正答：E（知識不足：上位・下位運動ニューロン所見の混同）

1. **決め手**：下位運動ニューロン障害では筋への運動神経入力が失われ、筋萎縮が起こる。
2. **CBT最小知識**：下位運動ニューロン＝筋萎縮・腱反射低下・筋トーヌス低下、上位運動ニューロン＝腱反射亢進・痙縮。
3. **選択肢からの連想**：仮性球麻痺は両側皮質延髄路、運動失調は小脳または後索障害を示唆する。
4. **ひっかけポイント**：筋トーヌス亢進・深部腱反射亢進は下位ではなく上位運動ニューロン障害。
5. **一言暗記**：下位運動ニューロンは筋萎縮、上位運動ニューロンは反射亢進。
