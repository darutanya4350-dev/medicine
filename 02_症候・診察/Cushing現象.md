# Cushing現象

> [[頭蓋内圧亢進]]でみられる**高血圧・徐脈・不規則呼吸**の三徴（Cushing三徴）。脳灌流を保とうとする反応であり、脳ヘルニア切迫を示す遅発性の重篤な徴候である。

## 要点

- 頭蓋内圧の上昇 → 脳灌流圧の低下 → 交感神経興奮による血圧上昇、という流れで生じる。
- 血圧上昇に対する圧受容体反射・迷走神経興奮により**徐脈**となる。
- 脳幹の圧迫により不規則呼吸・無呼吸を伴う。
- 脳出血、頭部外傷、脳腫瘍、脳浮腫などで生じる頭蓋内圧亢進の進行を疑う。
- [[Cushing病]]（下垂体ACTH産生腺腫による[[クッシング症候群]]）とは別の概念である。

## CBTチェック

- 頭蓋内圧亢進で**心拍数が低下する**のはCushing現象による。
- 問題文の「血圧上昇・脈拍低下」→ [[Cushing現象]]を考える。
- 高地登山、急性出血、甲状腺機能亢進症は通常は頻脈を来す。
- Cushing三徴は高血圧・徐脈・不規則呼吸。
