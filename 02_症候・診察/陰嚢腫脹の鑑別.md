# 陰嚢腫脹の鑑別

> 陰嚢腫脹では、疼痛の有無、透光性、立位・腹圧での変化、還納の可否を確認する。急な強い疼痛では[[精巣捻転]]を最優先で疑う。

## 重要な鑑別

| 疾患 | 主な所見 | ポイント |
|---|---|---|
| [[鼠径ヘルニア]] | 鼠径部から連続する膨隆、立位・咳嗽や腹圧で増大、仰臥位で縮小・還納可能なことがある | 透光性は陰性。還納不能で痛み・嘔吐を伴えば嵌頓を疑う。 |
| [[陰嚢水腫]] | 無痛性で弾性軟の陰嚢腫脹、精巣を触れにくい | 透光性は陽性。通常は体位で縮小せず、還納できない。 |
| [[精巣捻転]] | 突然の強い片側陰嚢痛、精巣の挙上・腫脹 | 緊急疾患。超音波検査で血流を評価し、速やかに治療する。 |
| [[精巣上体炎]] | 陰嚢痛、腫脹、発熱、精巣上体の圧痛 | 尿路感染症・性感染症を背景にみる。 |
| [[精巣腫瘍]] | 無痛性の精巣腫大・硬結 | 若年男性ではまず疑い、陰嚢超音波と[腫瘍マーカー](../04_検査/血液/腫瘍マーカー.md)で評価する。 |

## CBTチェック

- **透光性陽性**は[[陰嚢水腫]]を支持する。
- 鼠径部から陰嚢へ連続し、腹圧で増大・還納可能なら[[鼠径ヘルニア]]を考える。
- 急性陰嚢痛では、[[精巣捻転]]を見逃さない。
