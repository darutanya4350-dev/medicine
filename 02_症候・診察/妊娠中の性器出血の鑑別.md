# 妊娠中の性器出血の鑑別

> 妊娠中の性器出血では、まず母体の循環動態と胎児状態を確認する。**疼痛・子宮緊張の有無**と妊娠週数が、前置胎盤と[[常位胎盤早期剝離]]などの鑑別に重要である。

## 鑑別と対応

| 主に妊娠初期 | 特徴 | 治療・対応 |
|---|---|---|
| [[流産]] | 性器出血と下腹部痛。妊娠22週未満の妊娠喪失 | 超音波で子宮内妊娠・胎児心拍を確認。自然排出の待機、薬物・手術的子宮内容除去を状態により選択 |
| [[異所性妊娠]] | 下腹部痛・性器出血、子宮内胎嚢を認めない。破裂で腹腔内出血・ショック | 経腟超音波・[[hCG]]で評価。未破裂で適応があればメトトレキサート、破裂・ショックでは緊急手術 |
| [[胞状奇胎]] | 妊娠週数に比べ子宮が大きい、不規則出血、hCG著増、超音波で胞状所見 | 子宮内容除去術後にhCGを経時測定し、絨毛性疾患の持続を監視 |

| 主に妊娠中期以降 | 特徴 | 治療・対応 |
|---|---|---|
| [[切迫早産]] | 規則的な子宮収縮、下腹部痛・少量出血、頸管短縮・開大 | 分娩進行・感染・破水を評価。子宮収縮抑制、早産が予想される場合は母体ステロイドを検討 |
| [[前置胎盤]] | **無痛性**の鮮紅色出血、子宮は軟らかい。反復しうる | 経腟超音波で診断し、内診は避ける。出血量・週数により入院管理し、原則帝王切開 |
| [[常位胎盤早期剝離]] | 持続する腹痛・性器出血、子宮板状硬、胎児機能不全。外出血が少ないこともある | 母体蘇生、凝固障害への対応、胎児・母体の状態に応じた速やかな分娩（多くは緊急帝王切開） |

- 出血量が少なくても、腹痛・子宮緊張、頻脈・低血圧、胎児心拍異常があれば緊急性を判断する。
- 妊娠初期の出血では[[異所性妊娠]]を優先して除外し、妊娠中期以降の無痛性出血では[[前置胎盤]]、有痛性出血では[[常位胎盤早期剝離]]を考える。

## CBTチェック

- 「無痛性・鮮紅色の反復出血」は[[前置胎盤]]、「腹痛・子宮板状硬・胎児機能不全」は[[常位胎盤早期剝離]]が典型である。
- 前置胎盤が疑われる出血では、**内診を行わず**超音波で胎盤位置を確認する。
- 妊娠反応陽性で腹痛・出血を認めたら、子宮内胎嚢の有無を確認して[[異所性妊娠]]を除外する。
