# 精神症状の分類

> 精神症状は、意識・知覚・思考・感情・意欲・記憶・自我意識などの機能ごとに整理すると、選択肢の誤りを見抜きやすい。

## 要点

| 精神機能 | 代表的な症状 |
|---|---|
| 思考 | 観念奔逸、連合弛緩、思考制止、妄想 |
| 感情 | 高揚気分、抑うつ気分、易刺激性、感情鈍麻 |
| 意欲・行動 | 行為心迫、無為自閉、精神運動制止、興奮 |
| 知覚 | 幻覚、錯覚 |
| 自我意識 | 離人感、させられ体験、考想伝播 |

- 連合弛緩：思考のつながりが緩み、話のまとまりが悪くなる。
- 滅裂思考：思考がバラバラで、全体として意味が伝わらない状態。連合弛緩より強い思考のまとまりの障害として説明される。
- 思考途絶：考えが突然、途中で途切れる。[[統合失調症]]でみられる。
- 思考制止：思考の速度が低下し、考えが進まない。[[うつ病]]でみられる。
- 自生思考：自分のものではない考えが勝手に浮かぶ体験。強迫観念とは異なる。
- 強迫観念：不合理と分かっていても、繰り返し浮かび、払いのけにくい考え。
- 支配観念：ある考えが感情や行動を強く支配するもの。外部から思考を操られるのは[[自我障害]]。
- 反響言語：相手の言葉をそのまま繰り返す症状。
- 言語新作：本人独自の新しい言葉を作る症状。[[統合失調症]]でみられる。
- 観念奔逸：考えが次々に浮かび、話題が飛躍する。躁状態でみられる。
- 妄想：誤った確信であり、思考内容の障害に分類する。
- 無為自閉：活動せず、他者との関わりを避けて閉じこもる状態で、意欲の障害である。

## CBTチェック

- 「思考の障害─連合弛緩」→ 正しい組合せ。
- 「感情の障害─観念奔逸」「知覚の障害─妄想」「意欲の障害─無為自閉」→ 誤った組合せ。
- 「関連のない観念が浮かんでまとまらない」→ 連合弛緩を考える。
- 「思考が突然止まる」＝思考途絶、「思考が遅く進まない」＝思考制止。
- 「思考がバラバラで意味が伝わらない」＝滅裂思考、「独自の言葉を作る」＝言語新作。
