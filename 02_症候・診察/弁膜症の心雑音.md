# 弁膜症の心雑音

> 心雑音は、血流の乱れが生じる時相で整理する。**狭窄は血液が通過する時相、閉鎖不全は逆流する時相**に雑音を聴く。

## 要点

| 病態 | 雑音 | 特徴 |
| --- | --- | --- |
| [[大動脈弁閉鎖不全症]] | 拡張早期の高調性漸減性雑音 | 大動脈 → 左室への逆流。第2音の直後から聴く。 |
| [[大動脈弁狭窄症]] | 駆出性収縮期雑音 | 漸増漸減型で、頸動脈へ放散する。 |
| [[僧帽弁閉鎖不全症]] | 全収縮期雑音 | 心尖部で最強、左腋窩へ放散する。 |
| [[僧帽弁逸脱症]] | 収縮中期クリック＋収縮後期雑音 | 逸脱した時点から逆流が始まる。 |
| [[心室中隔欠損症]] | 全収縮期雑音 | 左室 → 右室への短絡。胸骨左縁で聴く。 |

- [[僧帽弁狭窄症]]・[[三尖弁狭窄症]]は、拡張期の低音性ランブルを呈する。
- [[肺動脈弁狭窄症]]は駆出性収縮期雑音、[[肺動脈弁閉鎖不全症]]は拡張期雑音を呈する。

## CBTチェック

- 拡張早期の高調性漸減性雑音は、大動脈弁または肺動脈弁の閉鎖不全を考える。
- [[僧帽弁逸脱症]]の雑音は全収縮期ではなく、クリック後に始まる収縮後期雑音である。
- [[全収縮期雑音]]の代表は僧帽弁閉鎖不全症・三尖弁閉鎖不全症・心室中隔欠損症である。
