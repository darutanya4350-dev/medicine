# ウイルス感染様式

| 分類            | イメージ                   | 代表ウイルス                                         |
| ------------- | ---------------------- | ---------------------------------------------- |
| **潜伏感染**      | 眠る(通常は増殖せず、刺激で再活性化)    | EBV、[CMV](CMV.md)、HSV、VZV、(一般的には[HIV](HIV.md)) |
| **慢性感染**      | 活動し続ける(免疫で排除されず持続的に産生) | B型肝炎ウイルス、C型肝炎ウイルス                      |
| **急性感染**      | 一過性、免疫で排除される           | インフルエンザウイルス、ノロウイルス、[アデノウイルス](アデノウイルス.md)         |
| **遅発性ウイルス感染** | 長い無症候期→緩徐に進行           | **[HIV](HIV.md)**、麻疹(SSPE)                           |

- **HIVは潜伏感染・慢性感染どちらとも言い切れず、「遅発性ウイルス感染」に分類されることが多い**(引っかけ注意)
