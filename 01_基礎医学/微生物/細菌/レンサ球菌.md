
## 最重要:溶血性による分類

| 分類       | 特徴                                                 |
| -------- | -------------------------------------------------- |
| **β溶血性** | 完全溶血。**化膿性レンサ球菌(Streptococcus pyogenes)**など、病原性が強い |
| **α溶血性** | 不完全溶血、緑色のリングを形成(肺炎球菌、口腔内レンサ球菌など)                   |
| **γ溶血性** | 溶血なし                                               |

## A群β溶血性レンサ球菌(Streptococcus pyogenes)

- 急性咽頭炎・急性扁桃炎の主要原因菌
- 皮膚感染症:**膿痂疹**
- **壊死性筋膜炎**:最も重要な重症感染症(劇症型溶血性レンサ球菌感染症)
- スーパー抗原による**猩紅熱**も引き起こす

A群β溶連菌が産生する溶血毒素であるストレプトリジンOに対する抗体。ASOともいう。

## 免疫学的合併症(感染後に遅れて発症)

|合併症|発症時期|症状|
|---|---|---|
|**急性糸球体腎炎**|感染後**1〜3週間**|乏尿・血尿・タンパク尿・高血圧・浮腫|
|**リウマチ熱**|感染後**10〜25日**|発熱・頻脈・関節症状・心筋炎|

- リウマチ熱を繰り返すと**心弁膜症**(特に僧帽弁)に至る

[レンサ球菌](レンサ球菌.md)の免疫学的合併症を、アレルギー反応の型で整理

| 合併症             | アレルギー分類       | 機序イメージ                       |
| --------------- | ------------- | ---------------------------- |
| **リウマチ熱**   | **II型アレルギー**  | 菌体成分に対する抗体が心筋・弁膜などの自己組織と交差反応 |
| **急性糸球体腎炎** | **III型アレルギー** | 免疫複合体が糸球体に沈着                 |

- A群β溶連菌感染症と診断された場合、**リウマチ熱予防**のため**アンピシリンを10日間**治療する
