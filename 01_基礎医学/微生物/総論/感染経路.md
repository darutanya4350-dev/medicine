

| 経路             | 代表ウイルス                                                     |
| -------------- | ---------------------------------------------------------- |
| **経口(糞口)**     | ノロウイルス、[ロタウイルス](../ウイルス/ロタウイルス.md)、[A型肝炎](../../../03_疾患/消化器/A型肝炎.md)ウイルス、[E型肝炎](../../../03_疾患/消化器/E型肝炎.md)ウイルス            |
| **空気感染**       | インフルエンザウイルス、[[風疹]]ウイルス、[ムンプスウイルス](../ウイルス/ムンプスウイルス.md)、[アデノウイルス](../ウイルス/アデノウイルス.md)        |
| 飛沫感染           | [[麻疹]]ウイルス、水痘ウイルス                                      |
| **血液・体液**      | [B型肝炎](../../../03_疾患/消化器/B型肝炎.md)ウイルス、[[C型肝炎]]ウイルス、[HIV](../ウイルス/HIV.md)                          |
| **性行為感染**      | [HIV](../ウイルス/HIV.md)、B型肝炎ウイルス、HPV、HSV                       |
| **[[母子感染]](垂直感染)** | B型肝炎ウイルス、[HIV](../ウイルス/HIV.md)、HSV、[CMV](../ウイルス/CMV.md)、風疹ウイルス、HTLV-1 |
| **蚊媒介(ベクター)**  | [日本脳炎ウイルス](../ウイルス/日本脳炎ウイルス.md)、デング熱ウイルス                                      |
| **動物咬傷**       | 狂犬病ウイルス                                                    |
| **接触感染**       | [[流行性角結膜炎]]、HSV                                        |

- 麻疹・水痘は**空気感染**(飛沫核感染)が特徴 → 個室・陰圧管理が必要
- 母子感染は経路が複数(経胎盤/産道/母乳)ある点に注意、特に[[HIV]]・HTLV-1は**母乳感染**もあり得る
