# 急性心筋梗塞の病理学的変化

> [[急性心筋梗塞]]では、心筋細胞は[[凝固壊死]]に陥り、炎症細胞浸潤・肉芽組織形成を経て線維性瘢痕へ置き換わる。心筋細胞は再生しない。

## 要点

| 発症後 | 主な組織学的変化 | 重要点 |
| --- | --- | --- |
| 〜12時間 | 明らかな光学顕微鏡所見に乏しい | 数時間後から波状線維・好酸性変化が現れる。 |
| 1〜3日 | 凝固壊死、好中球浸潤 | 横紋・核が消失する。 |
| 3〜7日 | マクロファージが壊死組織を除去 | 心筋壁が脆弱で、心破裂に注意する。 |
| 1〜2週 | 毛細血管・線維芽細胞を含む肉芽組織 | 膠原線維の沈着が始まる。 |
| 2か月以後 | 線維性瘢痕 | 細胞成分に乏しい治癒瘢痕となる。 |

- 壊死した心筋細胞は再生せず、欠損部は膠原線維による瘢痕で修復される。

## CBTチェック

- 心筋梗塞は[[凝固壊死]]を起こす。
- 発症後早期は好中球、数日後はマクロファージ、1〜2週後は肉芽組織が主体となる。
- 心破裂は、壊死組織の除去が進む発症3〜7日頃に起こりやすい。
