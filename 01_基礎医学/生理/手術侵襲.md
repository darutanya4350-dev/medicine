# 手術侵襲

> 手術による侵襲は神経・内分泌反応を起こし、循環・代謝・体液バランスを変化させる。代表的な反応は**高血糖・異化亢進・水分／Na貯留**である。

## 神経・内分泌反応

- 視床下部 → **CRH** → 下垂体前葉 → **ACTH** → 副腎皮質からコルチゾールが分泌される。
- 交感神経系 → 副腎髄質から[アドレナリン](../../06_薬剤/自律神経・循環/アドレナリン.md)が分泌され、頻脈・血管収縮をきたす。
- ADH・アルドステロンの分泌増加 → 尿量低下、水分・Na貯留、K排泄増加。

## 術後の経過

| 時期 | 目安 | 特徴 |
|---|---|---|
| **第1相：傷害期** | 術後2～4日 | 異化亢進、高血糖、尿量低下 |
| **第2相：変換期** | 術後3～7日 | 利尿が始まり、異化から同化へ移行 |
| **第3相：筋力回復期** | 術後2～5週 | タンパク同化が進み、筋力が回復 |
| **第4相：脂肪蓄積期** | 数か月～ | 脂肪が蓄積し、体重が回復 |

## CBTチェック

- 手術侵襲で高血糖をきたす要因 → **カテコールアミン・コルチゾール増加、インスリン感受性低下**
- 傷害期の体液変化 → **水分・Na貯留、尿量低下**
