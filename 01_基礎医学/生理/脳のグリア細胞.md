# 脳のグリア細胞

> 脳のグリア細胞は、神経細胞の支持、髄鞘形成、免疫、神経伝達物質の処理、脳脊髄液の流れなどを担う。細胞ごとの主な機能を対応させて覚える。

## 要点

| 細胞 | CBTで重要な機能 |
|---|---|
| 希突起膠細胞（オリゴデンドロサイト） | 中枢神経系の髄鞘形成 |
| 星状膠細胞（アストロサイト） | 神経伝達物質の取り込み・代謝、神経細胞の支持、血液脳関門の維持 |
| 小膠細胞（ミクログリア） | 中枢神経系の免疫担当細胞、貪食・異物除去 |
| 上衣細胞 | 脳室壁・脊髄中心管を裏打ちし、脳脊髄液の循環に関与 |
| 血管内皮細胞 | タイトジャンクションなどにより血液脳関門の主体を形成 |

- 中枢神経系の髄鞘は希突起膠細胞、末梢神経系の髄鞘は[[Schwann細胞]]が形成する。
- 小膠細胞は中胚葉由来で、中枢神経系のマクロファージとして働く。
- グルコースは血液脳関門の血管内皮細胞を通って脳内へ輸送される。小膠細胞の代表機能ではない。
- 血液脳関門は血管内皮細胞が主体で、基底膜・周皮細胞・星状膠細胞終足などがその機能を支える。

## CBTチェック

- 「髄鞘形成」→ 中枢は希突起膠細胞、末梢はSchwann細胞。
- 「神経伝達物質の取り込み・代謝」→ 星状膠細胞。
- 「中枢神経系の貪食・免疫」→ 小膠細胞。「グルコース輸送」ではない。
- 「脳室壁」→ 上衣細胞。「血液脳関門」→ 血管内皮細胞を中心に考える。

### 問題演習の振り返り（M3E 問題18101920）

前回の回答：A → 正答：C（知識不足：小膠細胞の主機能と血液脳関門の構成の整理不足）

1. **決め手**：小膠細胞は免疫・貪食担当であり、グルコース輸送を代表機能としない。
2. **CBT最小知識**：希突起膠細胞＝中枢の髄鞘、星状膠細胞＝神経伝達物質処理、小膠細胞＝免疫、上衣細胞＝脳室壁。
3. **選択肢からの連想**：Schwann細胞＝末梢の髄鞘、血管内皮細胞＝血液脳関門、星状膠細胞＝血液脳関門の維持。
4. **ひっかけポイント**：血液脳関門は星状膠細胞だけでなく、血管内皮細胞が主体。小膠細胞は免疫担当。
5. **一言暗記**：小膠細胞は「小さなマクロファージ」。
