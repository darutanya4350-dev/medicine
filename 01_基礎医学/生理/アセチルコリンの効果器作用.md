# アセチルコリンの効果器作用

> アセチルコリン（ACh）は自律神経の節前線維で共通して使われ、主に副交感神経の節後線維から放出される。副交感神経作用として、消化管運動・腺分泌・縮瞳・勃起などを起こす。

## 要点

| 臓器・機能 | アセチルコリンの主な作用 |
|---|---|
| 眼 | 縮瞳、調節（毛様体筋収縮） |
| 胃腸 | 蠕動・分泌促進 |
| 唾液腺・膵臓 | 分泌促進 |
| 陰茎 | 勃起を促進（副交感神経・NOを介する） |
| 心臓 | 心拍数低下、房室伝導抑制 |

- 自律神経節ではニコチン受容体、効果器では主にムスカリン受容体を介する。
- 例外として、交感神経の汗腺は節後線維からアセチルコリンが放出される。
- 勃起は副交感神経、射精は交感神経が中心であるため、アセチルコリン作用と射精を混同しない。

## CBTチェック

- 問題文の「陰茎 ― 勃起」→ アセチルコリン（副交感神経）を考える。
- 「散瞳・胃腸蠕動抑制・腺分泌抑制」→ 交感神経作用を考える。
- 「勃起＝副交感神経、射精＝交感神経」は頻出の対比。
- 問題文の「自律神経節前線維・副交感神経節後線維」→ いずれもアセチルコリン。詳細は[[自律神経の神経伝達物質]]を参照する。

### 問題演習の振り返り（M3E 問題22003920）

1. **決め手**：陰茎の副交感神経作用は勃起であり、射精ではない。
2. **CBT最小知識**：アセチルコリンは縮瞳、消化管運動・分泌促進、唾液・膵液分泌促進、勃起を起こす。
3. **選択肢からの連想**：散瞳、胃腸運動抑制、腺分泌抑制は交感神経作用を連想する。
4. **ひっかけポイント**：性機能では「勃起＝副交感神経」「射精＝交感神経」と分けて覚える。
5. **一言暗記**：AChは「縮瞳・分泌・蠕動・勃起」。
