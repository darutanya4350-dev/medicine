# 抗利尿ホルモン（ADH）

> 抗利尿ホルモン（antidiuretic hormone：ADH、バソプレシン）は、視床下部で合成され、下垂体後葉から放出される。腎集合管で水の再吸収を促進する。

## 要点

- 血漿浸透圧の上昇、循環血液量・血圧の低下で分泌が増加する。
- 集合管のV2受容体 → cAMP → AQP2（水チャネル） → 水再吸収↑、尿量↓、尿浸透圧↑。
- 高濃度では血管のV1受容体を介して血管収縮にも働く。
- 飲酒はADH分泌を抑制し、水利尿を増やす。
- ADH不足は[[中枢性尿崩症]]、腎の反応低下は[[腎性尿崩症]]、過剰は[[SIADH]]につながる。

## CBTチェック

- 「血漿浸透圧上昇」→ ADH分泌↑。
- ADH → 集合管V2受容体 → cAMP・AQP2 → 水再吸収↑。
- ADHは下垂体前葉ではなく、視床下部で合成され下垂体後葉から放出される。
- 飲酒 → ADH分泌↓ → 多尿。
