# 骨格筋線維タイプ

> 骨格筋線維は、収縮速度とエネルギー代謝の違いから、遅筋のType I線維と速筋のType II線維に大別される。

## 要点

|特徴|Type I（遅筋・酸化型）|Type II（速筋）|
|---|---|---|
|収縮|遅い|速い|
|代謝|酸化系優位、解糖系酵素活性は低い|解糖系優位（特にIIx/IIb）|
|ミトコンドリア・ミオグロビン|多い|Type Iより少ない|
|疲労|起こりにくい|起こりやすい|

- Type Iは毛細血管も豊富で、持続的な姿勢保持や持久運動に適する。
- Type IIaは酸化能も比較的高く、Type IIx/IIbはより解糖系・易疲労性である。

## CBTチェック

- Type IでType IIより正しい → **解糖系酵素活性が低い**。
- Type Iは「遅い・赤い・疲れにくい」：収縮速度は遅く、ミオグロビンとミトコンドリアが多い。
