# 血管作動性物質

> 血管径は、血管平滑筋を収縮・弛緩させる神経伝達物質、ホルモン、内皮由来物質によって調節される。CBTでは、**ムスカリン（アセチルコリン）は内皮を介して血管を拡張する**ことが重要である。

## 要点

| 物質 | 主な血管作用 | CBTでの機序 |
|---|---|---|
| セロトニン | 収縮 | 血小板などから放出され、血管平滑筋を収縮させる |
| エンドセリン | 強い収縮 | 血管内皮由来の強力な血管収縮ペプチド |
| ノルアドレナリン | 収縮 | 血管平滑筋のα1受容体を刺激する |
| ニコチン | 収縮傾向 | 交感神経節を刺激し、カテコールアミン放出を介する |
| ムスカリン・アセチルコリン | 拡張 | 内皮細胞のM3受容体 → NO産生 → 平滑筋弛緩 |

- ムスカリンの血管拡張は、**内皮が保たれていること**を前提とする。
- NOは平滑筋でcGMPを増加させ、血管を弛緩させる。[[ニトログリセリン]]もNOを介して作用する。

## CBTチェック

- 血管を弛緩させる選択肢として、ムスカリン（アセチルコリン）を選ぶ。
- ムスカリンの作用は、血管平滑筋への直接作用ではなく、内皮細胞のM3受容体を介するNO放出で説明する。
- エンドセリンとノルアドレナリンは血管収縮、NOは血管拡張である。
