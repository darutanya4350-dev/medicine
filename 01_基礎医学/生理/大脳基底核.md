# 大脳基底核

> 大脳基底核は、随意運動の開始・抑制や運動の調整に関わる。視床下核からの興奮性投射を直接受ける主な出力核は淡蒼球内節と黒質網様部である。

## 要点

- 主な構成：線条体（尾状核＋被殻）、淡蒼球、視床下核、黒質など。
- レンズ核＝被殻＋淡蒼球。線条体＝尾状核＋被殻。
- 直接路：大脳皮質 → 線条体 → 淡蒼球内節・黒質網様部 → 視床 → 大脳皮質。運動を促進する方向に働く。
- 間接路：線条体 → 淡蒼球外節 → 視床下核 → 淡蒼球内節・黒質網様部 → 視床。不要な運動を抑制する方向に働く。
- 視床下核から淡蒼球内節・黒質網様部への投射はグルタミン酸作動性で興奮性である。
- 黒質緻密部から線条体へドパミンが投射する（黒質線条体系）。ドパミンはD1受容体を介して直接路を促進し、D2受容体を介して間接路を抑制する方向に働く。
- 線条体内部の介在ニューロンにはアセチルコリン作動性ニューロンがあり、線条体から淡蒼球・黒質への主な出力はGABA作動性である。
- [[Parkinson病]]では黒質緻密部のドパミンが減少し、運動開始が困難になる。

## CBTチェック

- 「視床下核からの投射先」→ 淡蒼球内節・黒質網様部。図では淡蒼球を選ぶ。
- 「尾状核＋被殻」→ 線条体、「被殻＋淡蒼球」→ レンズ核。
- 問題文の「黒質緻密部の変性脱落」→ 線条体へのドパミン低下、Parkinson病を考える。
- 図の対応：①内包、②視床、③尾状核、④被殻、⑤淡蒼球。
- 「ノルアドレナリン作動性ニューロンが最多」→ [[脳幹神経核と神経伝達物質|青斑核]]。「ドパミン→線条体」→ 黒質緻密部。

### 問題演習の振り返り（M3E 問題18200810）

1. **決め手**：視床下核の直接投射先は淡蒼球内節・黒質網様部。選択肢では⑤の淡蒼球が該当する。
2. **CBT最小知識**：視床下核 → 淡蒼球内節・黒質網様部、線条体＝尾状核＋被殻、レンズ核＝被殻＋淡蒼球。
3. **選択肢からの連想**：内包は投射線維の通路、視床は大脳皮質への中継、尾状核・被殻は線条体を構成する。
4. **ひっかけポイント**：視床下核からの投射先を視床と混同しない。視床は大脳基底核の出力を受けて皮質へ中継する。
5. **一言暗記**：視床下核は淡蒼球内節を興奮させる。

### 問題演習の振り返り（M3E 問題18200660）

1. **決め手**：黒質からのドパミン作動性投射の終点は線条体。正答はD。
2. **CBT最小知識**：黒質緻密部 → 線条体のドパミン投射、線条体＝尾状核＋被殻。
3. **選択肢からの連想**：海馬は記憶、嗅球は嗅覚、小脳は運動協調、大脳は高次脳機能を担う。
4. **ひっかけポイント**：黒質からの投射先は小脳や大脳全体ではなく、基底核の入力核である線条体。
5. **一言暗記**：黒質のドパミンは線条体へ。
