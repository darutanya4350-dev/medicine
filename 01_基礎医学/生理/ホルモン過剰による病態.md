# ホルモン過剰による病態

> ホルモンは過剰になると、標的臓器の生理作用が増強された所見を示す。CBTではホルモンと典型的な過剰作用の組合せを覚える。

## 要点

| ホルモン過剰 | 代表的な病態・所見 |
|---|---|
| グルカゴン | 高血糖（低血糖ではない） |
| ガストリン | 胃酸過剰、[[Zollinger-Ellison症候群]]、消化性潰瘍 |
| エストロゲン | 静脈血栓塞栓症リスク上昇 |
| コルチゾール | 好中球増多、好酸球減少、[[クッシング症候群]] |
| サイロキシン（T4） | 代謝亢進、体重減少、血中コレステロール低下 |

## CBTチェック

- コルチゾール過剰 → 白血球（主に好中球）増多。炎症が改善したとは限らない。
- 好中球増多は、血管壁への接着を弱める「脱辺縁化（demargination）」と骨髄からの動員により血中好中球が一時的に増えるため。好酸球は組織・骨髄への再分布やアポトーシス促進により血中で減少する。
- サイロキシン過剰 → 脂質異常症ではなく、LDLコレステロール低下。
- ガストリン過剰 → 胃酸分泌亢進・難治性潰瘍。


## 覚え方

- コルチゾール　ストレスに対抗して炎症を抑える　血管壁から血中に流れ出る
