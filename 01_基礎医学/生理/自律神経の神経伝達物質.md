# 自律神経の神経伝達物質

> 自律神経では、すべての節前線維がアセチルコリン（ACh）を使う。節後線維は、副交感神経ではACh、交感神経では主にノルアドレナリンを使う。

## 要点

| 部位・線維 | 主な神経伝達物質 |
|---|---|
| 交感神経節前線維 | アセチルコリン |
| 交感神経節後線維 | ノルアドレナリン（汗腺はACh） |
| 副交感神経節前線維 | アセチルコリン |
| 副交感神経節後線維 | アセチルコリン |
| 副腎髄質への交感神経節前線維 | アセチルコリン → カテコールアミン分泌 |

- 自律神経節の受容体はニコチン受容体、効果器の副交感神経受容体は主にムスカリン受容体である。
- 中枢では、青斑核＝ノルアドレナリン、縫線核＝セロトニン、黒質緻密部＝ドパミンを対応させる。
- グルタミン酸は中枢神経系で重要な興奮性伝達物質だが、副交感神経節後線維の代表的伝達物質ではない。

## CBTチェック

- 「交感神経節前線維」→ ACh。
- 「副交感神経節後線維」→ ACh。「グルタミン酸」ではない。
- 「青斑核・縫線核・黒質」→ それぞれノルアドレナリン・セロトニン・ドパミン。

### 問題演習の振り返り（M3E 問題18200540）

前回の回答：E → 正答：D（知識不足：自律神経の節前・節後線維の整理不足）

1. **決め手**：交感神経節前線維はアセチルコリンを使う。副交感神経節後線維もAChである。
2. **CBT最小知識**：交感神経節前＝ACh、交感神経節後＝主にノルアドレナリン、副交感神経節前・節後＝ACh。
3. **選択肢からの連想**：青斑核＝ノルアドレナリン、縫線核＝セロトニン、黒質＝ドパミン。
4. **ひっかけポイント**：交感神経と副交感神経は節前線維が共通してACh。副交感神経節後線維もAChで、グルタミン酸ではない。
5. **一言暗記**：自律神経は「節前ACh、交感節後NE、副交感節後ACh」。
