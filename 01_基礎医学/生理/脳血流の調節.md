# 脳血流の調節

> 脳血流量は動脈血二酸化炭素分圧（PaCO₂）の影響を強く受ける。PaCO₂上昇は脳血管を拡張して脳血流を増加させ、頭蓋内圧を上昇させる。

## 要点

| 動脈血の変化 | 脳血管・脳血流への影響 |
|---|---|
| PaCO₂上昇 | 脳血管拡張、脳血流増加、頭蓋内圧上昇 |
| PaCO₂低下 | 脳血管収縮、脳血流低下 |
| PaO₂低下 | 高度な低酸素で脳血管拡張・脳血流増加 |
| PaO₂上昇 | 通常、脳血流への影響は小さい |
| 動脈血pH低下 | 脳血流増加方向。ただし設問ではPaCO₂が最重要 |

- CO₂は血液脳関門を通過し、髄液・脳血管周囲のpHを変化させて血管径に影響する。
- 過換気によるPaCO₂低下は脳血管を収縮させ、脳血流を低下させる。
- PaO₂低下による脳血管拡張は、通常の軽度低下よりも高度低酸素で明瞭になる。

## CBTチェック

- 「脳血流量を最も強く増加させる」→ PaCO₂上昇。
- 「過換気」→ PaCO₂低下 → 脳血管収縮 → 脳血流低下。
- 「PaCO₂上昇＋意識障害・頭痛」→ 脳血流増加と頭蓋内圧上昇を連想する。

### 問題演習の振り返り（M3E 問題08500170）

1. **決め手**：脳血流の最も強い調節因子はPaCO₂で、上昇すると脳血流が増加する。
2. **CBT最小知識**：PaCO₂↑＝脳血管拡張・脳血流↑、PaCO₂↓＝脳血管収縮・脳血流↓。
3. **選択肢からの連想**：高度低酸素では脳血流が増加するが、酸素分圧上昇の影響は小さい。pH上昇は脳血流増加の方向ではない。
4. **ひっかけポイント**：動脈血pHの変化と、CO₂が髄液pHを介して生じる脳血管反応を混同しない。
5. **一言暗記**：脳血流はCO₂で増え、過換気で減る。
