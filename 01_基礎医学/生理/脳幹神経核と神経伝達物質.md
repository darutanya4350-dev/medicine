# 脳幹神経核と神経伝達物質

> 脳幹の神経核は、特徴的な神経伝達物質と機能をもつ。ノルアドレナリン作動性ニューロンの最大の集団は橋上部の青斑核にある。

## 要点

| 部位 | 主な神経伝達物質・機能 |
|---|---|
| 青斑核 | ノルアドレナリン。覚醒、警戒、注意、ストレス反応 |
| 黒質緻密部 | ドパミン。線条体へ投射し、運動調節に関与 |
| 赤核 | 小脳・大脳皮質から入力を受け、赤核脊髄路などを介して運動調節 |
| 淡蒼球 | GABA作動性。線条体から抑制性入力を受け、視床へ抑制性に出力 |
| 線条体 | 尾状核＋被殻。出力は主にGABA、内部の介在ニューロンにアセチルコリン |

- 青斑核（locus coeruleus）は橋上部・第4脳室底の外側部に位置する。
- 黒質緻密部 → 線条体のドパミン投射が低下すると、[[Parkinson病]]の無動などにつながる。
- 淡蒼球と線条体は大脳基底核の構成要素であり、運動の開始・抑制を調節する。

## CBTチェック

- 「ノルアドレナリン作動性ニューロンが最多」→ 青斑核。
- 「ドパミン → 線条体」→ 黒質緻密部・黒質線条体系。
- 「GABAで視床を抑制」→ 淡蒼球内節・黒質網様部。
- 「線条体内のアセチルコリン」→ 介在ニューロン。「線条体からの出力」→ GABA。
- 「青斑核・縫線核・黒質」→ ノルアドレナリン・セロトニン・ドパミン。

### 問題演習の振り返り（M3E 問題18401460）

1. **決め手**：ノルアドレナリン作動性ニューロンの最大集団は橋上部の青斑核。
2. **CBT最小知識**：青斑核＝ノルアドレナリン、黒質緻密部＝ドパミン、線条体＝GABA・アセチルコリン。
3. **選択肢からの連想**：黒質はドパミン、赤核は運動調節、淡蒼球はGABA、線条体は基底核回路を担う。
4. **ひっかけポイント**：黒質はドパミン作動性ニューロンを多く含むが、ノルアドレナリンの主な中枢ではない。
5. **一言暗記**：ノルアドレナリンは青斑核、ドパミンは黒質。
