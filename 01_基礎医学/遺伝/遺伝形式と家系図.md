# 遺伝形式と家系図

> 家系図では、発症者の男女比、世代ごとの連続性、父から息子への伝達、母系のみの伝達を確認する。本ノートでは、CBTで読み替えられるよう「顕性（優性）」「潜性（劣性）」を併記する。

## 家系図の読み方

- □は男性、○は女性、塗りつぶしは発症者、斜線は死亡、矢印は発端者（proband）を表す。
- **縦に連続**して発症者がみられれば顕性、**同胞に集中**して両親が健常なら潜性を考える。
- 遺伝確率は各妊娠で独立しており、前の子の結果によって次の子の確率は変わらない。
- 集団における[[常染色体潜性遺伝]]疾患の罹患頻度から保因者頻度を見積もるときは、[[Hardy-Weinberg平衡]]を用いる。

## CBT頻出の遺伝形式

| 遺伝形式 | 想定される家系図・典型的な確率 | 代表疾患 |
|---|---|---|
| 常染色体顕性（優性） | 男女同程度、世代を越えて縦に連続し、父→息子もあり得る。ヘテロ接合体患者×健常者では各児1/2 | [[Huntington病]]、[[Marfan症候群]]、[[神経線維腫症1型]] |
| 常染色体潜性（劣性） | 男女同程度、健常な両親から同胞に発症者が集まりやすい。保因者同士では各児1/4が発症、1/2が保因者 | [[フェニルケトン尿症]]、[[Wilson病]]、[[脊髄性筋萎縮症]] |
| [[X連鎖劣性遺伝\|X連鎖潜性（劣性）]] | 男性に多く、父→息子はない。保因者母×健常父では男児の1/2が発症、女児の1/2が保因者 | [[血友病]]A・B、[[Duchenne型筋ジストロフィー]]、[[Hunter症候群]] |
| X連鎖顕性（優性） | 父→息子はない。患者父×健常母では娘全員が発症し、息子は発症しない。ヘテロ接合体患者母では男女各1/2 | [[X連鎖低リン血症性くる病]] |
| ミトコンドリア遺伝 | 男女とも発症し得るが、母からのみ伝わる。患者父からは伝わらず、患者母の全児が病的mtDNAを受け継ぎ得る | [[MELAS]]、[[Leber遺伝性視神経症]] |

- **Y連鎖遺伝**では男性のみが発症し、患者父から息子全員へ伝わる。
- 家系図が典型像にならない要因として、[[新生突然変異]]、浸透率低下、発症年齢の遅さ、家族人数の少なさがある。ミトコンドリア病ではヘテロプラスミーにより症状の有無や重症度も異なる。

## CBTチェック

- 提示画像のように、男女とも発症し、複数世代に連続し、患者と健常者の子が約1/2で発症する家系は**常染色体顕性遺伝**を考える。
- **父→息子なし**ならX連鎖、**患者父の娘全員が発症**ならX連鎖顕性、**母系のみ**ならミトコンドリア遺伝を考える。
- [[Huntington病]]は常染色体顕性、[[フェニルケトン尿症]]は常染色体潜性、[[血友病]]・[[Duchenne型筋ジストロフィー]]はX連鎖潜性である。[[糖尿病]]の多くは単一遺伝子疾患ではなく多因子遺伝である。
