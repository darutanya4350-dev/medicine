# Hardy-Weinberg平衡

> **Hardy-Weinberg平衡**は、集団内の対立遺伝子頻度から遺伝子型頻度を推定する考え方である。CBTでは、[[常染色体潜性遺伝]]疾患の罹患頻度から保因者頻度を求める計算に用いる。

## 計算方法

- 正常対立遺伝子の頻度を **p**、病的対立遺伝子の頻度を **q** とすると、**p + q = 1** である。
- 遺伝子型頻度は、正常ホモ接合体 **p²**、ヘテロ接合体（保因者） **2pq**、病的ホモ接合体 **q²** となる。
- 常染色体潜性遺伝疾患では、罹患頻度が **q²** に相当する。罹患頻度から平方根をとってqを求め、**2pq = 2q(1−q)** に代入する。
- まれな疾患ではpはほぼ1であるため、保因者頻度は **2pq ≒ 2q** と近似できる。

**例：罹患頻度が1/40,000の場合**

`q² = 1/40,000 → q = 1/200 → p = 199/200 → 保因者頻度 2pq = 2 × 199/200 × 1/200 ≒ 1/100`

## CBTチェック

- 常染色体潜性遺伝疾患では、**罹患頻度 = q²、保因者頻度 = 2pq** と対応させる。
- 罹患頻度1/10,000ならq = 1/100、保因者頻度は約1/50である。
- この推定は無作為交配、選択・突然変異・移住の影響が小さいことなどを仮定する。家系内の再発率そのものを求める式ではない。
