# 胎児期の発生

> 胎生期の主な器官形成を、週数と先天異常を結び付けて整理する年表である。**胎生週**は受精後の週数、**妊娠週数**は最終月経開始日からの週数で、通常は約2週の差がある。

## 発生年表

| 胎生週（受精後） | 主な発生・関連事項 |
| --- | --- |
| 6〜8週 | [[口唇口蓋裂]]：口唇が形成される時期。内側鼻突起と上顎突起の癒合不全で口唇裂を生じる。 |
| 8〜12週 | [[口唇口蓋裂]]：口蓋が形成される時期。左右の口蓋突起の癒合不全で口蓋裂を生じる。 |

### 妊娠週数でみる初期発生

| 妊娠週数（最終月経から） | 主な発生・関連事項 |
| --- | --- |
| 4〜5週 | 経腟超音波で子宮内の[[妊娠初期超音波検査|胎嚢]]を確認し始める。 |
| 10週頃 | 四肢の自発運動が超音波で観察されうる。 |
| 12週頃 | 胎児は羊水を嚥下し、腎臓で産生した尿を羊水中へ排出する。胎便は腸管内に蓄積し、通常は出生後に排泄される。 |
| 34週頃 | 肺[[サーファクタント]]が肺胞虚脱を防ぐのに十分な量となり、[[新生児呼吸窮迫症候群]]のリスクが低下する。 |

## CBTチェック

- 口唇は胎生6〜8週頃、口蓋は胎生8〜12週頃に形成される。
- 先天異常は、障害された器官形成の時期と結び付けて覚える。
- 妊娠週数と胎生週は約2週ずれる。胎内での胎便排泄は通常ではない。
