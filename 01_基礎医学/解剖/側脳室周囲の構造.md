# 側脳室周囲の構造

> [[大脳基底核]]は、レンズ核（被殻＋淡蒼球）と尾状核に分けて考えると、側脳室との位置関係を整理しやすい。

## 基底核のグループ分け

- **レンズ核**＝被殻＋淡蒼球。淡蒼球が内側、被殻が外側に位置し、前額断ではレンズ状の塊に見える。
- **尾状核**＝レンズ核の内側〜上側をC字状に取り囲む細長い構造。頭部は側脳室前角〜体部の外側壁に接し、尾部は側頭角上方を走る。
- レンズ核は内包の外側にあり、側脳室とは内包などを隔てて直接接しない。

```text
側脳室（体部）
      │
尾状核（頭部）──側脳室の外側壁に接する
      │
   内包（白質）
      │
被殻＋淡蒼球──レンズ核（側脳室とは接しない）
```

## 側脳室に接する構造

- **尾状核**：側脳室の前角・体部に沿い、頭部が外側壁を形成する。尾部は側頭角上方を走る。
- **海馬**：側脳室下角（側頭角）の床〜内側壁に沿う。尾状核と同様にC字状の走行を示す。
- **扁桃体**：側頭角の前方（側頭葉先端寄り）に位置し、側脳室下角に接する。
- **被殻・淡蒼球**：内包の外側にあるレンズ核で、側脳室には直接接しない。
- **黒質**：[[中脳の構造]]で、側脳室から離れている。

## CBTチェック

- 「側脳室に接する」→ **尾状核・海馬・扁桃体**。
- 「レンズ核」→ **被殻＋淡蒼球**。内側が淡蒼球、外側が被殻。
- 「C字状に側脳室に沿う」→ 尾状核（前角〜体部〜側頭角上方）と海馬（下角の床）を考える。
- 「内包を挟んで側脳室から離れる」→ 被殻・淡蒼球を考える。
