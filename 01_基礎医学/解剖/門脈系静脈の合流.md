# 門脈系静脈の合流

> **門脈系**は、消化管・脾臓・膵臓・胆嚢などの静脈血を集めて肝臓へ運ぶ。基本形は、**上腸間膜静脈＋脾静脈 → 門脈**である。

## 肝臓から遠い順の合流

1. **末梢静脈 → 3本の主要静脈**
   - 空腸・回腸、虫垂、盲腸、上行結腸、横行結腸右側 → **上腸間膜静脈**
   - 上直腸、S状結腸、下行結腸 → **下腸間膜静脈**
   - 脾臓、胃底部、胃大彎左側、膵体尾部 → **脾静脈**
2. **下腸間膜静脈 → 脾静脈へ合流**
   - 典型型では、下腸間膜静脈が脾静脈へ合流する。
3. **脾静脈＋上腸間膜静脈 → 門脈**
   - 膵頸部の背側で合流して門脈を形成する。
4. **門脈 → 右・左門脈枝 → 肝類洞**
   - 肝類洞を通った血液は中心静脈、肝静脈を経て下大静脈へ流れる。

```text
上直腸・S状結腸・下行結腸
        ↓
下腸間膜静脈 ─→ 脾静脈 ←─ 脾臓・胃底部・膵体尾部
                      ＋
上腸間膜静脈 ←─ 小腸・虫垂・右側結腸
                      ↓
                    門脈
                      ↓
             右・左門脈枝 → 肝類洞
```

## CBTチェック

- 下腸間膜静脈は通常、脾静脈へ合流するが、上腸間膜静脈や門脈合流部へ入る変異もある。
- 左・右胃静脈、胆嚢静脈などは門脈本幹または門脈枝へ直接合流しうる。
- [[肝静脈]]は門脈へ合流せず、肝臓から下大静脈へ血液を出す静脈である。
