# 泌尿生殖器の解剖

> 国試では、**尿管の3狭窄**、**射精管の開口**、**副腎静脈の合流**、**精巣動脈の起始**、**尿膜管の付着**が頻出である。

## 要点

| 部位 | 正しい理解 | よくある誤り |
| --- | --- | --- |
| **尿管** | **3か所**に生理的狭窄（腎盂尿管移行部・総腸骨動脈交叉部・膀胱貫通部） | 狭窄がない／1か所だけ |
| **射精管** | 精管＋精嚢管の合流。前立腺内を走り、**前立腺部尿道**の精丘に開口 | 尿道球部・膜部に開口 |
| **右副腎静脈** | **下大静脈**に直接流入 | 右腎静脈に流入 |
| **左副腎静脈** | **左腎静脈**に流入 | — |
| **精巣動脈** | **腹大動脈**から直接分枝（L2付近） | 内腸骨動脈から分枝 |
| **尿膜管** | 胎生期の尿膜（=allantoic duct）の遺残。**膀胱頂部**に付着 | 膀胱三角部に開口 |

- 尿管狭窄部は[[尿管結石]]の嵌頓好発部位。閉塞→[[水腎症]]。
- 男性尿道は前立腺部・膜部・海綿体部に分け、前立腺部に精丘がある。
- 勃起と射精の自律神経支配は[[勃起と射精]]を参照する。
- 尿膜管遺残は臍部からの尿漏（臍尿管瘘）などの原因になりうる。

## CBTチェック

- 正しい組合せ：**射精管→前立腺部尿道**、**尿管→3狭窄**（114回 D-13）。
- 右副腎静脈＝**IVC直接**、左副腎静脈＝**左腎静脈**。
- 精巣動脈＝**腹大動脈**、精巣静脈＝右は下大静脈、左は左腎静脈。
- 尿膜管＝**膀胱頂**（三角部ではない）。
