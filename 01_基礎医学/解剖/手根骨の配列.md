# 手根骨の配列

> 手根骨は8個で、近位列4個と遠位列4個に分かれる。各列は橈側（親指側）から尺側（小指側）へ並ぶ。

## 要点

|列|橈側 → 尺側|
|---|---|
|近位列|舟状骨 → 月状骨 → 三角骨 → 豆状骨|
|遠位列|大菱形骨 → 小菱形骨 → 有頭骨 → 有鉤骨|

- まず「近位列／遠位列」を分け、次に各列を「橈側→尺側」で並べると、語呂を忘れても位置関係から復元できる。
- 手根骨8個の英語名は、近位列が scaphoid・lunate・triquetrum・pisiform、遠位列が trapezium・trapezoid・capitate・hamate である。[解剖学資料](https://www.ncbi.nlm.nih.gov/books/NBK535382/)

## CBTチェック

- 「舟状骨→月状骨→三角骨→豆状骨」＝近位列。
- 「大菱形骨→小菱形骨→有頭骨→有鉤骨」＝遠位列。
- 橈側（親指側）から数えると、近位列1番は舟状骨、遠位列1番は大菱形骨。
