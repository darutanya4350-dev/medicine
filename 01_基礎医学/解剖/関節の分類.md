# 関節の分類 － CBT必須まとめ

---

## 3. 運動軸による分類（最重要・頻出）

滑膜関節は運動軸の数によって分類される。**「軸の数」と「代表例」を必ずセットで暗記する。**

|軸性|関節型|運動様式|代表例|
|---|---|---|---|
|**一軸性**|蝶番関節（ginglymus）|屈曲・伸展のみ|腕尺関節、指節間関節、距腿関節（足関節）|
|**一軸性**|[車軸関節](車軸関節.md)（trochoid joint）|回旋のみ|**正中環軸関節**、**上橈尺関節**、下橈尺関節|
|**二軸性**|顆状関節（ellipsoid/condylar joint）|屈伸＋外転内転|橈骨手根関節、中手指節関節、環椎後頭関節|
|**二軸性**|鞍関節（saddle joint）|屈伸＋外転内転（回旋は制限）|母指手根中手関節、胸鎖関節|
|**多軸性（三軸性）**|球関節（spheroidal joint）|あらゆる方向|肩関節、股関節|
|**多軸性**|平面関節（plane joint）|主に滑走運動|肩鎖関節、椎間関節（一部）、手根間・足根間関節|

### 覚え方のポイント

- 「回旋のみ＝車軸関節」→ 正中環軸関節（歯突起周囲の回旋）、上橈尺関節（回内外）
- 「屈伸のみ＝蝶番関節」→ 腕尺関節、指節間関節
- 球関節は肩・股のみ（多軸性で最も可動域が大きい）
- 母指CM関節と胸鎖関節は鞍関節（形が特殊なので頻出）

## 4. 関節円板・関節半月を有する関節（CBT頻出）

関節円板／半月は関節腔を分割し、適合性向上・荷重分散・複合運動を可能にする線維軟骨構造。

|関節|構造名|特徴|
|---|---|---|
|顎関節|関節円板|上関節腔（滑走）・下関節腔（回転）に分離|
|胸鎖関節|関節円板|鞍関節だが円板により多軸性運動が可能|
|橈骨手根関節（遠位橈尺関節）|関節円板（TFCC の一部）|尺骨頭と手根骨を隔てる|
|膝関節|関節半月（内側・外側）|円板ではなく「半月」と呼ばれる点に注意|

※ 肩関節・腕尺関節・指節間関節には関節円板は**存在しない**（頻出のひっかけ）。

## 5. その他CBT頻出ポイント

- **前腕の回内・回外**：上橈尺関節＋下橈尺関節（ともに車軸関節）が連動して行う運動。
- **肩関節と股関節**：ともに球関節だが、肩関節は関節窩が浅く可動域重視、股関節は臼蓋が深く安定性重視。
- **顎関節**：構造上は顆状関節に近いが、関節円板により複合運動（回転＋滑走）を行う特殊な関節。
- **環椎後頭関節**：顆状関節（うなずき運動＝屈伸＋わずかな側屈）。正中環軸関節（車軸関節、回旋運動）と機能的に対比して覚える。
- **半関節と可動関節の違い**：半関節は関節腔が不完全またはスリット状で可動性が乏しい（恥骨結合など）。
- 線維軟骨結合の代表は[[線維軟骨結合]]を参照（椎間円板・恥骨結合など）。

## 6. 一問一答形式チェックリスト

- [ ] 車軸関節の代表例を2つ挙げよ → 正中環軸関節、上（下）橈尺関節
- [ ] 蝶番関節の代表例を2つ挙げよ → 腕尺関節、指節間関節
- [ ] 鞍関節の代表例を2つ挙げよ → 母指手根中手関節、胸鎖関節
- [ ] 関節円板を有する関節を3つ挙げよ → 顎関節、胸鎖関節、橈骨手根関節
- [ ] 球関節を2つ挙げよ → 肩関節、股関節
- [ ] 前腕回内外に関与する関節型は？ → 車軸関節（上・下橈尺関節）
- [ ] 「運動軸が2つ」→ 顆状関節の[[橈骨手根関節]]（屈曲・伸展＋橈屈・尺屈）を考える。
- [ ] 「上橈尺関節」→ 車軸関節（前腕の回内・回外）を考える。
