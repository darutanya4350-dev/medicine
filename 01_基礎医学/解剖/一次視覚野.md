# 一次視覚野

> 一次視覚野（V1、Brodmann 17野）は後頭葉の鳥距溝周囲にあり、外側膝状体から視放線を介して視覚情報を受け取る。

## 要点

- 視覚情報の経路：網膜 → 視神経 → 視交叉 → 視索 → 外側膝状体 → 視放線 → 一次視覚野。
- 一次視覚野は後頭葉にあり、Brodmann 17野（線条野）に相当する。
- 外側膝状体からの入力は主に大脳皮質第Ⅳ層へ入り、顆粒細胞が発達している。
- 一次視覚野の障害では、典型的に反対側の同名半盲をきたす。
- 瞳孔対光反射は一次視覚野を経由せず、前視蓋核を介するため保たれる。

## CBTチェック

- 「外側膝状体 → 視放線」→ その終点は後頭葉の一次視覚野（17野）。
- 「17野」→ 一次視覚野・後頭葉を考える。「頭頂葉」ではない。
- 「視覚野障害でも瞳孔反応が保たれる」→ 視覚路と瞳孔対光反射路を区別する。
- 本設問では「明暗の感覚は残る」を正答として扱うが、厳密には意識的な視覚と瞳孔対光反射は別の経路である。
