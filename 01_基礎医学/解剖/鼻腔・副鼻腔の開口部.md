# 鼻腔・副鼻腔の開口部

> 副鼻腔は鼻道へ、[[鼻涙管]]は下鼻道へ開口する。[[耳管]]は鼻腔ではなく上咽頭に開く。

## 要点

| 開口部 | 開く部位 |
|---|---|
| 前頭洞・上顎洞・前／中篩骨洞 | 中鼻道 |
| 後篩骨洞 | 上鼻道 |
| 蝶形骨洞 | 蝶篩陥凹（上鼻甲介の上後方） |
| 鼻涙管 | 下鼻道 |
| 耳管 | 上咽頭（耳管咽頭口） |

- 前頭洞は鼻前頭管を通り、前頭陥凹または篩骨漏斗を経て中鼻道へ開く。
- 上顎洞は半月裂孔後方の自然口から中鼻道へ開く。
- 眼から流れた涙が鼻へ出るのは、鼻涙管が下鼻道に開くためである。

## CBTチェック

- 「下鼻道に開口するもの」→[[鼻涙管]]。
- 「耳管の開口部」→上咽頭。
