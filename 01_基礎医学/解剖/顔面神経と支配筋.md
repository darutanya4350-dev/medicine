# 顔面神経と支配筋

> 顔面神経（第Ⅶ脳神経）は主に表情筋を支配する。運動線維のほか、舌前2/3の味覚、涙腺・顎下腺・舌下腺への副交感線維も含む。

## 要点

| 筋・機能 | 支配神経 | CBTでの対応 |
|---|---|---|
| 眼輪筋 | 顔面神経（Ⅶ） | 閉眼 |
| 咬筋 | 下顎神経（Ⅴ₃） | 下顎を挙上し閉口 |
| 胸鎖乳突筋 | 副神経（Ⅺ） | 頭部を反対側へ回旋 |
| 咽頭筋 | 主に迷走神経（Ⅹ、疑核） | 嚥下・咽頭運動。茎突咽頭筋のみ舌咽神経（Ⅸ） |
| 眼瞼挙筋 | 動眼神経（Ⅲ） | 開眼 |

- 顔面神経の運動：前頭筋、眼輪筋、口輪筋、頬筋、広頸筋などの表情筋、アブミ骨筋、茎突舌骨筋、顎二腹筋後腹。
- 顔面神経の味覚：舌前2/3（鼓索神経）。
- 顔面神経の副交感：涙腺、顎下腺、舌下腺などの分泌。
- 「口を閉じる」は、口唇を閉じる口輪筋なら顔面神経、下顎を挙上する閉口運動なら下顎神経と区別する。

## CBTチェック

- 「閉眼できない」→ 眼輪筋・顔面神経麻痺を考える。
- 「咀嚼・閉口」→ 咬筋などの咀嚼筋・下顎神経（Ⅴ₃）。
- 「開眼」→ 眼瞼挙筋・動眼神経（Ⅲ）。
- 「頭部を反対側へ回旋」→ 胸鎖乳突筋・副神経（Ⅺ）。
- 「嚥下・咽頭運動」→ 疑核を経由する舌咽神経（Ⅸ）・迷走神経（Ⅹ）。

### 問題演習の振り返り（顔面神経支配筋の問題）

1. **決め手**：眼輪筋は表情筋で、閉眼を行い、顔面神経が支配する。
2. **CBT最小知識**：顔面神経＝表情筋、三叉神経Ⅴ₃＝咀嚼筋、動眼神経Ⅲ＝眼瞼挙筋、副神経Ⅺ＝胸鎖乳突筋・僧帽筋。
3. **選択肢からの連想**：咬筋は下顎神経、咽頭筋は主に迷走神経、眼瞼挙筋は動眼神経。
4. **ひっかけポイント**：「閉口」は口唇を閉じる口輪筋と、下顎を挙上する咬筋を区別する。
5. **一言暗記**：表情筋は顔面神経、咀嚼筋は三叉神経。
