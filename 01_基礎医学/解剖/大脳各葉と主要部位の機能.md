# 大脳各葉と主要部位の機能

> 脳の局在問題では、症状から主な機能を連想し、対応する大脳葉・脳部位を考える。記銘力は側頭葉内側部の海馬と関連が深い。

## 要点

| 部位 | CBTで重要な機能・障害 |
|---|---|
| 前頭葉 | 遂行機能、判断、計画、行動抑制。障害で脱抑制・判断力低下 |
| 頭頂葉 | 体性感覚の統合。優位半球障害で手指失認・左右失認・失算・失書 |
| 側頭葉 | 聴覚、言語理解、記憶。内側側頭葉・海馬の障害で記銘力低下 |
| 後頭葉 | 視覚。一次視覚野はBrodmann 17野 |
| 小脳 | 運動協調、姿勢、筋緊張の調整 |

- 脳幹は大脳・小脳・脊髄を連絡し、脳神経核や意識・生命維持に関わる経路を含む。
- 「記銘」は新しい情報を覚える過程で、海馬を含む側頭葉内側部が重要である。
- 「視覚」→ [[一次視覚野]]、「情動・記憶」→ [[大脳辺縁系]]も連想する。

## CBTチェック

- 「記銘力・近時記憶の低下」→ 側頭葉内側部・海馬を考える。
- 「手指失認・左右失認・失算・失書」→ 優位半球の頭頂葉を考える。
- 「視覚障害」→ 後頭葉・一次視覚野、「運動失調」→ 小脳を考える。
- 「読字・書字の障害」＋「音声理解は保たれる」→ 優位半球頭頂葉・角回を考える。

### 問題演習の振り返り（M3E 問題18401470）

前回の回答：D → 正答：B（知識不足：記憶機能の局在の整理不足）

1. **決め手**：設問の「記銘力の低下」。側頭葉内側部の海馬が記銘に重要である。
2. **CBT最小知識**：側頭葉は聴覚・言語理解・記憶、特に海馬は記銘に関与する。
3. **選択肢からの連想**：脳幹は生命維持・伝導、後頭葉は視覚、頭頂葉は感覚統合・Gerstmann症候群、小脳は運動協調。
4. **ひっかけポイント**：頭頂葉の失算・失書などの高次機能障害と、側頭葉の記憶障害を混同しない。
5. **一言暗記**：記銘力低下は側頭葉内側部・海馬。
