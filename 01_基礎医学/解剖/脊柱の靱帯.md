# 脊柱の靱帯

> 脊柱の連結は、椎体・椎弓・突起のどの部分をつなぐかで靱帯を覚える。

## 要点

| 連結部位 | 靱帯 |
| --- | --- |
| 椎体の前面・後面 | 前縦靱帯・後縦靱帯 |
| 隣接する椎弓 | 黄色靱帯（ligamentum flavum） |
| 隣接する棘突起の間 | 棘間靱帯 |
| 棘突起の先端 | 棘上靱帯 |
| 横突起の間 | 横突間靱帯 |

- 黄色靱帯は椎弓間を連結し、脊柱管の後方壁の一部をつくる。
- 後縦靱帯は椎体後面を走り、脊柱管の前方側に位置する。

## CBTチェック

- 「椎体」→ 前縦靱帯・後縦靱帯。
- 「椎弓」→ 黄色靱帯。
- 「棘突起」→ 棘間靱帯（先端なら棘上靱帯）。
