# 下肢の運動と末梢神経

> 下肢の運動は、主働筋と末梢神経をセットで覚える。足趾背屈は前区画筋・深腓骨神経が手掛かりである。

## 要点

| 運動 | 主な筋 | 主な神経 |
| --- | --- | --- |
| 股関節屈曲 | [[腸腰筋]] | 大腿神経など |
| 股関節伸展 | 大殿筋 | 下殿神経 |
| 股関節外転 | 中殿筋 | 上殿神経 |
| 股関節内転 | 内転筋群 | 閉鎖神経 |
| 膝関節伸展 | 大腿四頭筋 | 大腿神経（L3〜4） |
| 足関節背屈 | 前脛骨筋 | 深腓骨神経（L4〜5） |
| 足趾背屈 | 長母趾伸筋・長指伸筋 | 深腓骨神経（L5〜S1） |
| 足関節底屈 | 下腿三頭筋 | 脛骨神経（S1〜2） |

- [[総腓骨神経麻痺]]では、深腓骨神経支配の背屈・足趾伸展と、浅腓骨神経支配の外反が障害され、下垂足をきたす。感覚障害は下腿外側・足背に生じやすい。
- 腸腰筋のうち腸骨筋は大腿神経、大腰筋は[[腰神経叢]]の枝が主に支配する。設問で「腸骨筋」とあれば大腿神経を選ぶ。
- 大内転筋は二重神経支配で、内転部が閉鎖神経、ハムストリング部が坐骨神経（脛骨部）支配である。

## CBTチェック

- 問題文の「足趾背屈＋伸筋群麻痺」→ 深腓骨神経（腓骨神経）障害。
- 「膝伸展」→ 大腿神経。「足関節底屈」→ 脛骨神経。
- 「足関節背屈＋母趾伸展」→ L5神経根障害も連想する。
- 「足関節背屈＋足部外反低下」→ 総腓骨神経麻痺。「股関節外転や足部内反も低下」→ L5神経根障害を考える。
- 「腸骨筋―大腿神経」→ 正しい組合せ。大殿筋は下殿神経、小殿筋は上殿神経、前脛骨筋は深腓骨神経、内閉鎖筋は内閉鎖筋神経。
- 「二重神経支配」→ 大内転筋（閉鎖神経＋坐骨神経脛骨部）を考える。
