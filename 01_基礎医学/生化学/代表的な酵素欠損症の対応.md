# 代表的な酵素欠損症の対応

> CBTでは「疾患名―欠損酵素―典型所見」の対応を問う。選択肢の酵素名から疾患と決め手を逆引きする。

## 要点

- [[酸性α-グルコシダーゼ]]欠損 → [[Pompe病]]（糖原病II型）：筋力低下、乳児型では心筋肥大。
- [[グルコース-6-リン酸脱水素酵素]]（G6PD）欠損 → [[G6PD欠損症]]：X連鎖性、感染・薬剤などの酸化ストレスで溶血。
- [[イズロン酸-2-スルファターゼ]]欠損 → [[Hunter症候群]]（ムコ多糖症II型）：X連鎖性、角膜混濁を認めない。
- [[21-水酸化酵素]]欠損 → [[先天性副腎皮質過形成]]：コルチゾール低下、アンドロゲン増加、重症例では塩喪失。
- [[HGPRT]]欠損 → [[Lesch-Nyhan症候群]]：プリンサルベージ障害による高尿酸血症、神経症状、自傷行為。

## CBTチェック

- 「男児＋高尿酸血症＋不随意運動・自傷行為」→ HGPRT欠損による[[Lesch-Nyhan症候群]]。
- Hunter症候群・G6PD欠損症・Lesch-Nyhan症候群はX連鎖性である。
- 21-水酸化酵素欠損は副腎ステロイド合成異常であり、プリン代謝異常ではない。
