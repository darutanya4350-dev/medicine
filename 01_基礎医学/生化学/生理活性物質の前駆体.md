# 生理活性物質の前駆体

> アミノ酸やヘム関連物質は、神経伝達物質・ホルモン・胆汁色素などの原料になる。原料→生成物の向きを覚える。

## 要点

| 原料 | 生成物・経路 |
|---|---|
| チロシン | L-DOPA → ドパミン → ノルアドレナリン → アドレナリン |
| トリプトファン | 5-HTP → セロトニン |
| グリシン＋スクシニルCoA | ポルフィリン → ヘム |
| ヘム | ビリルビン |

## CBTチェック

- 「チロシン→ドパミン」は正しい。
- ノルアドレナリンからアドレナリンが合成される（逆ではない）。
- トリプトファンはセロトニンの原料で、セロトニンからは戻らない。
- ビリルビンはアルブミンからではなく、ヘム（主にヘモグロビン）分解産物。
