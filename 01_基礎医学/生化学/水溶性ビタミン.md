# 水溶性ビタミン（ビタミンB群）

> ビタミンB群は水溶性ビタミンで、番号と名称・欠乏症の組合せがCBTで問われやすい。

## ビタミンB群の名称

| ビタミン | 名称（別名） | 欠乏時の代表例 |
|---|---|---|
| B1 | チアミン | 脚気、[Wernicke脳症](Wernicke脳症.md)、乳酸アシドーシス |
| B2 | リボフラビン | 口角炎、舌炎、皮膚炎。補酵素型はFAD・FMN |
| B3 | ナイアシン（ニコチン酸・ニコチンアミド） | ペラグラ：皮膚炎・下痢・中枢神経症状 |
| B5 | パントテン酸 | 欠乏はまれ |
| B6 | ピリドキシン | 皮膚炎、口内炎、貧血、末梢神経障害 |
| B7 | ビオチン（ビタミンH） | 皮膚炎、脱毛、食欲不振など |
| B9 | 葉酸 | 巨赤芽球性貧血、胎児神経管閉鎖障害。核酸合成に必要 |
| B12 | コバラミン | 巨赤芽球性貧血、Hunter舌炎、末梢神経障害 |

## CBTチェック

- チアミン＝B1、ナイアシン＝B3、ピリドキシン＝B6、コバラミン＝B12。
- ビタミンB1欠乏 → [[脚気]]・[[Wernicke脳症]]・乳酸アシドーシス。チアミンは糖代謝に必要な補酵素である。
- ナイアシン欠乏 → ペラグラ（皮膚炎・下痢・中枢神経症状）。トウモロコシ主体の食事では、利用可能なナイアシンやトリプトファンが不足しやすい。
- 「日本人の食事摂取基準（2020年版）」では、ニコチン酸にも耐容上限量が設定されている。過剰では皮膚紅潮・掻痒などのフラッシュが起こりうる。
- 葉酸はプリン・チミジル酸などの合成に関わり、DNA合成に必要。妊娠前後の欠乏は胎児神経管閉鎖障害のリスクとなる。
- ビタミンB₁₂はコバルトを含むが、モリブデンではない。ビオチンは生卵白中のアビジンと結合して吸収が阻害される。
- 問題文の「核酸合成に必要」→ 葉酸を考える。
- ビオチンはB7（ビタミンH）であり、B群に分類される。
- ナイアシン欠乏の3徴は皮膚炎・下痢・認知機能低下（ペラグラ）。
