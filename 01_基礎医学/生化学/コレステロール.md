# コレステロール

> **コレステロール**は細胞膜の構成成分であり、胆汁酸・ステロイドホルモン・ビタミンDの材料となる脂質である。

## 要点

- エネルギー源としてはほとんど利用されない。細胞膜の流動性調節に重要である。
- コレステロール → [[ステロイドホルモン]]、胆汁酸、ビタミンDの前駆体。ペプチドホルモンの材料ではない。
- 皮膚では7-デヒドロコレステロールからビタミンD₃がつくられる。コレステロールがビタミンDから合成されるわけではない。
- 細胞内コレステロール低下 → SREBP活性化 → HMG-CoA還元酵素発現・活性上昇 → コレステロール合成促進となる。

| リポタンパク質 | 主な役割 |
|---|---|
| キロミクロン | 食事由来の脂質を腸管から組織へ運ぶ |
| VLDL | 肝臓で合成した主に中性脂肪を組織へ運ぶ |
| IDL | VLDLからLDLへ移行する中間体 |
| LDL | 肝臓から末梢組織へコレステロールを運ぶ。コレステロール含量の割合が最も高い |
| HDL | 末梢組織から肝臓へコレステロールを逆輸送する。プラーク内マクロファージからコレステロールを引き抜き、動脈硬化を抑制する方向に働く |

遠心分離後の血漿・血清が白濁（乳び）している場合は、食後または高脂血症によるキロミクロン増加を考える。

## CBTチェック

- 正しい組合せ：**コレステロール―細胞膜**。
- HMG-CoA還元酵素はコレステロール合成の律速酵素で、細胞内コレステロールが増えると抑制され、減ると促進される。
- 一言暗記：**コレステロールは膜とステロイドの材料、エネルギー源ではない。**
- 一言暗記：**肝臓から末梢へコレステロールを運ぶのはLDL、末梢から肝臓へ戻すのはHDL。**
