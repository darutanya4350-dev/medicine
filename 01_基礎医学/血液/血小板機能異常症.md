# 血小板機能異常症

> 一次止血では、血小板粘着をGPIb-vWFが、血小板凝集をGPIIb/IIIa-フィブリノゲンが担う。

## 要点

- [[von Willebrand病]]ではvWF異常により血小板粘着が障害される。
- Bernard–Soulier症候群はGPIb/IX/V異常による粘着障害で、巨大血小板を認める。
- 血小板無力症はGPIIb/IIIa異常による凝集障害である。
- いずれも粘膜・皮膚出血を来しやすく、[[血友病]]の深部出血とは対照的である。

## CBTチェック

- GPIb-vWF → 粘着、GPIIb/IIIa-フィブリノゲン → 凝集。
- GPIb異常＋巨大血小板 → Bernard–Soulier症候群。
- GPIIb/IIIa異常 → 血小板無力症。
