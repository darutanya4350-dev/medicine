# 血球の種類とCDマーカー

> 血球は形態だけでなく、細胞表面のCDマーカーを用いて系統を判定する。白血病・リンパ腫の診断では[[フローサイトメトリー]]が重要である。

## 要点

- 成人の主要ヘモグロビンはHbA（α₂β₂）である。
- 血小板は骨髄の[[巨核球]]から産生され、一次止血を担う。
- 好中球は細菌感染時の初期防御、単球は組織でマクロファージなどへ分化する。
- B細胞はCD19・CD20、T細胞はCD3、NK細胞はCD16・CD56を発現する。
- 骨髄系細胞はCD13・CD33、[[ミエロペルオキシダーゼ染色|MPO]]を手がかりにする。

## CBTチェック

- CD3 → T細胞、CD19・CD20 → B細胞、CD16・CD56 → NK細胞。
- B・T・NK細胞の系統判定にはCDマーカーを用いる。
