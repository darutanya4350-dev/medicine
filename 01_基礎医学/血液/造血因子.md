# 造血因子

> 造血因子は、造血前駆細胞の増殖・分化・成熟を調節するサイトカインやホルモンである。**血小板産生を促すのはトロンボポエチン（TPO）**である。

## 要点

| 因子 | 主な産生・作用 | 主な標的 |
|---|---|---|
| 顆粒球コロニー刺激因子（G-CSF） | 好中球系の増殖・分化を促進 | 好中球 |
| マクロファージコロニー刺激因子（M-CSF） | 単球系の増殖・分化、生存を促進 | 単球・マクロファージ |
| インターロイキン2（IL-2） | 主に活性化T細胞が産生し、T細胞の増殖とNK細胞の活性化を促進 | T細胞・NK細胞 |
| エリスロポエチン（EPO） | 主に腎の尿細管周囲間質細胞が産生し、赤芽球系を成熟 | 赤血球 |
| トロンボポエチン（TPO） | 主に肝細胞が産生し、巨核球系を成熟 | 血小板 |

- G-CSF製剤は、癌化学療法による発熱性好中球減少症（FN）の発症リスクを低下させる。
- 腎機能低下 → EPO産生低下 → 典型的には正球性の[腎性貧血](../../04_検査/血液/貧血のMCV分類.md)をきたす。

## CBTチェック

- [血小板減少](../../04_検査/血液/血小板減少.md)では、**TPO―肝臓―巨核球**の組合せを確認する。赤血球は**EPO―腎臓―赤芽球**である。
- G-CSFの主な標的は好中球、M-CSFの主な標的は単球・マクロファージである。
- IL-2は系統特異的な造血因子ではなく、主にT細胞の増殖とNK細胞の活性化に働く。
