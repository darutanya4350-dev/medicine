# CBT短答模擬問題 第3回

> 明日の朝に行う60分の弱点定着演習。解説やノートを見ず、必要最小限の語句で回答する。

## 実施方法

- 0〜20分：問1〜4
- 20〜35分：問5〜7
- 35〜55分：問8〜12
- 55〜60分：未回答を埋め、各問に確信度（○・△・×）を付ける

## 問題

**問1**

突然発症した「これまでで最も強い頭痛」、嘔吐、項部硬直を認める。最も疑う疾患と、最初に行う画像検査を答えよ。

**あなたの回答：くも膜下、頭部CT（MRIしてる暇ない）**

**確信度：まる**

---

**問2**

問1の疾患を強く疑うが、発症から時間が経過しており頭部CTで明らかな出血を認めない。診断のため次に検討する検査を1つ答えよ。

**あなたの回答：髄液検査　MRI**

**確信度：三角**

---

**問3**

破裂脳動脈瘤が原因と判明した。再出血を防ぐために行う根治的治療を2つ答えよ。

**あなたの回答：コイル塞栓、クリッピング**

**確信度：三角**

---

**問4**

発症後しばらくして意識障害と片麻痺が新たに出現した。頭蓋内の再出血は認めない。この時期に考える代表的な遅発性合併症を答えよ。

**あなたの回答：脳血管攣縮**

**確信度：ばつ**

---

**問5**

若年者の大腸内視鏡で数百個の腺腫を認め、父親も若年で大腸癌を発症している。最も疑う疾患、代表的な原因遺伝子、遺伝形式を答えよ。

**あなたの回答：FAP、APC遺伝子、常染色体？遺伝**

**確信度：まる**

---

**問6**

問5の疾患を治療せず放置した場合に高率に発生する悪性腫瘍と、その予防を目的とした基本的な外科治療を答えよ。

**あなたの回答：大腸がん、大腸全摘**

**確信度：まる**

---

**問7**

問5の疾患に合併することがある大腸外病変を2つ答えよ。

**あなたの回答：十二指腸潰瘍、顎骨骨腫**

**確信度：まる**

---

**問8**

倦怠感、感染の反復、皮下出血があり、末梢血で赤血球・白血球・血小板がすべて減少している。骨髄検査で予想される所見と、最も疑う疾患を答えよ。

**あなたの回答：再生不良性貧血、骨髄脂肪化**

**確信度：まる**

---

**問9**

問8の患者で、貧血があるにもかかわらず低値になりやすい赤血球産生の指標を答えよ。

**あなたの回答：網赤血球**

**確信度：まる**

---

**問10**

幼少時から黄疸と脾腫があり、家族にも同様の患者がいる。末梢血塗抹で中央淡明を欠く小型球状赤血球を認める。最も疑う疾患と、主な溶血部位を答えよ。

**あなたの回答：遺伝性球状赤血球、脾臓**

**確信度：まる**

---

**問11**

問10の疾患と自己免疫性溶血性貧血の鑑別に用いる検査、および問10の疾患で予想される結果を答えよ。

**あなたの回答：直接クームス試験or赤血球浸透圧けんさ、陰性＆脆弱赤血球**

**確信度：三角**

---

**問12**

遺伝性球状赤血球症で上昇する赤血球の性質を1つ、慢性溶血によって生じやすい胆石の種類を1つ答えよ。

**あなたの回答：浸透圧減少、黒色**

**確信度：ばつ**

## 採点結果

> 得点：10.5 / 22点（48%）｜解答時間：15分

- 問1（2 / 2点）正答：[[くも膜下出血]]、頭部単純CT。両方正答。
- 問2（0 / 1点）正答：腰椎穿刺による髄液検査（またはMRI）。脳血管造影は出血源の動脈瘤評価には有用だが、CT陰性時に出血自体を確認する問いへの回答ではない。
- 問3（1.5 / 2点）正答：脳動脈瘤クリッピング術、コイル塞栓術。コイルは正答。「切除」は外科治療の方向性として0.5点。
- 問4（0 / 1点）正答：脳血管攣縮による遅発性脳虚血。
- 問5（1 / 3点）正答：[[家族性大腸腺腫症]]、APC遺伝子、常染色体顕性（優性）遺伝。疾患名のみ正答。
- 問6（2 / 2点）正答：大腸癌、予防的大腸切除術。両方正答。
- 問7（0 / 2点）正答例：デスモイド腫瘍、十二指腸腺腫・癌、甲状腺癌、顎骨骨腫などから2つ。
- 問8（1 / 2点）正答：骨髄低形成・脂肪髄、[[再生不良性貧血]]。疾患名のみ正答。
- 問9（1 / 1点）正答：網状赤血球数。正答。
- 問10（1 / 2点）正答：[[遺伝性球状赤血球症]]、脾臓での血管外溶血。疾患名のみ正答。
- 問11（1 / 2点）正答：直接Coombs試験、陰性。検査名は正答だが結果が不足。赤血球浸透圧脆弱性試験では脆弱性亢進を認める。
- 問12（0 / 2点）正答：赤血球浸透圧脆弱性亢進、黒色石（色素胆石）。

### 問1の振り返り

1. **決め手**：「突然の最激痛」「項部硬直」。
2. **CBT最小知識**：疑ったら頭部単純CT。
3. **選択肢からの連想**：CTは診断、血管評価はCTA・脳血管造影。
4. **ひっかけポイント**：初手をMRIにしない。
5. **一言暗記**：雷鳴頭痛 → くも膜下出血 → 単純CT。

### 問2の振り返り

1. **決め手**：「強く疑う」「CTで出血なし」。
2. **CBT最小知識**：髄液のキサントクロミーを確認する。
3. **選択肢からの連想**：脳血管造影は出血源の評価。
4. **ひっかけポイント**：出血の確認と動脈瘤の検索を分ける。
5. **一言暗記**：CT陰性でも疑えば髄液検査またはMRI。

### 問3の振り返り

1. **決め手**：「破裂脳動脈瘤」「再出血予防」。
2. **CBT最小知識**：クリッピング術とコイル塞栓術。
3. **選択肢からの連想**：開頭術か血管内治療かを病変に応じて選ぶ。
4. **ひっかけポイント**：動脈瘤を単に「切除」と表現しない。
5. **一言暗記**：瘤を挟むクリップ、内から詰めるコイル。

### 問4の振り返り

1. **決め手**：「しばらくして」「再出血なし」「新たな神経症状」。
2. **CBT最小知識**：遅発性脳血管攣縮による脳虚血。
3. **選択肢からの連想**：発症直後の悪化なら再出血も考える。
4. **ひっかけポイント**：時期と画像で再出血と区別する。
5. **一言暗記**：数日後の麻痺 → 脳血管攣縮。

### 問5の振り返り

1. **決め手**：「数百個の腺腫」「若年の家族歴」。
2. **CBT最小知識**：FAP＝APC遺伝子、常染色体顕性遺伝。
3. **選択肢からの連想**：MUTYH関連ポリポーシスは常染色体潜性。
4. **ひっかけポイント**：疾患名だけでなく遺伝子と遺伝形式まで一組にする。
5. **一言暗記**：FAPはAPC、顕性遺伝。

### 問6の振り返り

1. **決め手**：「放置」「高率に発生」「予防」。
2. **CBT最小知識**：大腸癌予防のため大腸切除を行う。
3. **選択肢からの連想**：多数の腺腫は個別ポリペクトミーでは管理困難。
4. **ひっかけポイント**：内視鏡だけで完結しない。
5. **一言暗記**：FAPは癌になる前に大腸切除。

### 問7の振り返り

1. **決め手**：「大腸外病変」。
2. **CBT最小知識**：デスモイド腫瘍、十二指腸病変を優先して覚える。
3. **選択肢からの連想**：顎骨骨腫などを伴う表現型はGardner症候群。
4. **ひっかけポイント**：大腸病変だけの疾患と考えない。
5. **一言暗記**：FAPは大腸＋デスモイド＋十二指腸。

### 問8の振り返り

1. **決め手**：「汎血球減少」。
2. **CBT最小知識**：再生不良性貧血は骨髄低形成・脂肪髄。
3. **選択肢からの連想**：骨髄線維症では線維化・脾腫。
4. **ひっかけポイント**：病名だけで骨髄所見を落とさない。
5. **一言暗記**：汎血球減少＋脂肪髄 → 再生不良性貧血。

### 問9の振り返り

1. **決め手**：「赤血球産生の指標」。
2. **CBT最小知識**：造血低下では網状赤血球が減少する。
3. **選択肢からの連想**：溶血では代償性に網状赤血球が増える。
4. **ひっかけポイント**：貧血だから網状赤血球が増えるとは限らない。
5. **一言暗記**：作れない貧血は網赤血球低下。

### 問10の振り返り

1. **決め手**：「家族歴」「黄疸・脾腫」「球状赤血球」。
2. **CBT最小知識**：脾臓での血管外溶血。
3. **選択肢からの連想**：自己免疫性溶血性貧血でも球状赤血球を認める。
4. **ひっかけポイント**：疾患名と溶血部位をセットにする。
5. **一言暗記**：球状赤血球は脾臓で捕まる。

### 問11の振り返り

1. **決め手**：「自己免疫性との鑑別」。
2. **CBT最小知識**：遺伝性球状赤血球症は直接Coombs陰性。
3. **選択肢からの連想**：自己免疫性溶血性貧血は直接Coombs陽性。
4. **ひっかけポイント**：検査名だけでなく陽性・陰性まで答える。
5. **一言暗記**：球状赤血球＋Coombs陰性 → 遺伝性。

### 問12の振り返り

1. **決め手**：「上昇する性質」「慢性溶血の胆石」。
2. **CBT最小知識**：浸透圧脆弱性亢進、黒色石。
3. **選択肢からの連想**：溶血で非抱合ビリルビンが増える。
4. **ひっかけポイント**：胆石はCTでの見え方ではなく成分を答える。
5. **一言暗記**：球状赤血球は脆く、溶血で黒色石。

## 総評

- 定着している点：くも膜下出血の典型像と初期CT、FAPの大腸癌リスクと大腸切除、網状赤血球低下。
- 優先して復習する点：くも膜下出血のCT陰性時・遅発性合併症、FAPのAPC遺伝子と大腸外病変、遺伝性球状赤血球症の検査・胆石。
- 15分で完答した速度は十分。次回は病名だけで止めず、問われた全要素を埋める。
