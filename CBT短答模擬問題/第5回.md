## 採点結果

> 得点：13 / 19点（68%）

- 問1（0.5 / 3点）正答：重層扁平上皮から円柱上皮へ置換、食道腺癌。置換方向が逆。「腺がん」は候補に挙げられているため0.5点。
- 問2（0 / 2点）正答：Nikolsky現象、Köbner現象。順序を逆にしている。
- 問3（1 / 1点）正答：髄液検査（またはMRI）。正答。
- 問4（1 / 1点）正答：脳血管攣縮による遅発性脳虚血。正答。
- 問5（3 / 3点）正答：APC遺伝子、常染色体顕性遺伝、予防的大腸切除術。正答。
- 問6（2 / 2点）正答例：顎骨骨腫、十二指腸腺腫。正答。
- 問7（2 / 3点）正答：汎血球減少、骨髄低形成・脂肪髄、網状赤血球減少。前2つは正答。涙滴赤血球は原発性骨髄線維症などでみられる所見。
- 問8（3.5 / 4点）正答：脾臓、直接Coombs陰性、赤血球浸透圧脆弱性亢進、黒色石。「浸透圧」は方向が不足するため0.5点。

### 問1の振り返り

1. **決め手**：胃酸にさらされる食道下部。
2. **CBT最小知識**：重層扁平上皮 → 円柱上皮化生 → 食道腺癌。
3. **選択肢からの連想**：通常の食道癌では扁平上皮癌が多い。
4. **ひっかけポイント**：上皮の置換方向を逆にしない。
5. **一言暗記**：酸に耐えるため、扁平から円柱へ。

### 問2の振り返り

1. **決め手**：「こすると剥離」と「外傷部に同じ皮疹」。
2. **CBT最小知識**：前者はNikolsky、後者はKöbner。
3. **選択肢からの連想**：Nikolskyは天疱瘡・TEN、Köbnerは乾癬。
4. **ひっかけポイント**：似た名称を順序で混同しない。
5. **一言暗記**：剥けるNikolsky、傷に出るKöbner。

### 問3の振り返り

1. **決め手**：SAHを疑うがCT陰性。
2. **CBT最小知識**：髄液検査またはMRIを検討する。
3. **選択肢からの連想**：脳血管造影は出血源の動脈瘤評価。
4. **ひっかけポイント**：出血の確認と血管評価を区別する。
5. **一言暗記**：CT陰性でも疑えば髄液。

### 問4の振り返り

1. **決め手**：発症数日後の新たな局所神経症状。
2. **CBT最小知識**：脳血管攣縮による遅発性脳虚血。
3. **選択肢からの連想**：急な再増悪では再出血も考える。
4. **ひっかけポイント**：時期を読む。
5. **一言暗記**：数日後の麻痺は攣縮。

### 問5の振り返り

1. **決め手**：FAPの遺伝と癌予防。
2. **CBT最小知識**：APC、常染色体顕性、予防的大腸切除。
3. **選択肢からの連想**：MUTYH関連ポリポーシスは常染色体潜性。
4. **ひっかけポイント**：内視鏡的切除だけでは不十分。
5. **一言暗記**：FAPはAPC・顕性・大腸切除。

### 問6の振り返り

1. **決め手**：FAPの大腸外病変。
2. **CBT最小知識**：十二指腸病変、デスモイド腫瘍、顎骨骨腫など。
3. **選択肢からの連想**：顎骨骨腫を伴う表現型はGardner症候群。
4. **ひっかけポイント**：大腸だけの病気と考えない。
5. **一言暗記**：FAPは十二指腸とデスモイドにも注意。

### 問7の振り返り

1. **決め手**：血球を作れない骨髄不全。
2. **CBT最小知識**：汎血球減少＋脂肪髄＋網状赤血球減少。
3. **選択肢からの連想**：涙滴赤血球は骨髄線維症を考える。
4. **ひっかけポイント**：異形赤血球ではなく産生指標を答える。
5. **一言暗記**：作れない貧血は網赤血球も減る。

### 問8の振り返り

1. **決め手**：球状赤血球の膜が脆い。
2. **CBT最小知識**：脾臓で血管外溶血、Coombs陰性、浸透圧脆弱性亢進、黒色石。
3. **選択肢からの連想**：自己免疫性溶血性貧血はCoombs陽性。
4. **ひっかけポイント**：「浸透圧」だけでなく脆弱性亢進まで答える。
5. **一言暗記**：球状赤血球は脆く、脾で壊れ、黒色石。
