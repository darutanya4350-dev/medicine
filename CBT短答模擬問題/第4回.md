**確信度：三角**

## 採点結果

> 得点：15 / 16点（94%）

- 問1（1 / 1点）正答：キサントクロミー（黄色調）。「黄色」で正答。自己評価は△。
- 問2（2 / 2点）正答：クリッピング術、コイル塞栓術。「コイル側線」は表記の誤りとして扱い、意図は正答。
- 問3（1 / 1点）正答：脳血管攣縮による遅発性脳虚血。正答。
- 問4（2 / 2点）正答：APC遺伝子、常染色体顕性（優性）遺伝。表記の誤りはあるが両要素とも正答。自己評価は△。
- 問5（0 / 1点）前回の回答「？」→ 正答：デスモイド腫瘍。誤りの種類：知識不足。
- 問6（2 / 2点）正答例：十二指腸腺腫・癌、顎骨骨腫。両方正答。デスモイド腫瘍は追加の大腸外病変。
- 問7（2 / 2点）正答：再生不良性貧血、網状赤血球減少。正答。
- 問8（2 / 2点）正答：遺伝性球状赤血球症、脾臓。正答。
- 問9（2 / 2点）正答：赤血球浸透圧脆弱性亢進、直接Coombs試験。正答。
- 問10（1 / 1点）正答：黒色石（色素胆石）。正答。

### 問1の振り返り

1. **決め手**：「SAHを疑う」「単純CTで出血なし」「髄液の色調」。
2. **CBT最小知識**：[くも膜下出血](../03_疾患/神経/くも膜下出血.md)では髄液のキサントクロミーを確認する。
3. **選択肢からの連想**：血性髄液は穿刺による混入でも起こるが、上清の黄色調は出血後の変化を示唆する。
4. **ひっかけポイント**：「黄色」だけでなくキサントクロミーという名称まで再生する。
5. **一言暗記**：CT陰性でもSAHを疑えば髄液の黄染。

### 問2の振り返り

1. **決め手**：「開頭して頸部を挟む」「血管内から充塡」。
2. **CBT最小知識**：前者はクリッピング術、後者はコイル塞栓術。
3. **選択肢からの連想**：いずれも破裂動脈瘤を閉鎖し、再出血を防ぐ。
4. **ひっかけポイント**：「コイル塞栓」まで正確に書く。
5. **一言暗記**：外からクリップ、内からコイル。

### 問3の振り返り

1. **決め手**：「発症7日後」「再出血なし」「新たな局所神経症状」。
2. **CBT最小知識**：脳血管攣縮による遅発性脳虚血を考える。
3. **選択肢からの連想**：急な再増悪では再出血、意識低下では水頭症も鑑別する。
4. **ひっかけポイント**：発症時期と再出血の有無を読む。
5. **一言暗記**：SAH数日後の麻痺は血管攣縮。

### 問4の振り返り

1. **決め手**：「家族性大腸腺腫症」「原因遺伝子と遺伝形式」。
2. **CBT最小知識**：[FAP](../03_疾患/消化器/家族性大腸腺腫症.md)はAPC遺伝子異常による常染色体顕性遺伝。
3. **選択肢からの連想**：MUTYH関連ポリポーシスは常染色体潜性遺伝。
4. **ひっかけポイント**：「顕性（優性）」まで明記する。
5. **一言暗記**：FAP＝APC・顕性。

### 問5の振り返り

1. **決め手**：「FAP」「腹腔内腫瘤」「手術後に発生・増大」。
2. **CBT最小知識**：FAPの腹腔内デスモイド腫瘍は手術後に生じることがある。
3. **選択肢からの連想**：顎骨骨腫、十二指腸腺腫・癌もFAPの大腸外病変。
4. **ひっかけポイント**：デスモイド腫瘍は局所浸潤性だが転移しない。
5. **一言暗記**：FAP＋術後腹腔内腫瘤＝デスモイド。

### 問6の振り返り

1. **決め手**：「上部消化管」と「頭頸部または骨」を1つずつ。
2. **CBT最小知識**：十二指腸腺腫・癌と顎骨骨腫が代表。
3. **選択肢からの連想**：顎骨骨腫を伴う表現型はGardner症候群。
4. **ひっかけポイント**：デスモイド腫瘍は上部消化管病変でも骨病変でもない。
5. **一言暗記**：FAPは大腸だけでなく十二指腸と顎骨もみる。

### 問7の振り返り

1. **決め手**：「汎血球減少」「低形成・脂肪髄」。
2. **CBT最小知識**：[再生不良性貧血](../03_疾患/血液/再生不良性貧血.md)では網状赤血球も減少する。
3. **選択肢からの連想**：骨髄線維症では線維化、涙滴赤血球、脾腫をみる。
4. **ひっかけポイント**：貧血でも産生低下なら網状赤血球は増えない。
5. **一言暗記**：脂肪髄では網赤血球も少ない。

### 問8の振り返り

1. **決め手**：「球状赤血球」「直接Coombs陰性」「家族性を示唆する像」。
2. **CBT最小知識**：[遺伝性球状赤血球症](../03_疾患/血液/遺伝性球状赤血球症.md)は脾臓で血管外溶血を起こす。
3. **選択肢からの連想**：自己免疫性溶血性貧血でも球状赤血球を認めるが、直接Coombs陽性。
4. **ひっかけポイント**：形態だけでなくCoombs試験と組み合わせる。
5. **一言暗記**：Coombs陰性の球状赤血球は脾で壊れる。

### 問9の振り返り

1. **決め手**：「亢進する赤血球の性質」「自己免疫性との鑑別」。
2. **CBT最小知識**：浸透圧脆弱性亢進、直接Coombs陰性。
3. **選択肢からの連想**：自己免疫性溶血性貧血は直接Coombs陽性。
4. **ひっかけポイント**：脆弱性は「亢進」と方向まで答える。
5. **一言暗記**：遺伝性球状赤血球は脆く、Coombs陰性。

### 問10の振り返り

1. **決め手**：「慢性溶血」「右季肋部痛」。
2. **CBT最小知識**：慢性溶血では非抱合ビリルビン由来の黒色石を生じやすい。
3. **選択肢からの連想**：コレステロール石は肥満・女性などが代表的背景。
4. **ひっかけポイント**：「色素胆石」だけでなく黒色石まで答える。
5. **一言暗記**：慢性溶血は黒色石。

## 総評

- 定着：くも膜下出血、再生不良性貧血、遺伝性球状赤血球症は選択肢なしでも再生できた。
- 改善：第3回48%から第4回94%へ上昇し、補強演習の目的を達成した。
- 残る一点：FAPの「手術後腹腔内腫瘤＝デスモイド腫瘍」のみ再確認する。
