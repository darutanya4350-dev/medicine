## 採点結果

> **得点：15 / 44点（34%）**  
> 採点基準：設問が要求する各要素を1点、核心に近いが不十分な表現を0.5点とした。

- **問1（2 / 2点）** 正答：[急性下壁ST上昇型心筋梗塞](../../03_疾患/循環器/急性心筋梗塞.md)（STEMI）／[[経皮的冠動脈インターベンション]]（primary PCI）。「経皮バルーンカテーテル」はPCIの趣旨として正答。
- **問2（1.5 / 2点）** 正答：[肺血栓塞栓症](../../03_疾患/循環器/肺血栓塞栓症.md)／[[造影CT]]（CT肺動脈造影）。「胸部CT」だけでは造影・肺動脈評価が不明確。
- **問3（0 / 3点）** 正答：[感染性心内膜炎](../../03_疾患/循環器/感染性心内膜炎.md)／[[血液培養]]／[[心エコー]]。[Osler結節](../../02_症候・診察/Osler結節.md)（有痛性）を川崎病と混同している。
- **問4（0 / 2点）** 正答：[[膝胸位]]／[[全身血管抵抗]]を上げて右左短絡を減らす。右側臥位ではない。
- **問5（0.5 / 3点）** 正答：[[高アニオンギャップ性代謝性アシドーシス]]／[[生理食塩水]]を中心とする輸液／[[速効型インスリン]]持続静注。「ケトアシドーシス」は病態名として部分点。
- **問6（0 / 2点）** 正答：[[IGF-1]]／75 g[[経口ブドウ糖負荷試験]]でGHが正常域まで抑制されない。血糖低下を判定する検査ではない。
- **問7（0 / 2点）** 正答：[血栓性血小板減少性紫斑病](../../03_疾患/血液/血栓性血小板減少性紫斑病.md)（TTP）／[[血漿交換]]。[[破砕赤血球の鑑別|破砕赤血球]]＋[[血小板減少]]＋凝固検査正常が手掛かり。
- **問8（0 / 3点）** 正答：[発作性夜間ヘモグロビン尿症](../../03_疾患/血液/発作性夜間ヘモグロビン尿症.md)（PNH）／[CD55](../../01_基礎医学/血液/CD55.md)／[CD59](../../01_基礎医学/血液/CD59.md)。Coombs陰性の[[溶血|血管内溶血]]と暗色尿が手掛かり。
- **問9（0.5 / 1点）** 正答：[足細胞（ポドサイト）の足突起消失](../../03_疾患/腎・泌尿器/微小変化型ネフローゼ症候群.md)（癒合）。ポドサイト自体の消失ではないため部分点。
- **問10（0 / 3点）** 正答例：治療抵抗性の[[高カリウム血症]]／高度[[代謝性アシドーシス]]／[[肺水腫]]（または[[尿毒症性脳症]]など）。高アンモニア血症は代表的な[緊急透析の適応](../../05_治療/緊急透析の適応.md)ではない。
- **問11（2 / 2点）** 正答：[異所性妊娠](../../03_疾患/産婦人科/異所性妊娠.md)／低血圧・[[ショック]]。正答。
- **問12（1 / 2点）** 正答：[一相性基礎体温](../../04_検査/生理検査/基礎体温.md)／[[子宮内膜増殖症]]・[[子宮体癌]]。「無峰性の低い体温」は一相性として正答、子宮内膜症とは区別する。
- **問13（1 / 2点）** 正答：[[冠動脈瘤]]／[[心エコー]]。合併症は正答だが、基本評価は年1回の造影MRIではない。
- **問14（1 / 3点）** 正答：まず[[陽圧換気]]／有効な換気後も心拍数60/分未満なら[[胸骨圧迫]]を追加／圧迫・換気比3：1。胸骨圧迫の追加のみ正答。
- **問15（0 / 1点）** 正答：[Apgarスコア](../../02_症候・診察/Apgarスコア.md)5点（心拍1、呼吸1、筋緊張1、反射1、皮膚色1）。
- **問16（1.5 / 2点）** 正答：[急性閉塞隅角緑内障](../../03_疾患/眼科/急性閉塞隅角緑内障.md)／[[散瞳眼底検査]]。「緑内障」は病型が不足するため部分点、避ける検査は正答。
- **問17（0 / 2点）** 正答：[[可逆性気流制限]]（気管支拡張薬で1秒量が改善）／[[吸入ステロイド薬]]（ICS）。LABA単独は基本薬ではなく、[β遮断薬](../../06_薬剤/自律神経・循環/β遮断薬.md)は喘息を悪化させうる。
- **問18（0 / 2点）** 正答：[髄膜炎菌](../../01_基礎医学/微生物/細菌/髄膜炎菌.md)（Neisseria meningitidis）／[[セフトリアキソン]]などの第3世代セフェム。肺炎球菌はグラム陽性双球菌。
- **問19（1.5 / 2点）** 正答：[所轄警察署・24時間以内](../../07_公衆衛生・法医学/医事法/医師法.md)。期限は正答、「近く」ではなく「所轄」を用いる。
- **問20（2.5 / 3点）** 正答：[Stanford A型急性大動脈解離](../../03_疾患/循環器/急性大動脈解離.md)／[[造影CT]]／[[人工血管置換術]]。「CT」は造影の明示がないため部分点。

## 総評

- **定着している点：** 急性心筋梗塞、異所性妊娠、大動脈解離など、典型的な救急疾患の病名判断は比較的良好。
- **優先課題：** 病名の次に問われる「確定・中心検査」と「初期治療」を一組で覚える。特にTTP、PNH、DKA、[新生児蘇生](../../05_治療/処置/新生児蘇生.md)は早めの復習が必要。
- **読み分け：** [グラム染色](../../04_検査/染色法/グラム染色.md)、Coombs試験、PT・APTT、特徴的身体所見（Osler結節）から疾患を絞る練習を増やす。
- **次回の目標：** まず60%（27 / 44点相当）。誤答した設問を「疾患―決め手―初期対応」の3点セットで言い直してから次回へ進む。
