# CBT短答模擬問題 第6回

> 9月4日の産科演習で、誤答・迷い・自信未記載だった論点を選択肢なしで再生する45分演習。

## 実施方法

- 0〜35分：問1〜18を解く。
- 35〜41分：空欄を見直し、分かる範囲で埋める。
- 41〜45分：各問へ確信度（○・△・×）を付ける。
- 解説やノートは開かず、分からない場合は「？」と記入する。

## 採点結果

> 得点：34 / 59点（58%）

- 問1（3 / 3点）正答：ARB、ACE阻害薬、ニフェジピン。全要素正答。自己評価は△。
- 問2（0 / 1点）前回の回答「塩酸ヒドララジン」→ 正答：インスリン。誤りの種類：降圧薬との知識混同。
- 問3（2 / 4点）正答：血小板数↓、凝固能↑、赤沈↑、空腹時血糖↓。血小板数と凝固能のみ正答。誤りの種類：方向の混同。
- 問4（0 / 2点）前回の回答「異所性妊娠」→ 正答：切迫流産、絨毛膜下血腫。誤りの種類：症例の読み違い。子宮内胎児心拍確認は異所性妊娠に合わない。
- 問5（1.5 / 3点）正答：1. 稽留流産、2. 進行流産、3. 不全流産。「稽」まで想起できたため0.5点、3は正答。2の切迫早産は誤り。
- 問6（0 / 2点）前回の回答「胎児機能不全、チアノーゼ」→ 正答：臍帯脱出、臍帯圧迫による胎児血流・酸素供給低下。誤りの種類：原因病態と結果の混同。
- 問7（0 / 2点）正答：1. 前置胎盤、2. 常位胎盤早期剝離。誤りの種類：妊娠後期出血の鑑別不足。
- 問8（1 / 1点）正答例：頸管裂傷・腟裂傷などの産道裂傷。「腟裂」で正答。本問だけでは損傷部位を一意に特定できないため減点しない。
- 問9（2 / 2点）正答：子宮内反症、用手整復。正答。
- 問10（1 / 4点）正答：BPS（biophysical profile score）と、その構成項目（NST、胎児呼吸様運動、胎動、筋緊張、羊水量）から3つ。「羊水」のみ正答。誤りの種類：スコアの用途混同。
- 問11（2 / 2点）正答例：吸引分娩。子宮口全開大・児頭低位・回旋正常で、胎児機能不全のため急速遂娩が必要という理由も正答。
- 問12（1 / 2点）正答：胎児頭殿長（CRL）、妊娠9〜10週頃。「10週」は範囲内のため1点。指標名が不足。
- 問13（4 / 4点）正答目安：胎嚢4週末〜5週、胎児心拍5週半〜6週、胎動初覚16〜20週、臍高20〜24週。回答はいずれも許容範囲。
- 問14（4.5 / 5点）増加する4ホルモンは全正答。FSHは主にエストロゲン・プロゲステロンなどの負のフィードバックで低下する。「エストロゲン」は正しいが、プロラクチンを主因に含めたため0.5点。
- 問15（4 / 4点）正答：プロラクチン、オキシトシン、エストロゲン、分泌型IgA。全要素正答。自己評価は△。
- 問16（4 / 7点）羊水過多は消化管閉鎖・母体糖尿病、羊水過少はPotter症候群、影響は肺低形成が正答。妊娠高血圧症候群は羊水過少、無脳症は羊水過多。長期羊水過少のもう1つは四肢変形など。
- 問17（1 / 6点）RDSのサーファクタント不足のみ正答。TTNは肺液吸収遅延、好発背景と経過の対比が不足。誤りの種類：回答要素不足。
- 問18（3 / 5点）第1回旋（屈曲）、第2回旋（内回旋）、低在横定位は正答。第3回旋は伸展、第4回旋は外回旋で、回答では順序が逆。誤りの種類：順序の混同。

### 問1の振り返り

1. **決め手**：「妊娠中に禁忌」「使用できるCa拮抗薬」。
2. **CBT最小知識**：[妊娠高血圧症候群](../03_疾患/産婦人科/妊娠高血圧症候群.md)ではACE阻害薬・ARBを避け、ニフェジピンなどを用いる。
3. **選択肢からの連想**：ヒドララジン、ラベタロール、メチルドパも選択肢となる。
4. **ひっかけポイント**：硫酸Mgは子癇予防であり降圧薬ではない。
5. **一言暗記**：妊娠はACE・ARB禁忌、Ca拮抗薬はニフェジピン。

### 問2の振り返り

1. **決め手**：「血糖高値」「食事療法後も不十分」。
2. **CBT最小知識**：[妊娠中の糖尿病](../03_疾患/内分泌/妊娠糖尿病.md)で食事療法が不十分ならインスリン。
3. **選択肢からの連想**：ヒドララジンは降圧薬。
4. **ひっかけポイント**：直前の高血圧問題の薬を引きずらない。
5. **一言暗記**：妊娠中の高血糖治療はインスリン。

### 問3の振り返り

1. **決め手**：「正常妊娠での増減」。
2. **CBT最小知識**：血小板数↓、凝固能↑、赤沈↑、空腹時血糖↓。
3. **選択肢からの連想**：hPLによるインスリン抵抗性で食後血糖は上がりやすい。
4. **ひっかけポイント**：凝固能亢進と血小板数低下は同時に起こりうる。
5. **一言暗記**：妊娠は「血小板↓、固まりやすい、赤沈↑、空腹時糖↓」。

### 問4の振り返り

1. **決め手**：「子宮内胎児心拍あり」「子宮口閉鎖」「胎嚢外の低エコー域」。
2. **CBT最小知識**：[流産](../03_疾患/産婦人科/流産.md)のうち切迫流産で、低エコー域は絨毛膜下血腫。
3. **選択肢からの連想**：子宮内妊娠が確認できなければ異所性妊娠も考える。
4. **ひっかけポイント**：出血だけで異所性妊娠に飛ばない。
5. **一言暗記**：心拍あり・口閉鎖＝切迫、胎嚢外血腫＝絨毛膜下。

### 問5の振り返り

1. **決め手**：「死亡して残る」「口が開いて進行」「一部が残る」。
2. **CBT最小知識**：順に稽留流産、進行流産、不全流産。
3. **選択肢からの連想**：切迫流産は子宮口閉鎖で妊娠継続の可能性がある。
4. **ひっかけポイント**：22週未満は早産ではなく流産。
5. **一言暗記**：留まる稽留、進む進行、残る不全。

### 問6の振り返り

1. **決め手**：「骨盤位」「破水直後」「遷延一過性徐脈」。
2. **CBT最小知識**：[臍帯脱出](../03_疾患/産婦人科/臍帯脱出.md)で臍帯が圧迫され、胎児低酸素となる。
3. **選択肢からの連想**：胎児機能不全は結果であり、原因病態ではない。
4. **ひっかけポイント**：チアノーゼは機序ではなく低酸素の徴候。
5. **一言暗記**：骨盤位の破水後徐脈＝臍帯脱出。

### 問7の振り返り

1. **決め手**：「無痛・軟らかい」と「有痛・板状硬」。
2. **CBT最小知識**：前者は[前置胎盤](../03_疾患/産婦人科/前置胎盤.md)、後者は[常位胎盤早期剝離](../03_疾患/産婦人科/常位胎盤早期剝離.md)。
3. **選択肢からの連想**：産道裂傷は通常、胎児娩出後の出血で考える。
4. **ひっかけポイント**：羊水量ではなく、痛みと子宮の硬さで分ける。
5. **一言暗記**：前置は無痛で軟、早剝は痛くて硬。

### 問8の振り返り

1. **決め手**：「胎盤娩出後」「鮮紅色」「子宮収縮良好」。
2. **CBT最小知識**：弛緩出血より[産道裂傷](../03_疾患/産婦人科/頸管裂傷.md)を疑う。
3. **選択肢からの連想**：子宮が軟らかく収縮不良なら弛緩出血。
4. **ひっかけポイント**：本問の情報だけでは頸管と腟を一意に区別できない。
5. **一言暗記**：締まった子宮から鮮血なら産道裂傷。

### 問9の振り返り

1. **決め手**：「胎盤娩出直後」「子宮底を触れない」「腟内腫瘤」。
2. **CBT最小知識**：[子宮内反症](../03_疾患/産婦人科/子宮内反症.md)は直ちに用手整復する。
3. **選択肢からの連想**：弛緩出血では子宮収縮不良だが、腟内腫瘤はない。
4. **ひっかけポイント**：大量出血だけで弛緩出血と決めない。
5. **一言暗記**：子宮底なし＋腟内腫瘤＝内反、手で戻す。

### 問10の振り返り

1. **決め手**：「FGR」「nonreactive NST」「次の胎児評価」。
2. **CBT最小知識**：[胎児機能不全](../03_疾患/産婦人科/胎児機能不全.md)を疑いBPSでNST、呼吸様運動、胎動、筋緊張、羊水量を評価する。
3. **選択肢からの連想**：[Bishopスコア](../02_症候・診察/Bishopスコア.md)は頸管熟化度、CRLは初期の週数推定。
4. **ひっかけポイント**：BPSとBishopの頭文字Bを混同しない。
5. **一言暗記**：NST不良ならBPS、頸管ならBishop。

### 問11の振り返り

1. **決め手**：「子宮口全開」「SP＋3」「回旋正常」「高度徐脈」。
2. **CBT最小知識**：児頭が十分下降していれば吸引・鉗子で急速遂娩できる。
3. **選択肢からの連想**：経腟分娩が困難なら緊急帝王切開。
4. **ひっかけポイント**：胎児機能不全でも常に帝王切開とは限らない。
5. **一言暗記**：全開・低位・回旋正常なら吸引を選べる。

### 問12の振り返り

1. **決め手**：「妊娠初期」「週数推定」。
2. **CBT最小知識**：[胎児頭殿長](../04_検査/胎児頭殿長.md)（CRL）を妊娠9〜10週頃に測る。
3. **選択肢からの連想**：児頭大横径（BPD）は妊娠中期以降。
4. **ひっかけポイント**：週数だけでなく指標名まで答える。
5. **一言暗記**：初期の週数は9〜10週のCRL。

### 問13の振り返り

1. **決め手**：「経腟超音波」「胎動初覚」「臍高」。

4. **ひっかけポイント**：個人差があるため単一週数に固定しすぎない。

### 問14の振り返り

1. **決め手**：「妊娠中に増加」「FSH低下の機序」。
2. **CBT最小知識**：[妊娠中の母体ホルモン](../01_基礎医学/生理/妊娠中の母体ホルモン変化.md)ではPRL・hPL・hCG・エストロゲンが増え、FSHは負のフィードバックで低下する。
3. **選択肢からの連想**：hCGは妊娠初期にピークを作る。
4. **ひっかけポイント**：プロラクチンをFSH抑制の主因として答えない。
5. **一言暗記**：妊娠は胎盤ホルモン↑、FSH・LH↓。

### 問15の振り返り

1. **決め手**：「産生」「射乳」「抑制」「初乳」。
2. **CBT最小知識**：[乳汁分泌](../01_基礎医学/生理/乳汁分泌.md)はPRLで産生、オキシトシンで射乳、エストロゲンで抑制、初乳は分泌型IgA。
3. **選択肢からの連想**：胎盤娩出後のエストロゲン・プロゲステロン低下で乳汁分泌の抑制が外れる。
4. **ひっかけポイント**：産生と射乳を逆にしない。
5. **一言暗記**：作るPRL、出すオキシトシン、初乳IgA。

### 問16の振り返り

1. **決め手**：「過多と過少の原因を分ける」「長期過少の影響」。
2. **CBT最小知識**：[羊水異常](../03_疾患/産婦人科/羊水異常と新生児呼吸障害.md)は、過多＝母体糖尿病・消化管閉鎖・無脳症、過少＝Potter症候群・HDP・破水。
3. **選択肢からの連想**：長期羊水過少は肺低形成、四肢変形、臍帯圧迫を来しうる。
4. **ひっかけポイント**：無脳症は嚥下低下で過多、HDPは胎盤機能不全で過少。
5. **一言暗記**：飲めないと過多、作れない・届かないと過少。

### 問17の振り返り

1. **決め手**：「病態・好発背景・経過」の3軸で比較する。
2. **CBT最小知識**：RDS＝早産＋サーファクタント不足＋増悪、TTN＝帝王切開・正期産＋肺液吸収遅延＋一過性改善。
3. **選択肢からの連想**：母体糖尿病はRDSのリスク、帝王切開は両者のリスクになりうる。
4. **ひっかけポイント**：治療だけでなく病態と経過を要求どおり答える。
5. **一言暗記**：早産で萎むRDS、帝切で肺液が残るTTN。

### 問18の振り返り

1. **決め手**：「第1〜第4を順に」「小泉門が9時で停止」。
2. **CBT最小知識**：[分娩の回旋](../03_疾患/産婦人科/分娩の回旋.md)は屈曲→内回旋→伸展→外回旋。9時方向で停止は低在横定位。
3. **選択肢からの連想**：第1と第3、第2と第4がそれぞれ逆方向。
4. **ひっかけポイント**：「逆」という関係だけでなく、第3と第4の順序を固定する。
5. **一言暗記**：屈・内・伸・外、横で止まれば低在横定位。

## 総評

- 定着：妊娠中の降圧薬、子宮内反症、吸引分娩、妊娠時期、ホルモン、乳汁分泌は再生できた。
- 最優先：高血糖治療、妊娠後期出血、臍帯脱出、NST後のBPSを「症例の決め手→病名・検査」で再確認する。
- 次点：正常妊娠の検査値、流産分類、CRL、羊水過多・過少、RDSとTTN、分娩回旋。
- 得点率60%未満のため、翌日は全18問を解き直さず、誤答論点を短い8問に絞って再生する。
