# 学校感染症

> 学校保健安全法施行規則では、感染拡大を防ぐための出席停止基準が定められている。CBTでは第二種感染症の症状と復学基準の組合せが問われやすい。

## 要点

| 疾患 | 典型所見 | 出席停止の基準 |
| --- | --- | --- |
| [[風疹]] | 発熱・発疹・リンパ節腫脹 | 発疹が消失するまで |
| [[麻疹]] | カタル症状、[[Koplik斑]]、発熱・発疹 | 解熱後3日を経過するまで |
| 水痘 | 紅斑 → 水疱 → 痂皮。各段階が混在する | すべての発疹が痂皮化するまで |
| [[流行性耳下腺炎]] | 有痛性耳下腺腫脹 | 腫脹発現後5日を経過し、かつ全身状態が良好になるまで |
| インフルエンザ | 発熱、頭痛、関節痛、全身倦怠感 | 発症後5日かつ解熱後2日（幼児は3日）を経過するまで |

- 流行性耳下腺炎は無痛性ではなく、有痛性の耳下腺腫脹が典型である。
- 水痘では新旧の皮疹が混在することが特徴である。

## CBTチェック

- 麻疹のKoplik斑は発疹前のカタル期にみられる。
- 風疹は「発疹消失」、水痘は「全て痂皮化」、麻疹は「解熱後3日」と対比する。
