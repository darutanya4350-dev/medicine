# 窒息

> 窒息は換気・酸素供給の障害による死亡である。窒息の三徴候は非特異的で、状況と損傷を組み合わせて判断する。

## 要点

- 溢血点、暗赤色流動血、臓器うっ血は窒息の三徴候だが、単独で窒息死を確定できない。
- [[縊頸]]は索条と自己体重、[[絞頸]]は索条と体重以外の力、[[扼頸]]は手・腕による頸部圧迫である。
- 扼頸では他殺を疑い、舌骨・甲状軟骨の損傷を確認する。
- 酩酊者の嘔吐物誤嚥、胸腹部圧迫による圧死、鼻口閉塞も窒息の原因となる。

## CBTチェック

- 首つり → 縊頸、紐で首を絞める → 絞頸、手で首を絞める → 扼頸。
- 吉川線は絞頸時に索条を外そうとしてできる爪の表皮剝脱で、他殺を示唆する。
