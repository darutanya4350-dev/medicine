# 精神保健福祉法による入院形態

> 精神科入院は、本人の同意、自傷他害のおそれ、緊急性、家族等の同意の有無で区別する。以下はCBTで押さえる基本形である。

## 要点

| 入院形態 | CBTでの決め手 | 指定医・期間の要点 |
|---|---|---|
| 任意入院 | 本人の同意 | 指定医の診察は不要 |
| 医療保護入院 | 本人の同意はないが、入院が必要。自傷他害のおそれは要件でない | 指定医の診察＋家族等の同意 |
| 措置入院 | 自傷他害のおそれ | 指定医2名の診察が一致し、都道府県知事が措置 |
| 緊急措置入院 | 自傷他害のおそれがあり、急速な入院が必要 | 指定医1名、72時間以内 |
| 応急入院 | 急速な入院が必要だが、家族等の同意が得られない | 本人の同意なし、72時間以内 |

## CBTチェック

- 本人が同意 → 任意入院。
- 本人の同意なし＋家族等の同意＋自傷他害のおそれなし → 医療保護入院。
- 自傷他害のおそれ＋指定医2名 → 措置入院。
- 緊急性＋指定医1名＋72時間以内 → 緊急措置入院。
- 「自傷他害のおそれ」と「本人の同意がない」だけで、直ちに同じ入院形態とは限らない。
- 興奮状態の初期対応では、まず患者の同意能力と自傷他害の危険性を評価する。隔離・保護室は必要性を判断した後に行う。
- 医療保護入院は、精神保健指定医1名の判定と家族等の同意が要件である。
