# 公費医療

> **公費医療**は、特定の病気・対象者の医療費を公費で負担する制度。対象と根拠法を対応させて覚える。

## 主な制度

| 制度 | 根拠法 | ポイント |
|---|---|---|
| **医療扶助** | 生活保護法 | 生活保護の8扶助の1つ |
| **結核医療** | 感染症法 | 第37条の2 |
| **自立支援医療** | 障害者総合支援法 | 更生・育成・精神通院医療 |
| **措置入院** | 精神保健福祉法 | 自傷他害のおそれがある精神障害者 |
| **養育医療** | 母子保健法 | 入院が必要な未熟児 |

## CBTチェック

- 結核医療 → **感染症法**
- 医療扶助 → **生活保護法**
- 自立支援医療 → **障害者総合支援法**
- 養育医療 → **母子保健法**
