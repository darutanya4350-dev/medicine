# 入院

> 精神科の入院形態は、**本人同意の有無**、**自傷他害のおそれ**、**精神保健指定医の人数**で区別する。

## 精神科入院形態

| 形態 | 要件 | 指定医・期間 |
|---|---|---|
| **任意入院** | 本人の同意あり | 不要・期限なし |
| **医療保護入院** | 本人同意なし、家族等の同意あり | 1名・期限なし |
| **応急入院** | 急を要し、本人・家族等の同意を得られない | 1名・**72時間以内** |
| **措置入院** | 自傷他害のおそれあり | **2名以上**・期限なし |
| **緊急措置入院** | 急を要する自傷他害のおそれあり | 1名・**72時間以内** |

## CBTチェック

- 自傷他害のおそれ → **措置入院**
- 急を要し、本人・家族等の同意を得られない → **応急入院**
- 指定医2名以上が必要 → **措置入院**
- 72時間以内 → **応急入院・緊急措置入院**
