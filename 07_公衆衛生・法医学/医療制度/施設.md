# 施設

> 高齢者施設は、**在宅復帰をめざす老健**と、**生活の場である特養**を区別する。

## 主な施設

| 施設 | 目的・対象 | キーワード |
|---|---|---|
| **特定機能病院** | 高度医療、医療技術の開発、研修を担う病院 | 大学病院が多い |
| **介護老人福祉施設（特養）** | 常時介護を要する要介護者の生活施設 | 長期入所 |
| **介護老人保健施設（老健）** | 病状が安定した要介護者の在宅復帰を支援 | リハビリ中心・3か月が目安 |
| **軽費老人ホーム** | 低所得などで在宅生活が難しい高齢者を支援 | 低額で食事・生活支援 |
| **老人福祉センター** | 高齢者の相談、健康増進、教養、レクリエーション | 無料または低額 |

※ 老健の「3か月」は在宅復帰をめざす目安であり、一律の法定入所上限ではない。

## CBTチェック

- 在宅復帰をめざしてリハビリを行う → **老健**
- 常時介護が必要な高齢者の生活施設 → **特養**
- 高度医療・研究・研修を担う病院 → **特定機能病院**
