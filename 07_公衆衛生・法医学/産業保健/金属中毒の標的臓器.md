# 金属中毒の標的臓器

> 金属・化学形ごとに標的臓器を結び付ける。特にカドミウムは近位尿細管障害が重要。

## 要点

| 物質 | CBTで押さえる標的・所見 |
|---|---|
| カドミウム | 近位尿細管障害。慢性曝露では骨軟化症（イタイイタイ病）も起こる |
| 水銀 | 有機水銀－中枢神経（[[水俣病]]）、無機水銀－腎近位尿細管 |
| ヒ素 | 急性：消化管障害。慢性：皮膚色素沈着・角化、皮膚癌 |
| ベリリウム | 肺の肉芽腫性病変・肺線維症（ベリリウム肺） |
| マンガン | 大脳基底核障害によるパーキンソニズム |

## CBTチェック

- 問題文の「尿細管障害」→ **カドミウム**を考える（CBT2027 2-731）。
- 「水銀」だけで一括りにしない。有機水銀は神経、無機水銀は腎障害が典型。
- 問題文の「有機水銀－肺癌」→誤り。有機水銀は[[水俣病]]（神経障害）を起こす（CBT2027 2-736）。
- 鉛の症状・健康診断項目は[鉛中毒](鉛中毒.md)を参照。
