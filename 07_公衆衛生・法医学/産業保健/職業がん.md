# 職業がん

> **職業がん**は、職業上の発がん物質へのばく露により生じるがん。**物質と標的臓器をセット**で覚える。

## 代表的な組合せ

| 物質・作業 | 主ながん | 例 |
|---|---|---|
| **ニッケル** | 鼻腔がん（肺がんも） | メッキ・精錬 |
| **芳香族アミン** | [[膀胱癌]] | 染料製造・取扱い |
| **放射線・ラジウム** | 白血病、[[骨肉腫]] | 夜光塗料・放射線業務 |
| **石綿（アスベスト）** | 悪性中皮腫、肺がん | 石綿吹き付け |
| **ベンゼン** | 白血病 | 溶剤・燃料 |

## CBTチェック

- メッキ作業 → **ニッケル → 鼻腔がん**
- 染料取扱い → **芳香族アミン** → [[膀胱癌]]
- 石綿 → **悪性中皮腫・肺がん**
- 原子炉作業などの放射線ばく露 → **白血病**
