# 職業性中毒

> 代表的な有害物質は、特徴的な臓器障害とセットで覚える。

## 要点

| 物質 | 代表的な障害 |
|---|---|
| 鉛 | ヘム合成障害による貧血、腹部疝痛、末梢神経障害 |
| クロム（六価クロム） | 鼻粘膜潰瘍・鼻中隔穿孔、肺癌 |
| ベンゼン | 骨髄障害、白血病（[[職業がん]]） |
| 芳香族アミン | [[膀胱癌]]（[[職業がん]]） |
| パラコート | 肺障害・肺線維症（遅れて進行することがある） |

## CBTチェック

- 問題文の「鉛－網膜症」→誤り。鉛は貧血・腹部疝痛・末梢神経障害を考える（CBT2027 2-719）。
- クロム－鼻中隔穿孔、ベンゼン－白血病、芳香族アミン－膀胱癌、パラコート－肺線維症は代表的な組合せ。
- 金属ごとの標的臓器は[金属中毒の標的臓器](金属中毒の標的臓器.md)を参照。
- パラコート中毒の機序・肺障害は[パラコート中毒](パラコート中毒.md)を参照。
