# 歴史

> CBTでは、日本の医学史における人物と業績の対応が問われる。特に**高木兼寛・北里柴三郎・野口英世・志賀潔**を区別する。

## 人物と業績

| 人物        | 業績                              | 覚え方・ポイント                                        |
| --------- | ------------------------------- | ----------------------------------------------- |
| **高木兼寛**  | 海軍で食事を改善し、脚気患者を激減させた            | 脚気は現在、ビタミンB1欠乏症と分かっている。**海軍の脚気対策**。             |
| **鈴木梅太郎** | 米ぬかから脚気予防に有効なオリザニン（ビタミンB1）を抽出した | **脚気の原因となる栄養素＝ビタミンB1**。高木兼寛は食事改善、鈴木梅太郎は有効成分を発見。 |
| **北里柴三郎** | 破傷風菌の純粋培養、破傷風・ジフテリアの血清療法の確立     | **破傷風・血清療法**。ペスト菌も発見した（イェルサンとほぼ同時期）。            |
| **野口英世**  | 進行麻痺・脊髄癆の患者の脳に[梅毒](../../03_疾患/感染症/梅毒.md)[[トレポネーマ]]を証明   | **梅毒と神経疾患**。黄熱病研究にも従事した。                        |
| **志賀潔**   | 赤痢菌を発見                          | **志賀菌（Shigella）＝赤痢菌**。                      |

## 間違えやすい対応

- **脚気** → 高木兼寛（海軍の食事改善）
- **オリザニン（ビタミンB1）** → 鈴木梅太郎
- **破傷風・血清療法** → 北里柴三郎
- **梅毒トレポネーマ** → 野口英世
- **赤痢菌** → 志賀潔
- **ペスト菌** → 北里柴三郎（イェルサンもほぼ同時期に発見）
