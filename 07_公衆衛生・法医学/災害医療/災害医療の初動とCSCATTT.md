# 災害医療の初動とCSCATTT

> 災害医療では、災害発生前の防災計画と、発生後の現場対応を分けて考える。現場ではまず指揮・安全・情報・状況評価を整え、その後に[[トリアージ]]、治療、搬送を行う。

## 要点

- 基本の流れ：**防災計画 → 災害発生 → 指揮命令系統の確立 → トリアージ → 治療 → 搬送**。
- 災害発生後は、まず **CSCA**（指揮・統制、安全、情報伝達、状況評価）を行い、その後に **TTT**（トリアージ、治療、搬送）へ進む。
- **CSCATTT** は、災害現場で組織的に対応するための7原則である。

| 記号 | 英語 | 現場で行うこと |
|---|---|---|
| C | Command and Control | 指揮・統制、指揮命令系統の確立 |
| S | Safety | 自分・現場・傷病者の安全確保 |
| C | Communication | 情報の収集・共有 |
| A | Assessment | 被害、傷病者数、危険、資源の状況評価 |
| T | Triage | 治療・搬送の優先順位決定 |
| T | Treatment | 必要な処置・治療 |
| T | Transport | 適切な医療機関への搬送 |

- 危険が残る状態で、いきなりトリアージや治療を始めない。
- 実際の災害対応では状況に応じて各要素を反復・並行して行うが、CBTでは **CSCA → TTT** の基本順序を押さえる。

## CBTチェック

- 「最初に行う」→ 指揮・統制と安全確保（CS）。
- 「CSCATTT」→ Command and Control → Safety → Communication → Assessment → Triage → Treatment → Transport。
- 「3T」→ Triage・Treatment・Transport。
- 防災計画は災害発生前、CSCATTTは災害発生後の現場対応。
