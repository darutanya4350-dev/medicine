# 脊髄くも膜下麻酔

> 局所麻酔薬を**くも膜下腔**へ注入し、脊髄神経を遮断する麻酔法。**脊椎麻酔**ともいう。

帝王切開など

## 低血圧の機序

- 交感神経遮断 → 末梢血管抵抗が低下する。
- 静脈拡張 → 血液が末梢に貯留し、静脈還流量が減少する。
- 静脈還流量低下 → 心拍出量が低下し、**血圧低下**をきたす。
- 妊婦では、増大した子宮が下大静脈を圧迫する**仰臥位低血圧症候群**が加わりやすい。

## CBTチェック

- 脊髄くも膜下麻酔後の低血圧の主因 → **交感神経遮断**
- 妊婦の仰臥位で低血圧をきたす機序 → **下大静脈圧迫による静脈還流量低下**
