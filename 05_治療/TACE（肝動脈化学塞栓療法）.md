# TACE（肝動脈化学塞栓療法）

> **TACE**（transcatheter arterial chemoembolization）は、肝動脈から抗癌薬と塞栓物質を投与して[[肝細胞癌]]を治療する方法である。切除・アブレーションが難しい多発例で、肝予備能が保たれている場合に用いる。

## 要点

- 肝細胞癌は主に肝動脈から栄養されるため、抗癌薬とリピオドールを注入後に塞栓物質で腫瘍の血流を選択的に遮断する。
- 肝動脈の塞栓と抗癌薬の作用により、腫瘍周囲の肝実質も障害され、肝予備能が低下しうる。
- 肝予備能が保たれたChild-Pugh A〜Bで、手術や穿刺局所療法の対象とならない多発肝細胞癌に検討する。
- 3 cmを超える病変では、[[ラジオ波焼灼療法]]（RFA）との併用で局所制御の向上を図ることがある。
- 難治性腹水・著明な黄疸などの肝不全や、門脈本幹腫瘍栓では肝不全悪化の危険が高く、原則として避ける。

## CBTチェック

- 両葉多発の肝細胞癌 + 肝予備能良好 → TACEを考える。
- 難治性腹水、PT低下、総ビリルビン高値 → 肝予備能不良でTACEは不適。
- TACEは腫瘍だけでなく肝予備能も低下させうる。門脈本幹腫瘍栓は原則として禁忌。
- TACE後も効果不良、新規肝内病変、脈管侵襲・肝外転移の出現 → TACE不応を考える。
