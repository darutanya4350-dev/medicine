# 気管挿管

> 気道確保・人工呼吸のため、チューブを気管内へ留置する手技。侵襲的であり、**チューブ位置の確認**と合併症への注意が必要である。

## 主な合併症

| 合併症 | 要点 |
|---|---|
| **食道挿管** | 気づかないと低酸素血症をきたす。カプノグラムなどで気管内留置を確認する。 |
| **嗄声** | 喉頭浮腫、声帯損傷、反回神経麻痺などで抜管後に生じうる。 |
| **歯牙損傷** | う歯、動揺歯、義歯・差し歯では起こりやすい。 |
| **気胸** | ブラがある患者や、過度の陽圧換気で起こりうる。 |
| **片肺挿管** | チューブが深すぎると一側主気管支へ入り、低酸素血症・[[無気肺]]をきたす。 |

## CBTチェック

- 気管挿管後に必ず確認すること → **気管内留置の確認**
- 気管挿管に直接関連しにくいもの → **肺梗塞**
- 抜管後の吸気性喘鳴・呼吸困難 → **喉頭痙攣や喉頭浮腫**を疑う。
