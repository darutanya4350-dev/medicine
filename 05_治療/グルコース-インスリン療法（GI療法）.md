# グルコース-インスリン療法（GI療法）

> [[高カリウム血症]]で、インスリンとブドウ糖を静注して血中Kを細胞内へ一時的に移動させる治療。血中Kそのものを体外へ除去する治療ではない。

## 要点

- インスリン → Na⁺/K⁺-ATPase活性化 → 骨格筋などへのK取り込み → 血清K低下。
- ブドウ糖を併用してインスリンによる低血糖を予防する（高血糖時でも低血糖に注意）。
- 効果は一時的で、原因治療や[[血液透析]]などによるK除去が必要になることがある。
- 心電図異常がある場合、GI療法は心筋膜を安定化するカルシウム投与の代わりにはならない。

## CBTチェック

- 「糖とともに細胞内へ取り込まれる電解質」→ **K（カリウム）**。Caではない。
- 高K血症の治療：カルシウム＝心筋保護、GI療法＝Kの細胞内移動、透析＝Kの除去。
- 主な副作用は低血糖。治療後も血糖・血清Kを再評価する。
