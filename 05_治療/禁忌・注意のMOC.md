# 禁忌・注意のMOC

> CBTで頻出の「病態・状況 → 避ける治療」をまとめる入口。理由と例外は、各リンク先の個別ノートで確認する。

## 呼吸器・肺血管

| 病態・状況 | 避ける／注意する治療 | 理由・リンク |
| --- | --- | --- |
| [[気管支喘息]]・気管支攣縮 | **非選択的β遮断薬** | β₂遮断により気管支攣縮を誘発・悪化させる。β₁選択的薬も適応を慎重に判断する。[[β遮断薬]] |
| 感染性肺結核・疑い | 呼吸機能検査（スパイロメトリー） | 強制呼気により感染拡大の懸念があるため、原則延期する。必要時は施設の感染対策に従う。 |
| 感染性肺結核・疑い | 無菌室 | 空気感染対策には**陰圧個室**を用いる。無菌室ではない。 |
| [[アスピリン喘息]] | アスピリンを含む非選択的NSAIDs | COX-1阻害により急性の気管支攣縮・喘息発作を誘発しうる。 |
| [[肺血栓塞栓症]]・静脈血栓塞栓症の既往 | エストロゲン製剤 | 血栓症の発症・再発リスクを高めるため、原則避ける。 |

## CBTチェック

- β遮断薬の呼吸器における注意点は、気管支喘息・気管支攣縮である。
- [[気管挿管]]そのものは、β遮断薬の禁忌ではない。
- 肺血栓塞栓症ではエストロゲン製剤を避ける。一方、[[ジアゼパム]]・β遮断薬は一律禁忌ではなく、急性期の低酸素血症・低血圧・右心不全の有無で慎重に判断する。
