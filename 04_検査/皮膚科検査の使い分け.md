# 皮膚科検査の使い分け

> 皮膚科の検査は、疑う病態が感染症・遅延型アレルギー・即時型アレルギー・水疱性疾患のどれかで選ぶ。

## 要点

| 検査 | 主な対象 | 判定の要点 |
|---|---|---|
| KOH直接鏡検 | [[足白癬]]などの表在性真菌症 | 鱗屑・水疱蓋などで菌糸を確認 |
| ダーモスコピー・顕微鏡検査 | [[疥癬]] | 疥癬トンネル、ヒゼンダニ・虫卵を確認 |
| 貼布試験（パッチテスト） | [[接触皮膚炎|アレルギー性接触皮膚炎]] | 遅延型反応を評価 |
| プリック試験・皮内反応 | 即時型アレルギー | 膨疹・紅斑を評価 |
| Tzanck試験 | ヘルペス感染症・[[天疱瘡]] | ウイルス性巨細胞または棘融解細胞を確認 |

## CBTチェック

- 趾間の落屑・水疱から[[足白癬]]を疑う場合は**KOH直接鏡検**を選ぶ（M3E 18303633）。
- 問題文の「中心治癒＋周辺拡大する鼠径部病変」→ [[股部白癬]]を考え、迅速検査はKOH直接鏡検（M3E 10680530）。
- 鱗屑をKOHで処理して菌糸を確認 → [[足白癬]]などの白癬。白癬菌は真性菌糸・分節胞子としてみえる（M3E 18201670）。
- 角層にPAS陽性の菌要素 → 表在性真菌症を考えるが、病理検査や治療より先に鱗屑の**KOH直接鏡検**を行う（M3E 18201790）。
- PAS染色は組織内の真菌要素、Ziehl-Neelsen染色は結核菌などの抗酸菌の確認に用いる。
- 真菌症を疑う場合、ステロイド投与や抗真菌薬による治療開始前に可能な範囲で検体を採取し、菌要素を確認する。
- 外用薬による接触皮膚炎の原因検索は貼布試験、即時型アレルギーはプリック試験・皮内反応。
- Tzanck試験は真菌検査ではない。
- Nikolsky現象：こすっただけで表皮が剥離・水疱形成 → 天疱瘡、SSSS、TEN型薬疹など。
- Köbner現象：外傷部位に同じ皮疹が出現 → [[尋常性乾癬]]。
- 針反応：刺入部に24〜48時間後の紅斑・丘疹・膿疱 → [[Behçet病]]。
- 硝子圧法：紅斑は退色、紫斑・色素斑は退色しない。
