# 染色

> 染色法は、**何を観察したいか**で選ぶ。まず「組織・細胞」「微生物」「特定の物質」のどれを染めるかで整理する。

## 全体像

| 染色法                              | 主に染めるもの          | 代表的な染まり方                     | 主な用途                         |
| -------------------------------- | ---------------- | ---------------------------- | ---------------------------- |
| **HE染色**（hematoxylin–eosin）      | 組織全体             | 核：青紫、細胞質・間質：赤～桃色             | 病理組織の基本染色                    |
| **Papanicolaou染色**（Pap染色）        | 剥離細胞             | 核：青～青紫、非角化細胞質：青緑、角化細胞質：橙色    | 細胞診、特に子宮頸部細胞診                |
| **Grocott染色**（GMS染色）             | 真菌の細胞壁           | 真菌：黒色                        | 真菌感染症の検出                     |
| **PAM染色**（過ヨウ素酸メテナミン銀染色）         | 糸球体基底膜           | 基底膜：黒色                       | 腎生検、糸球体病変の評価                 |
| **Masson trichrome染色**           | 膠原線維             | 膠原線維：青または緑、細胞質・筋：赤           | 線維化の評価                       |
| **[グラム染色](グラム染色.md)**                    | 細菌               | Gram陽性菌：紫、Gram陰性菌：赤～桃色       | 細菌の大まかな分類                    |
| **Ziehl–Neelsen染色**              | 抗酸菌              | 抗酸菌：赤、背景：青                   | 結核菌などの検出                     |
| **PAS染色**                        | 多糖類・糖タンパク、基底膜、真菌 | 赤紫（マゼンタ）                     | 糖原、粘液、基底膜、真菌の観察              |
| [[Congo red染色]]                  | アミロイド            | 赤橙色、偏光下で黄緑色（apple-green）の複屈折 | [[アミロイドーシス]]の診断                  |
| **Berlin blue染色**（Prussian blue） | 三価鉄（ヘモジデリン）      | 青色                           | 組織・骨髄の鉄沈着の評価                 |
| **Giemsa染色**                     | 血球、血液中の原虫など      | 核・原虫を青紫系に描出                  | 血液塗抹、[マラリア](../../03_疾患/感染症/マラリア.md)など |

※ 染色調は手法や試薬によって多少異なる。

## 目的から逆引き

- **日常の病理組織**を見る → HE染色
- **細胞診**を行う → Papanicolaou染色
- **真菌**を探す → Grocott染色（PAS染色も真菌を染める）
- **抗酸菌**を探す → Ziehl–Neelsen染色
- **一般細菌**を分類する → Gram染色
- **糸球体基底膜**を見る → PAM染色
- **線維化・膠原線維**を見る → Masson trichrome染色
- **アミロイド**を証明する → Congo red染色
- **鉄**を証明する → Berlin blue染色
- **糖原・糖タンパク・基底膜**を見る → PAS染色
- **[マラリア](../../03_疾患/感染症/マラリア.md)原虫**を探す → Giemsa染色

## 間違えやすい組合せ

### Grocott染色とPAM染色

どちらも**メテナミン銀**を使い、対象が黒く見える。

- Grocott染色 → **真菌**
- PAM染色 → **糸球体基底膜**

### HE染色とPapanicolaou染色

- HE染色 → **組織診**の基本
- Papanicolaou染色 → **細胞診**の基本

### PAS染色とPAM染色

- PAS染色 → 糖質を含む構造を**赤紫色**に染める
- PAM染色 → 腎糸球体の基底膜を**黒色**に描出する

### Congo red染色

通常光で赤橙色に染まるだけでなく、**偏光下のapple-green複屈折**が重要。

## CBTチェック

- 子宮頸部の細胞診で用いる基本染色は？ → **Papanicolaou染色**
- 真菌と糸球体基底膜を染める銀染色は、それぞれ？ → **Grocott染色、PAM染色**
- アミロイド、鉄、抗酸菌を染める方法は？ → **Congo red、Berlin blue、Ziehl–Neelsen染色**
