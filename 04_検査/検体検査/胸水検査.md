# 胸水検査：滲出性と漏出性

> 胸水は、全身性の静水圧・膠質浸透圧の変化による**漏出液**と、胸膜・肺の炎症や腫瘍による**滲出液**に分ける。

## 要点

|  | 漏出性胸水 | 滲出性胸水 |
| --- | --- | --- |
| 主な原因 | 心不全、肝硬変、低栄養、[ネフローゼ症候群](../../03_疾患/腎・泌尿器/ネフローゼ症候群.md) | 感染・結核、悪性腫瘍、肺炎などの炎症 |
| 性状 | 比較的低蛋白・低LDH、低比重 | 比較的高蛋白・高LDH、高比重 |
| Rivalta反応 | 陰性 | 陽性 |

- 現在の基本判定は **Lightの基準**。次のいずれか1つを満たせば滲出液：胸水/血清総蛋白比 >0.5、胸水/血清LDH比 >0.6、胸水LDHが血清LDH基準上限の2/3超。
- 透明かどうかだけでは鑑別できない。外観、細胞数・分画、pH、糖、ADA、細胞診、培養などを原因に応じて追加する。
- 滲出液は局所の血管透過性亢進によるため、蛋白やLDHが胸水中へ移行しやすい。
- 胸水・血清総蛋白濃度比0.7は滲出液に該当し、リンパ球優位＋ADA高値なら[[結核性胸膜炎]]を強く疑う。
- 胸水ヒアルロン酸高値は[胸膜中皮腫](../../03_疾患/呼吸器/胸膜中皮腫.md)を示唆するが、確定には病理診断が必要である。

## CBTチェック

- 滲出性：**LDH高値、比重高値、Rivalta陽性**。結核・炎症・腫瘍。
- 漏出性：**心不全、肝疾患、ネフローゼ、低栄養**。
- 「Rivalta陰性」「ネフローゼ」は漏出性の所見・原因である。
- 問題文の「リンパ球優位＋ADA高値＋蛋白比>0.5」→ [[結核性胸膜炎]]を考える。
- 「胸水ヒアルロン酸高値」→ [胸膜中皮腫](../../03_疾患/呼吸器/胸膜中皮腫.md)を考える。
