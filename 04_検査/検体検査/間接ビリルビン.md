# 間接ビリルビン

> 間接ビリルビンは、[[ヘモグロビン代謝|ヘモグロビンの分解]]で生じ、肝臓で抱合される前の[[非抱合型ビリルビン]]である。高値では、まず産生増加と肝での抱合障害を分ける。

## 間接ビリルビン高値の鑑別

| 病態 | 検査・状況 | 代表例 |
|---|---|---|
| [[溶血]] | 貧血、網赤血球↑、乳酸脱水素酵素（LD）↑、[[ハプトグロビン]]↓（特に血管内溶血） | [[自己免疫性溶血性貧血]]、[[遺伝性球状赤血球症]] |
| [[無効造血]] | 貧血、LD↑に対して網赤血球が十分増えない | [[巨赤芽球性貧血]]、[[骨髄異形成症候群]] |
| ヘム分解増加 | 大きな血腫の吸収など。溶血性貧血を伴わない | 頭血腫、広範な皮下血腫 |
| 抱合能の軽度低下 | 肝機能正常、軽度・孤立性で絶食や感染時に増悪 | [[Gilbert症候群]] |
| 抱合能の高度低下・未熟 | 新生児期から高度上昇し、[[核黄疸]]の危険 | [[新生児黄疸]]、[[Crigler-Najjar症候群]] |

- 鑑別の一本道は、**貧血・LD上昇・ハプトグロビン低下の有無 → 網赤血球反応 → 肝機能と年齢・重症度**の順で確認する。
- 網赤血球増加があれば末梢での溶血、貧血があるのに網赤血球反応が乏しければ無効造血を考える。
- 水に溶けずアルブミンと結合するため、**間接ビリルビン高値でも尿中ビリルビンは陰性**である。
- 新生児の高度または急速な間接ビリルビン上昇では、溶血性疾患やCrigler-Najjar症候群を検索し、ビリルビン脳症を予防する。

## CBTチェック

- **間接ビリルビン＋貧血＋LD上昇＋ハプトグロビン低下**なら、まず溶血を考える。
- **間接ビリルビン単独軽度上昇＋肝機能正常**なら、Gilbert症候群が典型である。
- **間接ビリルビン高値＋尿中ビリルビン陰性**は頻出の組合せである。
