# 尿沈渣と円柱

> 円柱は尿細管内で形成されるため、尿沈渣中の円柱は腎実質、とくに糸球体・尿細管間質の病変を示す手がかりとなる。

## 要点

| 円柱 | 主な意義 |
| --- | --- |
| 赤血球円柱 | 活動性の糸球体腎炎を示唆する。 |
| 白血球円柱 | 腎盂腎炎・間質性腎炎を示唆する。 |
| 脂肪円柱 | [[ネフローゼ症候群]]でみられる。 |
| 顆粒円柱・蠟様円柱 | 腎実質障害や進行した[[慢性腎臓病]]でみられうる。 |

- 硝子円柱は発熱・脱水・運動後などでもみられ、単独では特異性が低い。
- 顆粒円柱は少数でも腎実質障害を示唆する異常所見である。
- 糸球体性血尿では変形赤血球や赤血球円柱を認めることがある。
- 尿路感染症でみられる血尿と、赤血球円柱を伴う糸球体性血尿は区別する。
- 尿路感染症では尿沈渣に白血球が多数みられ、尿の混濁を伴うことがある。

## CBTチェック

- **蛋白尿＋血尿＋赤血球円柱**は、活動性の[[糸球体腎炎]]を強く示唆する。
- 白血球円柱は膀胱炎よりも、腎盂腎炎など腎実質の炎症を考える所見である。
- 脂肪円柱はネフローゼ症候群の尿沈渣所見として問われる。
- 「尿沈渣の微小物質」では、白血球・赤血球・円柱・結晶・原虫を形態で区別する。膀胱炎の手掛かりは白血球（膿尿）。
