# 低ナトリウム血症の鑑別

> [[低ナトリウム血症]]では、まず血漿浸透圧と体液量を評価し、尿中Na⁺から腎がNa⁺を保持しているかを判断する。

## 要点

| 病態 | 尿中Na⁺ | 代表例 |
| --- | --- | --- |
| 有効循環血漿量低下 | 低下 | [[心不全]]、[[肝硬変]] |
| ADH不適切分泌 | 増加 | [[SIADH]] |
| アルドステロン欠乏 | 増加 | [[アジソン病|Addison病]] |
| 利尿薬使用 | 増加しうる | サイアザイド系利尿薬 |

- 心不全・肝硬変では全身の体液は増加していても、有効循環血漿量は低下する。RAASとバソプレシン亢進により、Na⁺を保持して希釈性低Na血症を生じる。
- SIADHでは尿中Na⁺排泄が持続する。サイアザイド系利尿薬使用中も尿中Na⁺は高くなりうるため、解釈に注意する。
- 慢性低Na血症の急速補正は[[浸透圧性脱髄症候群]]を起こしうるため、電解質異常のなかでも慎重な時間管理を要する。低K血症、低栄養、アルコール使用症、肝障害では特に補正上限を低くする。

## CBTチェック

- **低Na血症＋尿中Na⁺低下** → 心不全・肝硬変などの有効循環血漿量低下を考える。
- 最も時間をかけて補正する電解質異常 → **低ナトリウム血症**。
