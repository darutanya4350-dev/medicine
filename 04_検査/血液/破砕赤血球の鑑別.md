# 破砕赤血球の鑑別

> **破砕赤血球**（schistocyte）は、血管内のフィブリン網や強いずり応力で赤血球が機械的に破砕された断片である。まず微小血管障害性溶血性貧血（MAHA）を考える。

## 要点

- 破砕赤血球に加えて、LD高値・間接ビリルビン高値・ハプトグロビン低下・網赤血球増加を認める。
- 血小板減少を伴う場合は、PT・APTT、腎障害、妊娠、感染、血圧、薬剤歴を組み合わせて鑑別する。

| 疾患 | 手がかり |
|---|---|
| [[血栓性血小板減少性紫斑病]]（TTP） | 血小板減少＋MAHA＋神経症状、ADAMTS13活性著減・抗体陽性 |
| [[溶血性尿毒症症候群]]（HUS） | 血小板減少＋MAHA＋腎障害、下痢・志賀毒素の既往 |
| [[DIC]] | 血小板減少＋MAHA、PT・APTT延長、フィブリノゲン低下、FDP上昇 |
| [[HELLP症候群]] | 妊娠、溶血（Hemolysis）＋肝逸脱酵素上昇＋血小板減少 |
| 悪性高血圧・機械弁など | 高度高血圧、または人工弁・大血管のずり応力による機械的溶血 |

## CBTチェック

- 「破砕赤血球＋血小板減少＋凝固検査正常」→ TTP・HUSを考える。
- 「破砕赤血球＋PT／APTT延長」→ DICを考える。
- 「破砕赤血球＋妊娠＋肝障害」→ HELLP症候群を考える。
- 「破砕赤血球」だけでTTPと決めつけず、血小板・凝固検査・腎障害・ADAMTS13を確認する。
