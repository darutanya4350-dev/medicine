# 貧血のMCV分類

> 貧血は平均赤血球容積（mean corpuscular volume：MCV）により、小球性・正球性・大球性に分類する。MCVは原因を絞る入口であり、網状赤血球数と組み合わせて評価する。

## 要点

| 分類（成人）             | 主な病態       | CBTで重要な疾患                                  |
| ------------------ | ---------- | ------------------------------------------ |
| 小球性（MCV＜80 fL）     | ヘモグロビン合成障害 | [[鉄欠乏性貧血]]、サラセミア、鉄芽球性貧血、慢性炎症性貧血の一部             |
| 正球性（MCV 80～100 fL） | 産生低下、出血・溶血 | 腎性貧血、[再生不良性貧血](../../03_疾患/血液/再生不良性貧血.md)、急性出血、溶血性貧血、慢性炎症性貧血 |
| 大球性（MCV＞100 fL）    | DNA合成障害など  | ビタミンB12欠乏、葉酸欠乏、骨髄異形成症候群、肝疾患・アルコール、甲状腺機能低下症 |

- 正球性貧血では、網状赤血球↑なら出血・溶血、網状赤血球↓なら骨髄での産生低下を考える。
- 腎性貧血は腎機能低下による[エリスロポエチン](../../01_基礎医学/血液/造血因子.md)産生低下が原因で、典型的には正球性である。
- MCV（fL）＝Ht（％）÷赤血球数（×10⁶/μL）×10で計算する。

## CBTチェック

- 小球性ではまず[[鉄欠乏性貧血]]、大球性ではまず[[ビタミンB12欠乏]]・[[葉酸欠乏]]を考える。
- ビタミンB12欠乏では神経症状を伴いうるが、葉酸欠乏では通常みられない。
- MCVは平均値のため、複数の病態が併存すると正常範囲でも貧血を否定できない。
