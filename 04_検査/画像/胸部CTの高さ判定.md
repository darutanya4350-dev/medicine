# 胸部CTの高さ判定

> 胸部CTの軸位断では、**気管・主気管支**と**大動脈の形**を先に探す。頭側から「弓部分枝 → 大動脈弓 → 上行・下行大動脈 → 肺動脈分岐 → 心腔」の順に見える。

## 最初に見る向き

- 画像は足側から見上げる表示が基本で、**画像左＝患者右、画像上＝腹側、画像下＝背側**である。
- 前方の胸骨と後方の椎体を確認し、黒い空気を含む気管、造影される血管の順に探す。
- 下行大動脈は多くの高さで**椎体の左前方（画像右下）**にあり、位置の基準にしやすい。

## 高さごとのランドマーク

| 高さ（頭側→尾側） | 主に見える構造 | 見分け方 |
|---|---|---|
| 胸郭入口〜大動脈弓分枝 | 腕頭動脈、左総頸動脈、左鎖骨下動脈、腕頭静脈、気管、食道 | 気管は1本。左腕頭静脈が前方を横走する |
| 大動脈弓 | 大動脈弓、上大静脈、気管、食道 | 大動脈が患者左側で弓状・連続性に見える |
| 大動脈肺動脈窓〜気管分岐直上 | 上行大動脈、下行大動脈、上大静脈、気管、奇静脈弓 | 上行・下行大動脈が別々の円形構造となり、気管はまだ1本 |
| 気管分岐〜肺動脈分岐 | 左右主気管支、肺動脈幹、右・左肺動脈、上行・下行大動脈 | 気道が2本に分かれる。**RALS**：右肺動脈は右主気管支の前、左肺動脈は左主気管支の上 |
| 心腔〜横隔膜 | 右房・右室・左房・左室、肺静脈、下大静脈、下行大動脈、食道 | 右室は最前方、左房は後方。さらに尾側で肝・脾・胃が現れる |

## CBTチェック

- 提示画像は、上行・下行大動脈と上大静脈が見え、気管がまだ1本なので、**大動脈肺動脈窓〜気管分岐直上**の高さと考える。
- 気管が左右主気管支へ分かれた断面が[[気管分岐部]]で、その近くに左右肺動脈の分岐が現れる。
- 連続画像で確認するときは、頭側から「大動脈弓 → 上行・下行大動脈 → 肺動脈 → 心腔」と追う。
