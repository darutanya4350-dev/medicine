# 発達検査

> **発達検査**は、乳幼児・小児の発達を年齢相当の水準と比較し、発達の遅れや領域ごとの偏りを評価する検査である。

## 要点

| 検査 | 主な対象・目的 |
|---|---|
| 津守・稲毛式 | 0～7歳の発達検査。運動・探索・社会・生活習慣・言語を評価 |
| WISC | 主に学童期の知能検査。版により対象年齢が異なる |
| SLTA | 成人の失語症検査 |
| MMSE | 主に高齢者の認知機能検査 |

- 津守・稲毛式は、主な養育者への質問を通して発達状況を評価する。
- 3歳児の発達遅滞では、学童期対象の知能検査より乳幼児用の発達検査を選ぶ。
- 発達検査は発達の全体像や領域差をみるもので、単独で診断を確定するものではない。

## CBTチェック

- 問題文の「3歳」「言語と認知の発達の遅れ」→ 津守・稲毛式発達検査を考える。
- 年齢が低い発達評価＝発達検査、学童期の知的能力評価＝WISCと整理する。
