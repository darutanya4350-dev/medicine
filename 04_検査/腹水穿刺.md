# 腹水穿刺

> 腹腔内に貯留した腹水を採取して原因を調べる検査。腹水の排液による症状緩和にも用いられる。

## 要点

- 新たに出現した腹水や感染が疑われる腹水では、細胞数・培養・蛋白などを測定して原因を評価する。
- 腹水の分類には血清腹水アルブミン較差（SAAG）を用いる。SAAG 1.1 g/dL以上は門脈圧亢進を示唆し、1.1 g/dL未満は癌性腹膜炎・結核性腹膜炎などを考える。
- 腹水好中球数（PMN）250/mm³以上は、培養結果にかかわらず特発性細菌性腹膜炎を疑う基準である。
- 蛋白、LDH、Rivalta反応は漏出液・滲出液の補助的評価に用いられる。Rivalta反応は滲出液で陽性、漏出液で陰性だが、現在はSAAGが優先される。
- 安全な穿刺部位の決定には**腹部超音波検査**を用い、腹水貯留部位、腸管・腹壁血管との位置関係を確認する。
- 代表的な体表ランドマークは、臍と左上前腸骨棘を結ぶ**Monro-Richter（モンロー・リヒター）線の外側1/3**。ただし、実際の部位選定は超音波所見を優先する。
- CT・MRIも腹水の評価には有用だが、穿刺直前の部位選択には超音波が最も適する。
- 難治性の大量腹水では、治療目的の腹水穿刺排液を行うことがある。

| 腹水の性状 | 主に考える病態 |
|---|---|
| 淡黄色・透明 | [[肝硬変]]などの門脈圧亢進 |
| 乳び性 | リンパ流障害（悪性リンパ腫、術後など） |
| 血性 | 癌性腹膜炎、外傷など |
| 膿性・混濁 | [[細菌性腹膜炎]] |
| 粘液性 | [[腹膜偽粘液腫]] |

## CBTチェック

- 腹水穿刺の安全確認 → 腹部超音波検査。
- 超音波で腸管と腹壁血管を避けて穿刺部位を選ぶ。
- モンロー・リヒター線 → 臍と左上前腸骨棘を結ぶ線。
- 腹水の診断には超音波・CT・MRIが用いられるが、穿刺の誘導は超音波。
- 腹水PMN 250/mm³以上 → 特発性細菌性腹膜炎を疑う。SAAG 1.1 g/dL以上 → 門脈圧亢進性腹水。
