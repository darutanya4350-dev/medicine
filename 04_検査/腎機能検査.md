# 腎機能検査

> 腎機能検査は、何を評価するかで選ぶ。**左右別の腎機能**を非侵襲的に比較する検査は[[レノグラム]]である。

## 検査と評価部位

| 検査 | 主に評価するもの | CBTでのポイント |
|---|---|---|
| 血清クレアチニン・eGFR | 腎機能の全体的な指標 | 筋肉量の影響を受け、左右別には評価できない。 |
| [[クレアチニンクリアランス]] | [[糸球体濾過量]]（GFR）の近似 | 尿細管分泌のため、GFRをやや過大評価する。正確なGFR測定には[[イヌリン]]を用いる。 |
| PSP排泄試験 | 近位尿細管からの分泌・排泄能 | 両腎の尿細管機能をみる。現在は日常診療ではほぼ用いない。 |
| [[レノグラム]] | 腎血流、尿細管への取り込み・尿路への排泄を左右別に評価 | 放射性医薬品を静注し、体外から経時的に計測する。 |
| 尿濃縮試験（Fishberg試験） | 遠位尿細管〜集合管の濃縮能 | 水制限でADH分泌を促し、尿濃縮能をみる。 |

- [[レノグラム]]には、従来、¹³¹I-ヒップランなどの放射性医薬品が用いられる。

## CBTチェック

- **左右別・非侵襲的・連続的**に腎機能をみる → [[レノグラム]]。
- **GFRの正確な測定** → [[イヌリン]]クリアランス。
- クレアチニンは糸球体で濾過されるが、一部が尿細管から分泌される。
