# 急性心筋梗塞の心電図変化

> [[急性心筋梗塞]]（特にST上昇型）では、虚血の進行に伴い**超急性T波 → ST上昇 → 異常Q波・陰性T波**へ変化し、のちにST部分は基線へ戻る。

## 要点

| 時期の目安 | 心電図所見 | 意味 |
|---|---|---|
| 発症直後 | 高く幅広い[[T波]]（超急性T波） | 早期虚血 |
| 数分～数時間 | [[ST上昇]] | 心筋傷害 |
| 数時間～数日 | [[異常Q波]]、深く対称性の陰性T波（冠性T波） | 心筋壊死・虚血の進行 |
| 数週～ | ST部分は基線へ戻り、T波は浅くなる | 陳旧性変化 |

- 異常Q波は残存しやすいが、必ず出現・永続するわけではない。
- 変化は閉塞部位や再灌流の有無で異なるため、[[心電図]]は経時的に記録する。
- ST上昇は[[冠攣縮性狭心症]]、[[心膜炎]]、早期再分極などでもみられるため、持続時間、症状・連続する誘導の変化・[[トロポニン]]と合わせて判断する。
- 関連：[急性心筋梗塞](../../03_疾患/循環器/急性心筋梗塞.md)、[心筋マーカー](../血液/心筋マーカー.md)

## CBTチェック

- 図の典型的な経過は **③（超急性T波）→②（ST上昇）→①（異常Q波・深い陰性T波）→④（ST正常化）**。
- 超急性T波は高カリウム血症でもみられるため、臨床経過と心電図全体で区別する。
